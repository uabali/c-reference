# CLAUDE.md

Static C language and standard-library reference (Next.js 15, React 19, Tailwind 4, MDX) for c.umutabali.com. Text is converted from the cppreference html-book v20250209 (CC BY-SA 3.0, see `LICENSE-CONTENT`); code is MIT.

## Commands

- `npm install` / `npm ci`: install. `npm run dev`: dev server on port 43123.
- `npm run build`: runs `tools/copy-ort.mjs` (prebuild) then `next build`; `output: "export"` writes static `out/`.
- `npm run lint`: ESLint. `npm test`: pytest (`tests/test_*.py`) plus Node tests (`tests/*.test.ts`). Needs `pip install -r tools/requirements.txt`.
- `npm run examples`: compiles and runs curated C examples (needs Clang 18 / GCC 13).
- `npm run test:e2e`: Playwright smoke test against `out/`.
- `npm run typecheck` currently fails on `tests/render.test.ts` (`.ts` import extensions, TS5097); this predates the docs changes and CI does not run it.

## Layout

- `app/`: Next.js routes (reference, browse, search, paths, cards, mistakes, c23, diagrams, graph, assistant).
- `components/`, `lib/`: UI and content/search/render helpers.
- `content/mdx/`: generated reference pages (do not hand-edit; regenerate with `tools/convert.py`). `content/curated/*.json`: original notes, generated by `tools/write_curated.py` from `tools/curated_part*.py`. `content/catalog.json`, `public/graph.json`, `public/search/`: generated by `tools/build_graph.py` and `tools/build-embeddings.mjs`.
- `tools/`: Python/Node pipeline for conversion, graph, embeddings, upstream sync. `tests/`: pytest, Node tests, Playwright e2e.

## Conventions and gotchas

- Edit curated content in `tools/curated_part*.py`, then run `npm run curated`; never edit generated JSON/MDX directly.
- Curated sections must stay labeled "Added on c.umutabali.com"; every reference page keeps attribution.
- `public/models` and `public/search` hold large committed assets; `public/ort/` is generated and ignored.
- `.env*` is gitignored; no environment variables are required.
