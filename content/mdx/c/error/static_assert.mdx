<p class="decl-header">Defined in header <code>&lt;assert.h&gt;</code></p>

```c
#define static_assert _Static_assert
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span>  <span class="std std-until std-c23">(removed in C23)</span></p>

<p>This convenience macro expands to the keyword <a href="/reference/c/keyword/_Static_assert/"><code>_Static_assert</code></a>.</p>

<h3 id="Example">Example</h3>

```c
#include <assert.h>
 
int main(void)
{
    static_assert(2 + 2 == 4, "2+2 isn't 4");   // well-formed
 
    static_assert(sizeof(int) < sizeof(char),   // compile-time error
                  "this program requires that int is less than char");
}
```

<h3 id="Notes">Notes</h3>

<p>Since C23, <a href="/reference/c/language/static_assert/"><code>static_assert</code></a> is itself a keyword, which may also be a predefined macro, so <a href="/reference/c/error/"><code>&lt;assert.h&gt;</code></a> no longer provides it.</p>
