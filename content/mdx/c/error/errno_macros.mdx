<p>Each of the macros defined in <a href="/reference/c/error/"><code>&lt;errno.h&gt;</code></a> expands to an integer constant expression with type <code>int</code> and with a unique positive value. The following constants are defined by ISO C. The implementation may define more, as long as they begin with <code>&#x27;E&#x27;</code> followed by digits or uppercase letters.</p>

<table class="ref-table ref-dsc">
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;errno.h&gt;</code></td></tr>
<tr><td>EDOM</td><td>Mathematics argument out of domain of function   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>EILSEQ

<span class="std std-since std-c95">(C95)</span></td><td>Illegal byte sequence   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>ERANGE</td><td>Result too large   <span class="mark-note">(macro constant)</span></td></tr>
</table>

<h3 id="Notes">Notes</h3>

<p>Many additional errno constants are <a href="https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/errno.h.html" rel="noreferrer" target="_blank">defined by POSIX</a> and by the <a href="https://en.cppreference.com/w/cpp/error/errno_macros" rel="noreferrer" target="_blank">C++ standard library</a>, and individual implementations may define even more, e.g. <code>errno(3)</code> on Linux or <code>intro(2)</code> on BSD and OS X.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <math.h>
#include <stdio.h>
#include <string.h>
 
int main(void)
{
    errno = 0;
    printf("log(-1.0) = %f\n", log(-1.0));
    printf("%s\n\n", strerror(errno));
 
    errno = 0;
    printf("log(0.0)  = %f\n", log(0.0));
    printf("%s\n", strerror(errno));
}
```

<p>Possible output:</p>

```text
log(-1.0) = nan
Numerical argument out of domain
 
log(0.0)  = -inf
Numerical result out of range
```
