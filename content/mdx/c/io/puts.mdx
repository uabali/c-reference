<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
int puts( const char* str );
```

<p>Writes every character from the null-terminated string <code>str</code> and one additional newline character <code>&#x27;\n&#x27;</code> to the output stream <a href="/reference/c/io/std_streams/">stdout</a>, as if by repeatedly executing <a href="/reference/c/io/putc/">fputc</a>.</p>

<p>The terminating null character from <code>str</code> is not written.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>character string to be written</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>On success, returns a non-negative value.</p>

<p>On failure, returns <a href="/reference/c/io/">EOF</a> and sets the <em>error</em> indicator (see <a href="/reference/c/io/ferror/">ferror()</a>) on <code>stream</code>.</p>

<h3 id="Notes">Notes</h3>

<p>The <code>puts</code> function appends the newline character to the output, while <a href="/reference/c/io/fputs/">fputs</a> function does not.</p>

<p>Different implementations return different non-negative numbers: some return the last character written, some return the number of characters written (or <a href="/reference/c/types/limits/">INT_MAX</a> if the string was longer than that), some simply return a non-negative constant.</p>

<p>A typical cause of failure for <code>puts</code> is running out of space on the file system, when <a href="/reference/c/io/std_streams/">stdout</a> is redirected to a file.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
 
int main(void)
{
    int rc = puts("Hello World");
 
    if (rc == EOF)
        perror("puts()"); // POSIX requires that errno is set
}
```

<p>Output:</p>

```text
Hello World
```
