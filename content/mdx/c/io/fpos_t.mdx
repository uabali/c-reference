<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
typedef /* implementation-defined */ fpos_t;
```

<p><code>fpos_t</code> is a non-array complete object type, can be used to store (by <a href="/reference/c/io/fgetpos/">fgetpos</a>) and restore (by <a href="/reference/c/io/fsetpos/">fsetpos</a>) the position and multibyte parser state (if any) for a C stream.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c95">(since C95)</span></p><p>The multibyte parser state of a wide-oriented C stream is represented by a <a href="/reference/c/string/multibyte/mbstate_t/">mbstate_t</a> object, whose value is stored as part of the value of a <code>fpos_t</code> object by <a href="/reference/c/io/fgetpos/">fgetpos</a>.</p></aside>
