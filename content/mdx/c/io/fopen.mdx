<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
FILE *fopen( const char *filename, const char *mode );
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
FILE *fopen( const char *restrict filename, const char *restrict mode );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t fopen_s( FILE *restrict *restrict streamptr,
                 const char *restrict filename,

                 const char *restrict mode );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Opens a file indicated by <code>filename</code> and returns a pointer to the file stream associated with that file. <code>mode</code> is used to determine the file access mode.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that the pointer to the file stream is written to</p>

<code>streamptr</code>

<p>and the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>streamptr</code>

<p>is a null pointer</p>
</li>
<li>
<code>filename</code>

<p>is a null pointer</p>
</li>
<li>
<code>mode</code>

<p>is a null pointer</p>
</li>
</ul></dd>
</dl>

<p>As with all bounds-checked functions,</p>

<code>fopen_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/io/"><code>&lt;stdio.h&gt;</code></a>

<p>.</p></div>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  If successful, returns a pointer to the new file stream. The stream is fully buffered unless <code>filename</code> refers to an interactive device. On error, returns a null pointer. <a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/fopen.html" rel="noreferrer" target="_blank">POSIX requires</a> that <a href="/reference/c/error/errno/">errno</a> be set in this case.</p>

<p class="li-note"><span class="li-num">2)</span>  If successful, returns zero and a pointer to the new file stream is written to <code>*streamptr</code>. On error, returns a non-zero error code and writes the null pointer to <code>*streamptr</code> (unless <code>streamptr</code> is a null pointer itself).</p>

<h3 id="Notes">Notes</h3>

<p>The format of <code>filename</code> is implementation-defined, and does not necessarily refer to a file (e.g. it may be the console or another device accessible though filesystem API). On platforms that support them, <code>filename</code> may include absolute or relative filesystem path.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    const char* fname = "/tmp/unique_name.txt"; // or tmpnam(NULL);
    int is_ok = EXIT_FAILURE;
 
    FILE* fp = fopen(fname, "w+");
    if (!fp)
    {
        perror("File opening failed");
        return is_ok;
    }
    fputs("Hello, world!\n", fp);
    rewind(fp);
 
    int c; // note: int, not char, required to handle EOF
    while ((c = fgetc(fp)) != EOF) // standard C I/O file reading loop
        putchar(c);
 
    if (ferror(fp))
        puts("I/O error when reading");
    else if (feof(fp))
    {
        puts("End of file is reached successfully");
        is_ok = EXIT_SUCCESS;
    }
 
    fclose(fp);
    remove(fname);
    return is_ok;
}
```

<p>Possible output:</p>

```text
Hello, world!
End of file is reached successfully
```
