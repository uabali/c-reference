<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wint_t fputwc( wchar_t ch, FILE* stream );
```

<p class="decl-note">(1) <span class="std std-since std-c95">(since C95)</span></p>

```c
wint_t putwc( wchar_t ch, FILE* stream );
```

<p class="decl-note">(2) <span class="std std-since std-c95">(since C95)</span></p>

<p>Writes a wide character <code>ch</code> to the given output stream <code>stream</code>.</p>

<p class="li-note"><span class="li-num">2)</span>  May be implemented as a macro and may evaluate <code>stream</code> more than once.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ch</td><td>-</td><td>wide character to be written</td></tr>
<tr><td>stream</td><td>-</td><td>the output stream</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Returns a copy of <code>ch</code> on success.</p>

<p>On failure, returns WEOF and sets the <em>error</em> indicator (see <a href="/reference/c/io/ferror/">ferror()</a>) on <code>stream</code>.</p>

<p>If an encoding error occurred, additionally sets <a href="/reference/c/error/errno/">errno</a> to <a href="/reference/c/error/errno_macros/">EILSEQ</a>.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
 
    errno = 0;
    if (fputwc(L'🍌', stdout) == WEOF)
    {
        if (errno == EILSEQ)
            puts("Encoding error in fputwc.");
        else
            puts("I/O error in fputwc.");
        return EXIT_FAILURE;
    }
}
```

<p>Possible output:</p>

```text
🍌
```
