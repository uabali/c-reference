<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wint_t fgetwc( FILE *stream );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

```c
wint_t getwc( FILE *stream );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Reads the next wide character from the given input stream. <code>getwc()</code> may be implemented as a macro and may evaluate <code>stream</code> more than once.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>stream</td><td>-</td><td>to read the wide character from</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The next wide character from the stream or <code>WEOF</code> on failure.</p>

<p>If the failure has been caused by end-of-file condition, additionally sets the <em>eof</em> indicator (see <a href="/reference/c/io/feof/">feof()</a>) on <code>stream</code>. If the failure has been caused by some other error, sets the <em>error</em> indicator (see <a href="/reference/c/io/ferror/">ferror()</a>) on <code>stream</code>.</p>

<p>If an encoding error occurred, additionally sets <a href="/reference/c/error/errno/">errno</a> to <code>EILSEQ</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
#include <errno.h>
#include <locale.h>
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    FILE *fp = fopen("fgetwc.dat", "w");
    if(!fp) {
        perror("Can't open file for writing");
        return EXIT_FAILURE;
    }
    fputs("кошка\n", fp);
    fclose(fp);
 
    fp = fopen("fgetwc.dat", "r");
    if(!fp) {
        perror("Can't open file for reading");
        return EXIT_FAILURE;
    }
    wint_t wc;
    errno = 0;
    while ((wc = fgetwc(fp)) != WEOF)
        putwchar(wc);
 
    if (ferror(fp)) {
        if (errno == EILSEQ)
            puts("Character encoding error while reading.");
        else
            puts("I/O error when reading");
    } else if (feof(fp))
        puts("End of file reached successfully");
 
    fclose(fp);
}
```

<p>Output:</p>

```text
кошка
```
