<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
void rewind( FILE *stream );
```

<p>Moves the file position indicator to the beginning of the given file stream.</p>

<p>The function is equivalent to <code>fseek(stream, 0, SEEK_SET);</code>, except that end-of-file and error indicators are cleared.</p>

<p>The function drops any effects from previous calls to <a href="/reference/c/io/ungetc/">ungetc</a>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>stream</td><td>-</td><td>file stream to modify</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Example">Example</h3>

<p>This example shows how to read a file twice</p>

```c
#include <stdio.h>
 
char str[20];
 
int main(void)
{
    FILE *f;
    char ch;
 
    f = fopen("file.txt", "w");
    for (ch = '0'; ch <= '9'; ch++) {
        fputc(ch, f);
    }
    fclose(f);
 
    f = fopen("file.txt", "r");
    fread(str, 1, 10, f);
    puts(str);
 
    rewind(f);
    fread(str, 1, 10, f);
    puts(str);
    fclose(f);
 
    return 0;
}
```

<p>Output:</p>

```text
0123456789
0123456789
```
