<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
int fputs( const char*          str, FILE*          stream );
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
int fputs( const char* restrict str, FILE* restrict stream );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Writes every character from the null-terminated string <code>str</code> to the output stream <code>stream</code>, as if by repeatedly executing <a href="/reference/c/io/putc/">fputc</a>.</p>

<p>The terminating null character from <code>str</code> is not written.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>null-terminated character string to be written</td></tr>
<tr><td>stream</td><td>-</td><td>output stream</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>On success, returns a non-negative value.</p>

<p>On failure, returns <a href="/reference/c/io/">EOF</a> and sets the <em>error</em> indicator (see <a href="/reference/c/io/ferror/">ferror()</a>) on <code>stream</code>.</p>

<h3 id="Notes">Notes</h3>

<p>The related function <a href="/reference/c/io/puts/">puts</a> appends a newline character to the output, while <code>fputs</code> writes the string unmodified.</p>

<p>Different implementations return different non-negative numbers: some return the last character written, some return the number of characters written (or <a href="/reference/c/types/limits/">INT_MAX</a> if the string was longer than that), some simply return a non-negative constant such as zero.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
 
int main(void)
{
    int rc = fputs("Hello World", stdout);
 
    if (rc == EOF)
       perror("fputs()"); // POSIX requires that errno is set
}
```

<p>Output:</p>

```text
Hello World
```
