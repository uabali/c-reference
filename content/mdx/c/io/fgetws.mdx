<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wchar_t* fgetws( wchar_t* str, int count, FILE* stream );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span>  <span class="std std-until std-c99">(until C99)</span></p>

```c
wchar_t* fgetws( wchar_t* restrict str, int count, FILE* restrict stream );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Reads at most <code>count - 1</code> wide characters from the given file stream and stores them in <code>str</code>. The produced wide string is always null-terminated. Parsing stops if end-of-file occurs or a newline wide character is found, in which case <code>str</code> will contain that wide newline character.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>wide string to read the characters to</td></tr>
<tr><td>count</td><td>-</td><td>the length of <code>str</code></td></tr>
<tr><td>stream</td><td>-</td><td>file stream to read the data from</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>str</code> on success, a null pointer on an error</p>
