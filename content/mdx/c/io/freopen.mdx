<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
FILE *freopen( const char *filename, const char *mode,
               FILE *stream );
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
FILE *freopen( const char *restrict filename, const char *restrict mode, 
               FILE *restrict stream );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t freopen_s( FILE *restrict *restrict newstreamptr,
                   const char *restrict filename, const char *restrict mode,

                   FILE *restrict stream );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  First, attempts to close the file associated with <code>stream</code>, ignoring any errors. Then, if <code>filename</code> is not null, attempts to open the file specified by <code>filename</code> using <code>mode</code> as if by <a href="/reference/c/io/fopen/">fopen</a>, and associates that file with the file stream pointed to by <code>stream</code>. If <code>filename</code> is a null pointer, then the function attempts to reopen the file that is already associated with <code>stream</code> (it is implementation defined which mode changes are allowed in this case).</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that</p>

<code>mode</code>

<p>is treated as in</p>

fopen_s

<p>and that the pointer to the file stream is written to</p>

<code>newstreamptr</code>

<p>and the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>newstreamptr</code>

<p>is a null pointer</p>
</li>
<li>
<code>stream</code>

<p>is a null pointer</p>
</li>
<li>
<code>mode</code>

<p>is a null pointer</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>freopen_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/io/"><code>&lt;stdio.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  A copy of the value of <code>stream</code> on success, null pointer on failure.</p>

<p class="li-note"><span class="li-num">2)</span>  zero on success (and a copy of the value of <code>stream</code> is written to <code>*newstreamptr</code>, non-zero on error (and null pointer is written to <code>*newstreamptr</code> unless <code>newstreamptr</code> is itself a null pointer).</p>

<h3 id="Notes">Notes</h3>

<p><code>freopen</code> is the only way to change the narrow/wide orientation of a stream once it has been established by an I/O operation or by fwide.</p>

<p>Microsoft CRT version of <code>freopen</code> does not support any mode changes when <code>filename</code> is a null pointer and treats this as an error (see <a href="https://docs.microsoft.com/en-us/cpp/c-runtime-library/reference/freopen-wfreopen" rel="noreferrer" target="_blank">documentation</a>). A possible workaround is the non-standard function <a href="https://docs.microsoft.com/en-us/cpp/c-runtime-library/reference/setmode" rel="noreferrer" target="_blank"><code>_setmode()</code></a>.</p>

<h3 id="Example">Example</h3>

<p>The following code redirects <code>stdout</code> to a file.</p>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    puts("stdout is printed to console");
    if (freopen("redir.txt", "w", stdout) == NULL)
    {
       perror("freopen() failed");
       return EXIT_FAILURE;
    }
    puts("stdout is redirected to a file"); // this is written to redir.txt
    fclose(stdout);
    return EXIT_SUCCESS;
}
```

<p>Output:</p>

```text
stdout is printed to console
```
