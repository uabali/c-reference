<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
FILE* tmpfile( void );
```

<p class="decl-note">(1)</p>

```c
errno_t tmpfile_s( FILE* restrict* restrict streamptr );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Creates and opens a temporary file. The file is opened as binary file for update (as if by <a href="/reference/c/io/fopen/">fopen</a> with <code>&quot;wb+&quot;</code> mode). The filename of the file is guaranteed to be unique within the filesystem. At least <a href="/reference/c/io/">TMP_MAX</a> files may be opened during the lifetime of a program (this limit may be shared with <a href="/reference/c/io/tmpnam/">tmpnam</a> and may be further limited by <a href="/reference/c/io/">FOPEN_MAX</a>).</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that at least</p>

TMP_MAX_S

<p>files may be opened (the limit may be shared with</p>

tmpnam_s

<p>), and if</p>

<code>streamptr</code>

<p>is a null pointer, the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function is called.</p>

<dl>
<dd><p>As with all bounds-checked functions,</p>

<code>tmpfile_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/io/"><code>&lt;stdio.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<p>The temporary file created by this function is closed and deleted when the program exits normally. Whether it's deleted on abnormal termination is implementation-defined.</p>

<h3 id="Parameters">Parameters</h3>

<p class="li-note"><span class="li-num">1)</span>  (none)</p>

<p class="li-note"><span class="li-num">2)</span>  pointer to a pointer that will be updated by this function call</p>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  Pointer to the file stream associated with the file or null pointer if an error has occurred.</p>

<p class="li-note"><span class="li-num">2)</span>  Zero if the file was created and open successfully, non-zero if the file was not created or open or if <code>streamptr</code> was a null pointer. In addition, pointer to the associated file stream is stored in <code>*streamptr</code> on success, and a null pointer value is stored in <code>*streamptr</code> on error.</p>

<h3 id="Notes">Notes</h3>

<p>On some implementations (e.g. older Linux), this function actually creates, opens, and immediately deletes the file from the file system: as long as an open file descriptor to a deleted file is held by a program, the file exists, but since it was deleted, its name does not appear in any directory, so that no other process can open it. Once the file descriptor is closed, or once the program terminates (normally or abnormally), the space occupied by the file is reclaimed by the filesystem. Newer Linux (since 3.11 or later, depending on filesystem) creates such invisible temporary files in one step, via special flag in the <a href="https://man7.org/linux/man-pages/man2/open.2.html" rel="noreferrer" target="_blank"><code>open()</code></a> syscall.</p>

<p>On some implementations (e.g. Windows), elevated privileges are required as the function may create the temporary file in a system directory.</p>

<h3 id="Example">Example</h3>

```c
#define _POSIX_C_SOURCE 200112L
#include <stdio.h>
#include <unistd.h>
 
int main(void)
{
    printf("TMP_MAX = %d, FOPEN_MAX = %d\n", TMP_MAX, FOPEN_MAX);
    FILE* tmpf = tmpfile();
    fputs("Hello, world", tmpf);
    rewind(tmpf);
    char buf[6];
    fgets(buf, sizeof buf, tmpf);
    printf("got back from the file: '%s'\n", buf);
 
    // Linux-specific method to display the tmpfile name
    char fname[FILENAME_MAX], link[FILENAME_MAX] = {0};
    sprintf(fname, "/proc/self/fd/%d", fileno(tmpf));
    if (readlink(fname, link, sizeof link - 1) > 0)
        printf("File name: %s\n", link);
}
```

<p>Possible output:</p>

```text
TMP_MAX = 238328, FOPEN_MAX = 16
got back from the file: 'Hello'
File name: /tmp/tmpfjptPe5 (deleted)
```
