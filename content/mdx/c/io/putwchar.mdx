<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wint_t putwchar( wchar_t ch );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Writes a wide character <code>ch</code> to <code>stdout</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ch</td><td>-</td><td>wide character to be written</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>ch</code> on success, WEOF on failure.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
 
int main()
{
    setlocale(LC_ALL, "en_US.utf8");
 
    const wchar_t data[] =
    {
        L'\u2200', // Unicode name: "FOR ALL"
        L'∀',
        L'\n',
    };
 
    for (size_t t = 0; t != (sizeof data / sizeof(wchar_t)); ++t)
    {
        if (putwchar(data[t]) == WEOF)
        {
            puts("I/O error in putwchar");
            return EXIT_FAILURE;
        }
    }
 
    return EXIT_SUCCESS;
}
```

<p>Possible output:</p>

```text
∀∀
```
