<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wint_t getwchar(void);
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Reads the next wide character from <a href="/reference/c/io/std_streams/">stdin</a>.</p>

<h3 id="Parameters">Parameters</h3>

<p>(none)</p>

<h3 id="Return_value">Return value</h3>

<p>the obtained wide character or <code>WEOF</code> if an error has occurred or the end of file reached</p>
