<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
int remove( const char* pathname );
```

<p>Deletes the file identified by the character string pointed to by <code>pathname</code>.</p>

<p>If the file is currently open by any process, the behavior of this function is implementation-defined. POSIX systems unlink the file name (directory entry), but the filesystem space used by the file is not reclaimed while it is open in any process and while other hard links to the file exist. Windows does not allow the file to be deleted in such cases.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>pathname</td><td>-</td><td>pointer to a null-terminated string containing the path identifying the file to delete</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>0</code> upon success or non-zero value on error.</p>

<h3 id="Notes">Notes</h3>

<p><a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/remove.html" rel="noreferrer" target="_blank">POSIX specifies</a> many additional details for the behavior of this function.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    FILE* fp = fopen("file1.txt", "w"); // create file
    if (!fp)
    {
        perror("file1.txt");
        return EXIT_FAILURE;
    }
    puts("Created file1.txt");
    fclose(fp);
 
    int rc = remove("file1.txt");
    if (rc)
    {
        perror("remove");
        return EXIT_FAILURE;
    }
    puts("Removed file1.txt");
 
    fp = fopen("file1.txt", "r"); // Failure: file does not exist
    if (!fp)
        perror("Opening removed file failed");
 
    rc = remove("file1.txt"); // Failure: file does not exist
    if (rc)
        perror("Double-remove failed");
 
    return EXIT_SUCCESS;
}
```

<p>Possible output:</p>

```text
Created file1.txt
Removed file1.txt
Opening removed file failed: No such file or directory
Double-remove failed: No such file or directory
```
