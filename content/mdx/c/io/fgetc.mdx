<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
int fgetc( FILE* stream );
```

<p class="decl-note">(1)</p>

```c
int getc( FILE* stream );
```

<p class="decl-note">(2)</p>

<p class="li-note"><span class="li-num">1)</span>  Reads the next character from the given input stream.</p>

<p class="li-note"><span class="li-num">2)</span>  Same as <code>fgetc</code>, except that if <code>getc</code> is implemented as a macro, it may evaluate stream more than once, so the corresponding argument should never be an expression with side effects.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>stream</td><td>-</td><td>to read the character from</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>On success, returns the obtained character as an <code>unsigned char</code> converted to an <code>int</code>. On failure, returns <a href="/reference/c/io/">EOF</a>.</p>

<p>If the failure has been caused by end-of-file condition, additionally sets the <em>eof</em> indicator (see <a href="/reference/c/io/feof/">feof()</a>) on <code>stream</code>. If the failure has been caused by some other error, sets the <em>error</em> indicator (see <a href="/reference/c/io/ferror/">ferror()</a>) on <code>stream</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    const char* fname = "/tmp/unique_name.txt"; // or tmpnam(NULL);
    int is_ok = EXIT_FAILURE;
 
    FILE* fp = fopen(fname, "w+");
    if (!fp)
    {
        perror("File opening failed");
        return is_ok;
    }
    fputs("Hello, world!\n", fp);
    rewind(fp);
 
    int c; // note: int, not char, required to handle EOF
    while ((c = fgetc(fp)) != EOF) // standard C I/O file reading loop
        putchar(c);
 
    if (ferror(fp))
        puts("I/O error when reading");
    else if (feof(fp))
    {
        puts("End of file is reached successfully");
        is_ok = EXIT_SUCCESS;
    }
 
    fclose(fp);
    remove(fname);
    return is_ok;
}
```

<p>Possible output:</p>

```text
Hello, world!
End of file is reached successfully
```
