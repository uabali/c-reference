<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
void perror( const char *s );
```

<p>Prints a textual description of the error code currently stored in the system variable <a href="/reference/c/error/errno/">errno</a> to <a href="/reference/c/io/std_streams/">stderr</a>.</p>

<p>The description is formed by concatenating the following components:</p>

<ul>
<li>
<p>the contents of the null-terminated byte string pointed to by</p>

<code>s</code>

<p>, followed by</p>

<code>&quot;: &quot;</code>

<p>(unless</p>

<code>s</code>

<p>is a null pointer or the character pointed to by</p>

<code>s</code>

<p>is the null character)</p>
</li>
<li>
<p>implementation-defined error message string describing the error code stored in</p>

<code>errno</code>

<p>, followed by</p>

<code>&#x27;\n&#x27;</code>

<p>. The error message string is identical to the result of</p>

<code>strerror(errno)</code>

<p>.</p>
</li>
</ul>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>s</td><td>-</td><td>pointer to a null-terminated string with explanatory message</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
 
int main(void)
{
    FILE *f = fopen("non_existent", "r");
    if (f == NULL) {
        perror("fopen() failed");
    } else {
        fclose(f);
    }
}
```

<p>Possible output:</p>

```text
fopen() failed: No such file or directory
```
