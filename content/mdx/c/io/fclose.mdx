<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
int fclose( FILE* stream );
```

<p>Closes the given file stream. Any unwritten buffered data are flushed to the OS. Any unread buffered data are discarded.</p>

<p>Whether or not the operation succeeds, the stream is no longer associated with a file, and the buffer allocated by <a href="/reference/c/io/setbuf/">setbuf</a> or <a href="/reference/c/io/setvbuf/">setvbuf</a>, if any, is also disassociated and deallocated if automatic allocation was used.</p>

<p>The behavior is undefined if the value of the pointer <code>stream</code> is used after <code>fclose</code> returns.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>stream</td><td>-</td><td>the file stream to close</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>0</code> on success, <a href="/reference/c/io/">EOF</a> otherwise</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    const char* fname = "/tmp/unique_name.txt"; // or tmpnam(NULL);
    int is_ok = EXIT_FAILURE;
 
    FILE* fp = fopen(fname, "w+");
    if (!fp)
    {
        perror("File opening failed");
        return is_ok;
    }
    fputs("Hello, world!\n", fp);
    rewind(fp);
 
    int c; // note: int, not char, required to handle EOF
    while ((c = fgetc(fp)) != EOF) // standard C I/O file reading loop
        putchar(c);
 
    if (ferror(fp))
        puts("I/O error when reading");
    else if (feof(fp))
    {
        puts("End of file is reached successfully");
        is_ok = EXIT_SUCCESS;
    }
 
    fclose(fp);
    remove(fname);
    return is_ok;
}
```

<p>Possible output:</p>

```text
Hello, world!
End of file is reached successfully
```
