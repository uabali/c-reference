<p class="decl-header">Defined in header <code>&lt;stdio.h&gt;</code></p>

```c
char *tmpnam( char *filename );
```

<p class="decl-note">(1)</p>

```c
errno_t tmpnam_s(char *filename_s, rsize_t maxsize);
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

```c
#define TMP_MAX        /*unspecified*/
```

```c
#define TMP_MAX_S      /*unspecified*/
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

```c
#define L_tmpnam       /*unspecified*/
```

```c
#define L_tmpnam_s     /*unspecified*/
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Creates a unique valid file name (no longer than <a href="/reference/c/io/">L_tmpnam</a> in length) and stores it in character string pointed to by <code>filename</code>. The function is capable of generating up to <a href="/reference/c/io/">TMP_MAX</a> of unique filenames, but some or all of them may be in use in the filesystem and thus not suitable return values.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that up to</p>

TMP_MAX_S

<p>names may be generated, no longer than</p>

L_tmpnam_s

<p>in length, and the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>filename_s</code>

<p>is a null pointer</p>
</li>
<li>
<code>maxsize</code>

<p>is greater than</p>

<code>RSIZE_MAX</code>
</li>
<li>
<code>maxsize</code>

<p>is less than the generated file name string</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>tmpnam_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/io/"><code>&lt;stdio.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<p><code>tmpnam</code> and <code>tmpnam_s</code> modify static state (which may be shared between these functions) and are not required to be thread-safe.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>filename</td><td>-</td><td>pointer to the character array capable of holding at least <a href="/reference/c/io/">L_tmpnam</a> bytes, to be used as a result buffer. If null pointer is passed, a pointer to an internal static buffer is returned.</td></tr>
<tr><td>filename_s</td><td>-</td><td>pointer to the character array capable of holding at least L_tmpnam_s bytes, to be used as a result buffer.</td></tr>
<tr><td>maxsize</td><td>-</td><td>maximum number of characters the function is allowed to write (typically the size of the <code>filename_s</code> array).</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  <code>filename</code> if <code>filename</code> was not a null pointer. Otherwise a pointer to an internal static buffer is returned. If no suitable filename can be generated, null pointer is returned.</p>

<p class="li-note"><span class="li-num">2)</span>  Returns zero and writes the file name to <code>filename_s</code> on success. On error, returns non-zero and writes the null character to <code>filename_s[0]</code> (only if <code>filename_s</code> is not null and <code>maxsize</code> is not zero and is not greater than RSIZE_MAX).</p>

<h3 id="Notes">Notes</h3>

<p>Although the names generated by <code>tmpnam</code> are difficult to guess, it is possible that a file with that name is created by another process between the moment <code>tmpnam</code> returns and the moment this program attempts to use the returned name to create a file. The standard function <a href="/reference/c/io/tmpfile/">tmpfile</a> and the POSIX function <a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/mkdtemp.html" rel="noreferrer" target="_blank"><code>mkstemp</code></a> do not have this problem (creating a unique directory using only the standard C library still requires the use of <code>tmpnam</code>).</p>

<p>POSIX systems additionally define the similarly named function <a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/tempnam.html" rel="noreferrer" target="_blank"><code>tempnam</code></a>, which offers the choice of a directory (which defaults to the optionally defined macro <a href="https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/stdio.h.html" rel="noreferrer" target="_blank"><code>P_tmpdir</code></a>).</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
 
int main(void)
{
    // Note, the compiler/linker may issue a security warning, e.g. GCC:
    // "warning: the use of `tmpnam' is dangerous, better use `mkstemp'"
    char* name1 = tmpnam(NULL);
    printf("temporary file name: %s\n", name1);
 
    char name2[L_tmpnam];
    if (tmpnam(name2))
        printf("temporary file name: %s\n", name2);
 
    // POSIX offers mkstemp. The following declaration might be
    // necessary as mkstemp is absent in the standard C <stdlib.h>.
    int mkstemp(char*);
 
    char name3[] = "/tmp/fileXXXXXX"; // at least six 'X' required ^_^
    int file_descriptor = mkstemp(name3);
    if (file_descriptor != -1)
        printf("temporary file name: %s\n", name3);
    else
        perror("mkstemp");
}
```

<p>Possible output:</p>

```text
temporary file name: /tmp/file90dLlR
temporary file name: /tmp/fileY9LWAg
temporary file name: /tmp/filexgv8PF
```
