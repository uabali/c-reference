<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
void atomic_thread_fence( memory_order order );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Establishes memory synchronization ordering of non-atomic and relaxed atomic accesses, as instructed by <code>order</code>, without an associated atomic operation. For example, all non-atomic and relaxed atomic stores that happen before a <a href="/reference/c/atomic/memory_order/">memory_order_release</a> fence in thread A will be synchronized with non-atomic and relaxed atomic loads from the same locations made in thread B after an <a href="/reference/c/atomic/memory_order/">memory_order_acquire</a> fence.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>order</td><td>-</td><td>the memory ordering executed by this fence</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>
