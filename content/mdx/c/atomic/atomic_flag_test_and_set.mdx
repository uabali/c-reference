<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
_Bool atomic_flag_test_and_set( volatile atomic_flag* obj );
```

<p class="decl-note">(1) <span class="std std-since std-c11">(since C11)</span></p>

```c
_Bool atomic_flag_test_and_set_explicit( volatile atomic_flag* obj, memory_order order );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p>Atomically changes the state of a <code>atomic_flag</code> pointed to by <code>obj</code> to set (<code>true</code>) and returns the previous value. The first version orders memory accesses according to <a href="/reference/c/atomic/memory_order/">memory_order_seq_cst</a>, the second version orders memory accesses according to <code>order</code>.</p>

<p>The argument is pointer to a volatile atomic flag to accept addresses of both non-volatile and <a href="/reference/c/language/volatile/">volatile</a> (e.g. memory-mapped I/O) atomic flags.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>obj</td><td>-</td><td>pointer to the atomic flag object to modify</td></tr>
<tr><td>order</td><td>-</td><td>the memory synchronization ordering for this operation: all values are permitted</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The previous value held by the atomic flag pointed to by <code>obj</code>.</p>
