<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
#define ATOMIC_FLAG_INIT /* unspecified */
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Expands to an initializer that can be used to initialize <a href="/reference/c/atomic/atomic_flag/">atomic_flag</a> type to the clear state. The value of an <code>atomic_flag</code> that is not initialized using this macro is indeterminate.</p>

<h3 id="Example">Example</h3>

```c
#include <stdatomic.h>
 
atomic_flag flag = ATOMIC_FLAG_INIT;
```
