<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
#define ATOMIC_BOOL_LOCK_FREE     /* implementation-defined */
#define ATOMIC_CHAR_LOCK_FREE     /* implementation-defined */
#define ATOMIC_CHAR16_T_LOCK_FREE /* implementation-defined */
#define ATOMIC_CHAR32_T_LOCK_FREE /* implementation-defined */
#define ATOMIC_WCHAR_T_LOCK_FREE  /* implementation-defined */
#define ATOMIC_SHORT_LOCK_FREE    /* implementation-defined */
#define ATOMIC_INT_LOCK_FREE      /* implementation-defined */
#define ATOMIC_LONG_LOCK_FREE     /* implementation-defined */
#define ATOMIC_LLONG_LOCK_FREE    /* implementation-defined */

#define ATOMIC_POINTER_LOCK_FREE  /* implementation-defined */
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

```c
#define ATOMIC_CHAR8_T_LOCK_FREE  /* implementation-defined */
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Expands to <a href="/reference/c/language/constant_expression/">preprocessor constant expressions</a> that evaluate to either <code>0</code>, <code>1</code>, or <code>2</code> which indicate the lock-free property of the corresponding <a href="/reference/c/thread/#Atomic_operations">atomic types</a> (both signed and unsigned).</p>

<table class="ref-table ref-dsc">
<tr><td>Value</td><td>Explanation</td></tr>
<tr><td><code>0</code></td><td>The atomic type is never lock-free</td></tr>
<tr><td><code>1</code></td><td>The atomic type is sometimes lock-free</td></tr>
<tr><td><code>2</code></td><td>The atomic type is always lock-free</td></tr>
</table>
