<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
_Bool atomic_is_lock_free( const volatile A* obj );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Determines if the atomic operations on all objects of the type <code>A</code> (the type of the object pointed to by <code>obj</code>) are lock-free. In any given program execution, the result of calling <code>atomic_is_lock_free</code> is the same for all pointers of the same type.</p>

<p>This is a <a href="/reference/c/language/generic/">generic function</a> defined for all <a href="/reference/c/language/atomic/">atomic object types</a> <code>A</code>. The argument is pointer to a volatile atomic type to accept addresses of both non-volatile and <a href="/reference/c/language/volatile/">volatile</a> (e.g. memory-mapped I/O) atomic objects, and volatile semantic is preserved when applying this operation to volatile atomic objects.</p>

<p>It is unspecified whether the name of a generic function is a macro or an identifier declared with external linkage. If a macro definition is suppressed in order to access an actual function (e.g. parenthesized like <code>(atomic_is_lock_free)(...)</code>), or a program defines an external identifier with the name of a generic function, the behavior is undefined.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>obj</td><td>-</td><td>pointer to the atomic object to inspect</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>true</code> if the operations on all objects of the type <code>A</code> are lock-free, <code>false</code> otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdatomic.h>
 
_Atomic struct A { int a[100]; } a;
_Atomic struct B { int x, y; } b;
int main(void)
{
    printf("_Atomic struct A is lock free? %s\n", 
            atomic_is_lock_free(&a) ? "true" : "false");
    printf("_Atomic struct B is lock free? %s\n", 
            atomic_is_lock_free(&b) ? "true" : "false");
}
```

<p>Possible output:</p>

```text
_Atomic struct A is lock free? false
_Atomic struct B is lock free? true
```
