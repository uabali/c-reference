<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
#define ATOMIC_VAR_INIT(value) /* unspecified */
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span>  <span class="mark-note">(deprecated in C17)</span>  <span class="std std-until std-c23">(removed in C23)</span></p>

<p>Expands to an expression that can be used to initialize an atomic variable of the same type as <code>value</code>.</p>

<p>The initial value of atomic object of automatic storage duration that is not explicitly initialized is indeterminate. The default (zero) initialization of static and thread-local variables produces a valid value however.</p>

<p>When initializing an atomic variable, any concurrent access, even through an atomic operation, is a data race (it may happen if the address is immediately passed to another thread with a <a href="/reference/c/atomic/memory_order/">memory_order_relaxed</a> operation).</p>

<h3 id="Notes">Notes</h3>

<p>This macro was a part of early draft design for C11 atomic types. It is not needed in C11, and is deprecated in C17 and removed in C23.</p>
