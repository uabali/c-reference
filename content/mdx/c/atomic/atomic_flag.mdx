<p class="decl-header">Defined in header <code>&lt;stdatomic.h&gt;</code></p>

```c
typedef struct /* unspecified */ atomic_flag;
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p><code>atomic_flag</code> is an atomic boolean type. Unlike other atomic types, it is guaranteed to be lock-free. Unlike <a href="/reference/c/thread/#Atomic_operations"><code>atomic_bool</code></a>, <code>atomic_flag</code> does not provide load or store operations.</p>
