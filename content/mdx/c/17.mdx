<p><strong>ISO/IEC 9899:2018</strong>, a.k.a. <strong>C17</strong>/<strong>C18</strong> (denote the year of completion and publication respectively), is a previous revision of the C standard.</p>

<p>C17 is same as C11, except that it bumps the <a href="/reference/c/preprocessor/replace/"><code>__STDC_VERSION__</code></a> predefined macro to <code>201710L</code>, contains several defect reports, and deprecates some features.</p>

<h2 id="Obsolete_features">Obsolete features</h2>

<h3 id="Deprecated_features">Deprecated features</h3>

<ul>
<li>
<a href="/reference/c/atomic/ATOMIC_VAR_INIT/">ATOMIC_VAR_INIT</a>
</li>
<li>
<p>Support for calling</p>

<a href="/reference/c/memory/realloc/"><code>realloc()</code></a>

<p>with zero size</p>
</li>
</ul>
