<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wchar_t *wcspbrk( const wchar_t *dest, const wchar_t *str );
```

<p class="decl-note">(1) <span class="std std-since std-c95">(since C95)</span></p>

```c
/*QWchar_t*/ *wcspbrk( /*QWchar_t*/ *dest, const wchar_t *str );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Finds the first character in wide string pointed to by <code>dest</code>, that is also in wide string pointed to by <code>str</code>.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified wide character object type.</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>dest</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const wchar_t*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>dest</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>wchar_t*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(wcspbrk)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>dest</td><td>-</td><td>pointer to the null-terminated wide string to be analyzed</td></tr>
<tr><td>src</td><td>-</td><td>pointer to the null-terminated wide string that contains the characters to search for</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the first character in <code>dest</code>, that is also in <code>str</code>, or a null pointer if no such character exists.</p>

<h3 id="Notes">Notes</h3>

<p>The name stands for "wide character string pointer break", because it returns a pointer to the first of the separator ("break") characters.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <wchar.h>
 
int main(void)
{
    const wchar_t* str = L"Hello world, friend of mine!";
    const wchar_t* sep = L" ,!";
 
    unsigned int cnt = 0;
    do {
       str = wcspbrk(str, sep); // find separator
       if (str) str += wcsspn(str, sep); // skip separator
       ++cnt; // increment word count
    } while (str && *str);
 
    wprintf(L"There are %u words.\n", cnt);
}
```

<p>Output:</p>

```text
There are 5 words.
```
