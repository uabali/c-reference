<p class="decl-header">Defined in header <code>&lt;wctype.h&gt;</code></p>

```c
wctrans_t wctrans( const char* str );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Constructs a value of type wctrans_t that describes a <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> category of wide character mapping. It may be one of the standard mappings, or a locale-specific mapping, such as <code>&quot;tojhira&quot;</code> or <code>&quot;tojkata&quot;</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td><p>C string holding the name of the desired mapping.</p>

<p>The following values of <code>str</code> are supported in all C locales:</p>

<table class="ref-table ref-dsc">
<tr><td>Value of <code>str</code></td><td>Effect</td></tr>
<tr><td><code>&quot;toupper&quot;</code></td><td>identifies the mapping used by <a href="/reference/c/string/wide/towupper/">towupper</a></td></tr>
<tr><td><code>&quot;tolower&quot;</code></td><td>identifies the mapping used by <a href="/reference/c/string/wide/towlower/">towlower</a></td></tr>
</table></td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>wctrans_t object suitable for use with <a href="/reference/c/string/wide/towctrans/">towctrans</a> to map wide characters according to the named mapping of the current C locale or zero if <code>str</code> does not name a mapping supported by the current C locale.</p>
