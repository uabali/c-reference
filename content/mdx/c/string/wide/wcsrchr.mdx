<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wchar_t *wcsrchr( const wchar_t *str, wchar_t ch );
```

<p class="decl-note">(1) <span class="std std-since std-c95">(since C95)</span></p>

```c
/*QWchar_t*/ *wcsrchr( /*QWchar_t*/ *str, wchar_t ch );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Finds the last occurrence of the wide character <code>ch</code> in the wide string pointed to by <code>str</code>.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified wide character object type.</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>str</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const wchar_t*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>str</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>wchar_t*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(wcsrchr)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>pointer to the null-terminated wide string to be analyzed</td></tr>
<tr><td>ch</td><td>-</td><td>wide character to search for</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the found character in <code>str</code>, or a null pointer if no such character is found.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <wchar.h>
 
int main(void)
{
    wchar_t arr[] = L"白猫 黒猫 кошки";
    wchar_t *cat = wcsrchr(arr, L'猫');
    wchar_t *dog = wcsrchr(arr, L'犬');
 
    setlocale(LC_ALL, "en_US.utf8");
 
    cat ? printf("The character 猫 found at position %td\n", cat - arr)
        : puts("The character 猫 not found");
 
    dog ? printf("The character 犬 found at position %td\n", dog - arr)
        : puts("The character 犬 not found");
}
```

<p>Output:</p>

```text
The character 猫 found at position 4
The character 犬 not found
```
