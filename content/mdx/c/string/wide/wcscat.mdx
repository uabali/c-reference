<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
wchar_t *wcscat( wchar_t *dest, const wchar_t *src );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span>  <span class="std std-until std-c99">(until C99)</span></p>

```c
wchar_t *wcscat( wchar_t *restrict dest, const wchar_t *restrict src );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t wcscat_s( wchar_t *restrict dest, rsize_t destsz,
                  const wchar_t *restrict src );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Appends a copy of the wide string pointed to by <code>src</code> to the end of the wide string pointed to by <code>dest</code>. The wide character <code>src[0]</code> replaces the null terminator at the end of <code>dest</code>. The resulting wide string is null-terminated. The behavior is undefined if the destination array is not large enough for the contents of both <code>str</code> and <code>dest</code> and the terminating null wide character. The behavior is undefined if the strings overlap.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that it may clobber the rest of the destination array (from the last character written to</p>

<code>destsz</code>

<p>) with unspecified values and that the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>src</code>

<p>or</p>

<code>dest</code>

<p>is a null pointer</p>
</li>
<li>
<code>destsz</code>

<p>is zero or greater than</p>

<code>RSIZE_MAX/sizeof(wchar_t)</code>
</li>
<li>
<p>there is no null terminator in the first</p>

<code>destsz</code>

<p>wide characters of</p>

<code>dest</code>
</li>
<li>
<p>truncation would occur (the available space at the end of</p>

<code>dest</code>

<p>would not fit every wide character, including the null terminator, of</p>

<code>src</code>

<p>)</p>
</li>
<li>
<p>overlap would occur between the source and the destination strings</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>wcscat_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>dest</td><td>-</td><td>pointer to the null-terminated wide string to append to</td></tr>
<tr><td>src</td><td>-</td><td>pointer to the null-terminated wide string to copy from</td></tr>
<tr><td>destsz</td><td>-</td><td>maximum number of characters to write, typically the size of the destination buffer</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  returns a copy of <code>dest</code></p>

<p class="li-note"><span class="li-num">2)</span>  returns zero on success, returns non-zero on error. Also, on error, writes <code>L&#x27;\0&#x27;</code> to <code>dest[0]</code> (unless <code>dest</code> is a null pointer or <code>destsz</code> is zero or greater than <code>RSIZE_MAX/sizeof(wchar_t)</code>).</p>

<h3 id="Example">Example</h3>

```c
#include <wchar.h> 
#include <stdio.h>
#include <locale.h>
 
int main(void) 
{
    wchar_t str[50] = L"Земля, прощай.";
    wcscat(str, L" ");
    wcscat(str, L"В добрый путь.");
    setlocale(LC_ALL, "en_US.utf8");
    printf("%ls", str);
}
```

<p>Output:</p>

```text
Земля, прощай. В добрый путь.
```
