<p class="decl-header">Defined in header <code>&lt;wctype.h&gt;</code></p>

```c
wint_t towctrans( wint_t wc, wctrans_t desc );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Maps the wide character <code>wc</code> using the current C locale's <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> mapping category identified by <code>desc</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>wc</td><td>-</td><td>the wide character to map</td></tr>
<tr><td>desc</td><td>-</td><td>the <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> mapping, obtained from a call to <a href="/reference/c/string/wide/wctrans/">wctrans</a></td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The mapped value of <code>wc</code> using the mapping identified by <code>desc</code> in <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> facet of the current C locale.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <wctype.h>
#include <wchar.h>
#include <stdio.h>
 
int main(void)
{
    setlocale(LC_ALL, "ja_JP.UTF-8");
    const wchar_t kana[] = L"ヒラガナ";
    size_t sz = sizeof kana / sizeof *kana;
    wchar_t hira[sz];
    for (size_t n = 0; n < sz; ++n)
        hira[n] = towctrans(kana[n], wctrans("tojhira"));
    printf("katakana characters %ls are %ls in hiragana\n", kana, hira);
}
```

<p>Output:</p>

```text
katakana characters ヒラガナ are ひらがな in hiragana
```
