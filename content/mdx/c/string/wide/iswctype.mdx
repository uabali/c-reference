<p class="decl-header">Defined in header <code>&lt;wctype.h&gt;</code></p>

```c
int iswctype( wint_t wc, wctype_t desc );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Classifies the wide character <code>wc</code> using the current C locale's <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> category identified by <code>desc</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>wc</td><td>-</td><td>the wide character to classify</td></tr>
<tr><td>desc</td><td>-</td><td>the <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> category, obtained from a call to <a href="/reference/c/string/wide/wctype/">wctype</a></td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Non-zero if the character <code>wc</code> has the property identified by <code>desc</code> in <a href="/reference/c/locale/LC_categories/">LC_CTYPE</a> facet of the current C locale, zero otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <wchar.h>
#include <wctype.h>
 
const char* classify(wchar_t wc, const char* cat)
{
    return iswctype(wc, wctype(cat)) ? "true" : "false";
}
 
int main(void)
{
    setlocale(LC_ALL, "ja_JP.UTF-8");
    puts("The character \u6c34 is...");
    const char* cats[] = {"digit", "alpha", "space", "cntrl", "jkanji"};
    for (int n = 0; n < 5; ++n)
        printf("%s?\t%s\n", cats[n], classify(L'\u6c34', cats[n]));
}
```

<p>Output:</p>

```text
The character 水 is...
digit?  false
alpha?  true
space?  false
cntrl?  false
jkanji? true
```
