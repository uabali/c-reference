<p class="decl-header">Defined in header <code>&lt;wctype.h&gt;</code></p>

```c
wint_t towlower( wint_t wc );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Converts the given wide character to lowercase, if possible.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>wc</td><td>-</td><td>wide character to be converted</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Lowercase version of <code>wc</code> or unmodified <code>wc</code> if no lowercase version is listed in the current C locale.</p>

<h3 id="Notes">Notes</h3>

<p>Only 1:1 character mapping can be performed by this function, e.g. the Greek uppercase letter <code>&#x27;Σ&#x27;</code> has two lowercase forms, depending on the position in a word: <code>&#x27;σ&#x27;</code> and <code>&#x27;ς&#x27;</code>. A call to <code>towlower</code> cannot be used to obtain the correct lowercase form in this case.</p>

<p><a href="http://www.open-std.org/JTC1/SC35/WG5/docs/30112d10.pdf" rel="noreferrer" target="_blank">ISO 30112</a> specifies which pairs of Unicode characters are included in this mapping.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <wchar.h>
#include <wctype.h>
 
int main(void)
{
    wchar_t wc = L'\u0190'; // Latin capital open E ('Ɛ')
    printf("in the default locale, towlower(%#x) = %#x\n", wc, towlower(wc));
    setlocale(LC_ALL, "en_US.utf8");
    printf("in Unicode locale, towlower(%#x) = %#x\n", wc, towlower(wc));
}
```

<p>Output:</p>

```text
in the default locale, towlower(0x190) = 0x190
in Unicode locale, towlower(0x190) = 0x25b
```
