<p class="decl-header">Defined in header <code>&lt;wctype.h&gt;</code></p>

```c
int iswalnum( wint_t ch );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>Checks if the given wide character is an alphanumeric character, i.e. either a number (<code>0123456789</code>), an uppercase letter (<code>ABCDEFGHIJKLMNOPQRSTUVWXYZ</code>), a lowercase letter (<code>abcdefghijklmnopqrstuvwxyz</code>) or any alphanumeric character specific to the current locale.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ch</td><td>-</td><td>wide character</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Non-zero value if the wide character is an alphanumeric character, zero otherwise.</p>

<h3 id="Notes">Notes</h3>

<p><a href="https://www.open-std.org/JTC1/SC35/WG5/docs/30112d10.pdf" rel="noreferrer" target="_blank">ISO 30112</a> specifies which Unicode characters are include in POSIX alnum category.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <locale.h>
#include <wchar.h>
#include <wctype.h>
 
int main(void)
{
    wchar_t c = L'\u13ad'; // the Cherokee letter HA ('Ꭽ')
    printf("in the default locale, iswalnum(%#x) = %d\n", c, !!iswalnum(c));
    setlocale(LC_ALL, "en_US.utf8");
    printf("in Unicode locale, iswalnum(%#x) = %d\n", c, !!iswalnum(c));
}
```

<p>Possible output:</p>

```text
in the default locale, iswalnum(0x13ad) = 0
in Unicode locale, iswalnum(0x13ad) = 1
```
