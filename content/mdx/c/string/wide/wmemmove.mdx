<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wchar_t* wmemmove( wchar_t* dest, const wchar_t* src, size_t count );
```

<p class="decl-note">(1) <span class="std std-since std-c95">(since C95)</span></p>

```c
errno_t wmemmove_s( wchar_t *dest, rsize_t destsz,
                    const wchar_t *src, rsize_t count);
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Copies exactly <code>count</code> successive wide characters from the wide character array pointed to by <code>src</code> to the wide character array pointed to by <code>dest</code>. If <code>count</code> is zero, the function does nothing. The arrays may overlap: copying takes place as if the wide characters were copied to a temporary wide character array and then copied from the temporary array to <code>dest</code>.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>src</code>

<p>or</p>

<code>dest</code>

<p>is a null pointer</p>
</li>
<li>
<code>destsz</code>

<p>or</p>

<code>count</code>

<p>is greater than</p>

<code>RSIZE_MAX / sizeof(wchar_t)</code>
</li>
<li>
<code>count</code>

<p>is greater than</p>

<code>destsz</code>

<p>(overflow would occur)</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>wmemcpy_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>dest</td><td>-</td><td>pointer to the wide character array to copy to</td></tr>
<tr><td>src</td><td>-</td><td>pointer to the wide character array to copy from</td></tr>
<tr><td>destsz</td><td>-</td><td>max number of wide characters to write (the size of the destination buffer)</td></tr>
<tr><td>count</td><td>-</td><td>number of wide characters to copy</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  Returns a copy of <code>dest</code></p>

<p class="li-note"><span class="li-num">2)</span>  Returns zero on success, returns non-zero on error. Also, on error, fills the entire <code>dst</code> up to and not including <code>dst+dstsz</code> with null wide characters, <code>L&#x27;\0&#x27;</code> (unless <code>dest</code> is null or <code>destsz</code> is greater than <code>RSIZE_MAX/sizeof(wchar_t)</code>)</p>

<h3 id="Notes">Notes</h3>

<p>This function is not locale-sensitive and pays no attention to the values of the <code>wchar_t</code> objects it copies: nulls as well as invalid characters are copied too.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <wchar.h>
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
 
    wchar_t str[] = L"αβγδεζηθικλμνξοπρστυφχψω";
    printf("%ls\n", str);
    wmemmove(str + 4, str + 3, 3); // copy from [δεζ] to [εζη]
    printf("%ls\n", str);
}
```

<p>Output:</p>

```text
αβγδεζηθικλμνξοπρστυφχψω
αβγδδεζθικλμνξοπρστυφχψω
```
