<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
wchar_t *wcsncat( wchar_t *dest, const wchar_t *src, size_t count );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span>  <span class="std std-until std-c99">(until C99)</span></p>

```c
wchar_t *wcsncat( wchar_t *restrict dest,
                  const wchar_t *restrict src, size_t count );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t wcsncat_s( wchar_t *restrict dest, rsize_t destsz,
                   const wchar_t *restrict src, rsize_t count );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Appends at most <code>count</code> wide characters from the wide string pointed to by <code>src</code>, stopping if the null terminator is copied, to the end of the character string pointed to by <code>dest</code>. The wide character <code>src[0]</code> replaces the null terminator at the end of <code>dest</code>. The null terminator is always appended in the end (so the maximum number of wide characters the function may write is <code>count+1</code>).</p>

<p class="li-note">The behavior is undefined if the destination array is not large enough for the contents of both <code>str</code> and <code>dest</code> and the terminating null wide character.</p>

<p class="li-note">The behavior is undefined if the strings overlap.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that this function may clobber the remainder of the destination array (from the last wide character written to</p>

<code>destsz</code>

<p>) and that the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>src</code>

<p>or</p>

<code>dest</code>

<p>is a null pointer</p>
</li>
<li>
<code>destsz</code>

<p>or</p>

<code>count</code>

<p>is zero or greater than</p>

<code>RSIZE_MAX/sizeof(wchar_t)</code>
</li>
<li>
<p>there is no null wide character in the first</p>

<code>destsz</code>

<p>wide characters of</p>

<code>dest</code>
</li>
<li>
<p>truncation would occur:</p>

<code>count</code>

<p>or the length of</p>

<code>src</code>

<p>, whichever is less, exceeds the space available between the null terminator of</p>

<code>dest</code>

<p>and</p>

<code>destsz</code>

<p>.</p>
</li>
<li>
<p>overlap would occur between the source and the destination strings</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>wcsncat_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>dest</td><td>-</td><td>pointer to the null-terminated wide string to append to</td></tr>
<tr><td>src</td><td>-</td><td>pointer to the null-terminated wide string to copy from</td></tr>
<tr><td>count</td><td>-</td><td>maximum number of wide characters to copy</td></tr>
<tr><td>destsz</td><td>-</td><td>the size of the destination buffer</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  returns a copy of <code>dest</code></p>

<p class="li-note"><span class="li-num">2)</span>  returns zero on success, returns non-zero on error. Also, on error, writes <code>L&#x27;\0&#x27;</code> to <code>dest[0]</code> (unless <code>dest</code> is a null pointer or <code>destsz</code> is zero or greater than <code>RSIZE_MAX/sizeof(wchar_t)</code>).</p>

<h3 id="Notes">Notes</h3>

<p>Although truncation to fit the destination buffer is a security risk and therefore a runtime constraints violation for <code>wcsncat_s</code>, it is possible to get the truncating behavior by specifying <code>count</code> equal to the size of the destination array minus one: it will copy the first <code>count</code> wide characters and append the null terminator as always: <code>wcsncat_s(dst, sizeof dst/sizeof *dst, src, (sizeof dst/sizeof *dst)-wcsnlen_s(dst, sizeof dst/sizeof *dst)-1);</code></p>

<h3 id="Example">Example</h3>

```c
#include <wchar.h> 
#include <stdio.h>
#include <locale.h>
 
int main(void) 
{
    wchar_t str[50] = L"Земля, прощай.";
    wcsncat(str, L" ", 1);
    wcsncat(str, L"В добрый путь.", 8); // only append the first 8 wide chars
    setlocale(LC_ALL, "en_US.utf8");
    printf("%ls", str);
}
```

<p>Possible output:</p>

```text
Земля, прощай. В добрый
```
