<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
wchar_t *wcsstr( const wchar_t *dest, const wchar_t *src );
```

<p class="decl-note">(1) <span class="std std-since std-c95">(since C95)</span></p>

```c
/*QWchar_t*/ *wcsstr( /*QWchar_t*/ *dest, const wchar_t *src );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Finds the first occurrence of the wide string <code>src</code> in the wide string pointed to by <code>dest</code>. The terminating null characters are not compared.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified wide character object type.</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>dest</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const wchar_t*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>dest</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>wchar_t*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(wcsstr)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>dest</td><td>-</td><td>pointer to the null-terminated wide string to examine</td></tr>
<tr><td>src</td><td>-</td><td>pointer to the null-terminated wide string to search for</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the first character of the found substring in <code>dest</code>, or a null pointer if no such substring is found. If <code>src</code> points to an empty string, <code>dest</code> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <locale.h>
#include <wchar.h>
 
int main(void)
{
    setlocale(LC_ALL, "ru_RU.UTF-8");
 
    wchar_t str[5][64] = {
        L"Строка, где есть подстрока 'но'.",
        L"Строка, где такой подстроки нет.",
        L"Он здесь.",
        L"Здесь он.",
        L"Его нет."
    };
 
    for (size_t i = 0; i < 5; ++i) {
        if (wcsstr(str[i], L"но")) {
            wprintf(L"%ls\n", str[i]);
        }
    }
}
```

<p>Output:</p>

```text
Строка, где есть подстрока 'но'.
```
