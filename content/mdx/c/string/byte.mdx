<p>A null-terminated byte string (NTBS) is a sequence of nonzero bytes followed by a byte with value zero (the terminating null character). Each byte in a byte string encodes one character of some character set. For example, the character array <code>{&#x27;\x63&#x27;,&#x27;\x61&#x27;,&#x27;\x74&#x27;,&#x27;\0&#x27;}</code> is an NTBS holding the string <code>&quot;cat&quot;</code> in <a href="/reference/c/language/ascii/">ASCII</a> encoding.</p>
