<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
size_t mbstowcs( wchar_t          *dst, const char          *src, size_t len)
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
size_t mbstowcs( wchar_t *restrict dst, const char *restrict src, size_t len)
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t mbstowcs_s(size_t *restrict retval, wchar_t *restrict dst,
                  rsize_t dstsz, const char *restrict src, rsize_t len);
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Converts a multibyte character string from the array whose first element is pointed to by <code>src</code> to its wide character representation. Converted characters are stored in the successive elements of the array pointed to by <code>dst</code>. No more than <code>len</code> wide characters are written to the destination array.</p>

<p class="li-note">Each character is converted as if by a call to <a href="/reference/c/string/multibyte/mbtowc/">mbtowc</a>, except that the mbtowc conversion state is unaffected. The conversion stops if:</p>

<p class="li-note">* The multibyte null character was converted and stored.</p>

<p class="li-note">* An invalid (in the current C locale) multibyte character was encountered.</p>

<p class="li-note">* The next wide character to be stored would exceed <code>len</code>.</p>

<p class="li-note">If <code>src</code> and <code>dst</code> overlap, the behavior is undefined</p>

<p class="li-note"><span class="li-num">2)</span>  Same as (1), except that</p>

<p class="li-note">* conversion is as-if by <a href="/reference/c/string/multibyte/mbrtowc/">mbrtowc</a>, not <a href="/reference/c/string/multibyte/mbtowc/">mbtowc</a></p>

<p class="li-note">* the function returns its result as an out-parameter <code>retval</code></p>

<p class="li-note">* if no null character was written to <code>dst</code> after <code>len</code> wide characters were written, then <code>L&#x27;\0&#x27;</code> is stored in <code>dst[len]</code>, which means len+1 total wide characters are written</p>

<p class="li-note">* if <code>dst</code> is a null pointer, the number of wide characters that would be produced is stored in <code>*retval</code></p>

<p class="li-note">* the function clobbers the destination array from the terminating null and until <code>dstsz</code></p>

<p class="li-note">* If <code>src</code> and <code>dst</code> overlap, the behavior is unspecified.</p>

<h3 id="Notes">Notes</h3>

<p>In most implementations, <code>mbstowcs</code> updates a global static object of type <a href="/reference/c/string/multibyte/mbstate_t/">mbstate_t</a> as it processes through the string, and cannot be called simultaneously by two threads, <a href="/reference/c/string/multibyte/mbsrtowcs/">mbsrtowcs</a> should be used in such cases.</p>

<p>POSIX specifies a common extension: if <code>dst</code> is a null pointer, this function returns the number of wide characters that would be written to <code>dst</code>, if converted. Similar behavior is standard for <code>mbstowcs_s</code> and for <a href="/reference/c/string/multibyte/mbsrtowcs/">mbsrtowcs</a>.</p>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  On success, returns the number of wide characters, excluding the terminating <code>L&#x27;\0&#x27;</code>, written to the destination array. On conversion error (if invalid multibyte character was encountered), returns <code>(size_t)-1</code>.</p>

<p class="li-note"><span class="li-num">2)</span>  zero on success (in which case the number of wide characters excluding terminating zero that were, or would be written to <code>dst</code>, is stored in <code>*retval</code>), non-zero on error. In case of a runtime constraint violation, stores <code>(size_t)-1</code> in <code>*retval</code> (unless <code>retval</code> is null) and sets <code>dst[0]</code> to <code>L&#x27;\0&#x27;</code> (unless <code>dst</code> is null or <code>dstmax</code> is zero or greater than RSIZE_MAX)</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <locale.h>
#include <stdlib.h>
#include <wchar.h>
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    const char* mbstr = u8"z\u00df\u6c34\U0001F34C"; // or u8"zß水🍌"
    wchar_t wstr[5];
    mbstowcs(wstr, mbstr, 5);
    wprintf(L"MB string: %s\n", mbstr);
    wprintf(L"Wide string: %ls\n", wstr);
}
```

<p>Output:</p>

```text
MB string: zß水🍌
Wide string: zß水🍌
```
