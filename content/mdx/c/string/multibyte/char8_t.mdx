<p class="decl-header">Defined in header <code>&lt;uchar.h&gt;</code></p>

```c
typedef unsigned char char8_t;
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p><code>char8_t</code> is an unsigned integer type used for UTF-8 and is the same type as <code>unsigned char</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <uchar.h>
 
int main(void)
{
    char8_t str[] = u8"zß水🍌"; // or "z\u00df\u6c34\U0001f34c"
    size_t str_sz = sizeof str; // sizeof *str == 1 by definition
    printf("%zu UTF-8 code units: [ ", str_sz);
    for (size_t n = 0; n < str_sz; ++n)
        printf("%02X ", str[n]);
    printf("]\n");
}
```

<p>Possible output:</p>

```text
11 UTF-8 code units: [ 7A C3 9F E6 B0 B4 F0 9F 8D 8C 00 ]
```
