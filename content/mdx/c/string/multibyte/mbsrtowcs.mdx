```c
size_t mbsrtowcs( wchar_t* dst, const char** src, size_t len, mbstate_t* ps );
```

```

errno_t mbsrtowcs_s( size_t *restrict retval,
                     wchar_t *restrict dst, rsize_t dstsz,

```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<div class="li-note"><span class="li-num">1)</span>

<p>Converts a null-terminated multibyte character sequence, which begins in the conversion state described by</p>

<code>*ps</code>

<p>, from the array whose first element is pointed to by</p>

<code>*src</code>

<p>to its wide character representation. If</p>

<code>dst</code>

<p>is not null, converted characters are stored in the successive elements of the wchar_t array pointed to by</p>

<code>dst</code>

<p>. No more than</p>

<code>len</code>

<p>wide characters are written to the destination array. Each multibyte character is converted as if by a call to</p>

<a href="/reference/c/string/multibyte/mbrtowc/">mbrtowc</a>

<p>. The conversion stops if:</p>

<ul>
<li>
<p>The multibyte null character was converted and stored.</p>

<code>*src</code>

<p>is set to null pointer value and</p>

<code>*ps</code>

<p>represents the initial shift state.</p>
</li>
<li>
<p>An invalid multibyte character (according to the current C locale) was encountered.</p>

<code>*src</code>

<p>is set to point at the beginning of the first unconverted multibyte character.</p>
</li>
<li>
<p>the next wide character to be stored would exceed</p>

<code>len</code>

<p>.</p>

<code>*src</code>

<p>is set to point at the beginning of the first unconverted multibyte character. This condition is not checked if</p>

<code>dst</code>

<p>is a null pointer.</p>
</li>
</ul></div>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that</p>

<ul>
<li>
<p>the function returns its result as an out-parameter</p>

<code>retval</code>
</li>
<li>
<p>if no null character was written to</p>

<code>dst</code>

<p>after</p>

<code>len</code>

<p>wide characters were written, then</p>

<code>L&#x27;\0&#x27;</code>

<p>is stored in</p>

<code>dst[len]</code>

<p>, which means len+1 total wide characters are written</p>
</li>
<li>
<p>the function clobbers the destination array from the terminating null and until</p>

<code>dstsz</code>
</li>
<li>
<p>If</p>

<code>src</code>

<p>and</p>

<code>dst</code>

<p>overlap, the behavior is unspecified.</p>
</li>
<li>
<p>the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<code>retval</code>

<p>,</p>

<code>ps</code>

<p>,</p>

<code>src</code>

<p>, or</p>

<code>*src</code>

<p>is a null pointer</p>
</li>
<li>
<code>dstsz</code>

<p>or</p>

<code>len</code>

<p>is greater than</p>

RSIZE_MAX/sizeof(wchar_t)

<p>(unless</p>

<code>dst</code>

<p>is null)</p>
</li>
<li>
<code>dstsz</code>

<p>is not zero (unless</p>

<code>dst</code>

<p>is null)</p>
</li>
<li>
<p>There is no null character in the first</p>

<code>dstsz</code>

<p>multibyte characters in the</p>

<code>*src</code>

<p>array and</p>

<code>len</code>

<p>is greater than</p>

<code>dstsz</code>

<p>(unless</p>

<code>dst</code>

<p>is null)</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>mbsrtowcs_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  On success, returns the number of wide characters, excluding the terminating <code>L&#x27;\0&#x27;</code>, written to the character array. If <code>dst</code> is a null pointer, returns the number of wide characters that would have been written given unlimited length. On conversion error (if invalid multibyte character was encountered), returns <code>(size_t)-1</code>, stores <a href="/reference/c/error/errno_macros/">EILSEQ</a> in <a href="/reference/c/error/errno/">errno</a>, and leaves <code>*ps</code> in unspecified state.</p>

<p class="li-note"><span class="li-num">2)</span>  zero on success (in which case the number of wide characters excluding terminating zero that were, or would be written to <code>dst</code>, is stored in <code>*retval</code>), non-sero on error. In case of a runtime constraint violation, stores <code>(size_t)-1</code> in <code>*retval</code> (unless <code>retval</code> is null) and sets <code>dst[0]</code> to <code>L&#x27;\0&#x27;</code> (unless <code>dst</code> is null or <code>dstmax</code> is zero or greater than RSIZE_MAX)</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <locale.h>
#include <wchar.h>
#include <string.h>
 
void print_as_wide(const char* mbstr)
{
    mbstate_t state;
    memset(&state, 0, sizeof state);
    size_t len = 1 + mbsrtowcs(NULL, &mbstr, 0, &state);
    wchar_t wstr[len];
    mbsrtowcs(&wstr[0], &mbstr, len, &state);
    wprintf(L"Wide string: %ls \n", wstr);
    wprintf(L"The length, including L'\\0': %zu\n", len);
}
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    print_as_wide(u8"z\u00df\u6c34\U0001f34c"); // u8"zß水🍌"
}
```

<p>Output:</p>

```text
Wide string: zß水🍌
The length, including L'\0': 5
```
