<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int mblen( const char* s, size_t n );
```

<p>Determines the size, in bytes, of the multibyte character whose first byte is pointed to by <code>s</code>.</p>

<p>If <code>s</code> is a null pointer, resets the global conversion state and<span class="std std-until std-c23">(until C23)</span> determined whether shift sequences are used.</p>

<p>This function is equivalent to the call <code>mbtowc((wchar_t*)0, s, n)</code>, except that conversion state of <a href="/reference/c/string/multibyte/mbtowc/">mbtowc</a> is unaffected.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>s</td><td>-</td><td>pointer to the multibyte character</td></tr>
<tr><td>n</td><td>-</td><td>limit on the number of bytes in s that can be examined</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If <code>s</code> is not a null pointer, returns the number of bytes that are contained in the multibyte character or <code>-1</code> if the first bytes pointed to by <code>s</code> do not form a valid multibyte character or <code>0</code> if <code>s</code> is pointing at the null charcter <code>&#x27;\0&#x27;</code>.</p>

<p>If <code>s</code> is a null pointer, resets its internal conversion state to represent the initial shift state and<span class="std std-until std-c23">(until C23)</span> returns <code>0</code> if the current multibyte encoding is not state-dependent (does not use shift sequences) or a non-zero value if the current multibyte encoding is state-dependent (uses shift sequences).</p>

<h3 id="Notes">Notes</h3>

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c23">(until C23)</span></p><p>Each call to <code>mblen</code> updates the internal global conversion state (a static object of type <a href="/reference/c/string/multibyte/mbstate_t/">mbstate_t</a>, only known to this function). If the multibyte encoding uses shift states, care must be taken to avoid backtracking or multiple scans. In any case, multiple threads should not call <code>mblen</code> without synchronization: <a href="/reference/c/string/multibyte/mbrlen/">mbrlen</a> may be used instead.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p><code>mblen</code> is not allowed to have an internal state.</p></aside>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
 
// the number of characters in a multibyte string is the sum of mblen()'s
// note: the simpler approach is mbstowcs(NULL, str, sz)
size_t strlen_mb(const char* ptr)
{
    size_t result = 0;
    const char* end = ptr + strlen(ptr);
    mblen(NULL, 0); // reset the conversion state
    while(ptr < end) {
        int next = mblen(ptr, end - ptr);
        if (next == -1) {
           perror("strlen_mb");
           break;
        }
        ptr += next;
        ++result;
    }
    return result;
}
 
void dump_bytes(const char* str)
{
    for (const char* end = str + strlen(str); str != end; ++str)
        printf("%02X ", (unsigned char)str[0]);
    printf("\n");
}
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    const char* str = "z\u00df\u6c34\U0001f34c";
    printf("The string \"%s\" consists of %zu characters, but %zu bytes: ",
            str, strlen_mb(str), strlen(str));
    dump_bytes(str);
}
```

<p>Possible output:</p>

```text
The string "zß水🍌" consists of 4 characters, but 10 bytes: 7A C3 9F E6 B0 B4 F0 9F 8D 8C
```
