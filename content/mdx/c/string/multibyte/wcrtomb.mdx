<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
size_t wcrtomb( char *s, wchar_t wc, mbstate_t *ps);
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

```c
size_t wcrtomb( char *restrict s, wchar_t wc, mbstate_t *restrict ps);
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t wcrtomb_s(size_t *restrict retval, char *restrict s, rsize_t ssz,
                  wchar_t wc, mbstate_t *restrict ps);
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p>Converts a wide character to its narrow multibyte representation.</p>

<p class="li-note"><span class="li-num">1)</span>  If <code>s</code> is not a null pointer, the function determines the number of bytes necessary to store the multibyte character representation of <code>wc</code> (including any shift sequences, and taking into account the current multibyte conversion state <code>*ps</code>), and stores the multibyte character representation in the character array whose first element is pointed to by <code>s</code>, updating <code>*ps</code> as necessary. At most <code>MB_CUR_MAX</code> bytes can be written by this function.</p>

<p class="li-note">If <code>s</code> is a null pointer, the call is equivalent to <code>wcrtomb(buf, L&#x27;\0&#x27;, ps)</code> for some internal buffer <code>buf</code>.</p>

<p class="li-note">If wc is the null wide character <code>L&#x27;\0&#x27;</code>, a null byte is stored, preceded by any shift sequence necessary to restore the initial shift state and the conversion state parameter <code>*ps</code> is updated to represent the initial shift state.</p>

<p class="li-note">If the environment macro <code>__STDC_ISO_10646__</code> is defined, the values of type <code>wchar_t</code> are the same as the short identifiers of the characters in the Unicode required set (typically UTF-32 encoding); otherwise, it is implementation-defined. In any case, the multibyte character encoding used by this function is specified by the currently active C locale.</p>

<p class="li-note"><span class="li-num">2)</span>  Same as (1), except that</p>

<p class="li-note">if <code>s</code> is a null pointer, the call is equivalent to <code>wcrtomb_s(&amp;retval, buf, sizeof buf, L&#x27;\0&#x27;, ps)</code> with internal variables <code>retval</code> and <code>buf</code> (whose size is greater than MB_CUR_MAX)</p>

<p class="li-note">the result is returned in the out-parameter <code>retval</code></p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">

<tr><td>wc</td><td>-</td><td>the wide character to convert</td></tr>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  On success, returns the number of bytes (including any shift sequences) written to the character array whose first element is pointed to by <code>s</code>.</p>

<p class="li-note">On failure (if <code>wc</code> is not a valid wide character), returns <code>(size_t)-1</code>, stores <a href="/reference/c/error/errno_macros/">EILSEQ</a> in <a href="/reference/c/error/errno/">errno</a>, and leaves <code>*ps</code> in unspecified state.</p>

<p class="li-note"><span class="li-num">2)</span>  Returns zero on success and non-zero on failure, in which case, <code>s[0]</code> is set to <code>&#x27;\0&#x27;</code> (unless <code>s</code> is null or <code>ssz</code> is zero or greater than RSIZE_MAX) and <code>*retval</code> is set to <code>(size_t)-1</code> (unless <code>retval</code> is null)</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <locale.h>
#include <string.h>
#include <wchar.h>
#include <stdlib.h>
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    mbstate_t state;
    memset(&state, 0, sizeof state);
    wchar_t in[] = L"zß水🍌"; // or "z\u00df\u6c34\U0001F34C"
    size_t in_sz = sizeof in / sizeof *in;
 
    printf("Processing %zu wchar_t units: [ ", in_sz);
    for(size_t n = 0; n < in_sz; ++n) printf("%#x ", (unsigned int)in[n]);
    puts("]");
 
    char out[MB_CUR_MAX * in_sz];
    char *p = out;
    for(size_t n = 0; n < in_sz; ++n) {
        int rc = wcrtomb(p, in[n], &state); 
        if(rc == -1) break;
        p += rc;
    }
 
    size_t out_sz = p - out;
    printf("into %zu UTF-8 code units: [ ", out_sz);
    for(size_t x = 0; x < out_sz; ++x) printf("%#x ", +(unsigned char)out[x]);
    puts("]");
}
```

<p>Output:</p>

```text
Processing 5 wchar_t units: [ 0x7a 0xdf 0x6c34 0x1f34c 0 ]
into 11 UTF-8 code units: [ 0x7a 0xc3 0x9f 0xe6 0xb0 0xb4 0xf0 0x9f 0x8d 0x8c 0 ]
```
