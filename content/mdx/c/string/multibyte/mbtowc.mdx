<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int mbtowc( wchar_t*          pwc, const char*          s, size_t n )
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
int mbtowc( wchar_t* restrict pwc, const char* restrict s, size_t n )
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Converts a multibyte character whose first byte is pointed to by <code>s</code> to a wide character, written to <code>*pwc</code> if <code>pwc</code> is not null.</p>

<p>If <code>s</code> is a null pointer, resets the global conversion state and determines whether shift sequences are used.</p>

<h3 id="Notes">Notes</h3>

<p>Each call to <code>mbtowc</code> updates the internal global conversion state (a static object of type <a href="/reference/c/string/multibyte/mbstate_t/">mbstate_t</a>, known only to this function). If the multibyte encoding uses shift states, care must be taken to avoid backtracking or multiple scans. In any case, multiple threads should not call <code>mbtowc</code> without synchronization: <a href="/reference/c/string/multibyte/mbrtowc/">mbrtowc</a> may be used instead.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>pwc</td><td>-</td><td>pointer to the wide character for output</td></tr>
<tr><td>s</td><td>-</td><td>pointer to the multibyte character</td></tr>
<tr><td>n</td><td>-</td><td>limit on the number of bytes in s that can be examined</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If <code>s</code> is not a null pointer, returns the number of bytes that are contained in the multibyte character or <code>-1</code> if the first bytes pointed to by <code>s</code> do not form a valid multibyte character or <code>0</code> if <code>s</code> is pointing at the null character <code>&#x27;\0&#x27;</code>.</p>

<p>If <code>s</code> is a null pointer, resets its internal conversion state to represent the initial shift state and returns <code>0</code> if the current multibyte encoding is not state-dependent (does not use shift sequences) or a non-zero value if the current multibyte encoding is state-dependent (uses shift sequences).</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <wchar.h>
 
// print multibyte string to wide-oriented stdout
// equivalent to wprintf(L"%s\n", ptr);
void print_mb(const char* ptr)
{
    mbtowc(NULL, NULL, 0); // reset the conversion state
    const char* end = ptr + strlen(ptr);
    int ret = 0;
    for (wchar_t wc; (ret = mbtowc(&wc, ptr, end - ptr)) > 0; ptr += ret)
        wprintf(L"%lc", wc);
    wprintf(L"\n");
}
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    // UTF-8 narrow multibyte encoding
    print_mb("z\u00df\u6c34\U0001F34C"); // or "zß水🍌"
}
```

<p>Output:</p>

```text
zß水🍌
```
