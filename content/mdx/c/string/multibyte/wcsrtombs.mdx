<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
size_t wcsrtombs( char *dst, const wchar_t **src, size_t len, mbstate_t* ps );
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span>  <span class="std std-until std-c99">(until C99)</span></p>

```c
size_t wcsrtombs( char *restrict dst, const wchar_t **restrict src, size_t len,
                  mbstate_t *restrict ps );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
errno_t wcsrtombs_s( size_t *restrict retval, char *restrict dst, rsize_t dstsz,
                     const wchar_t **restrict src, rsize_t len,

                     mbstate_t *restrict ps );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<div class="li-note"><span class="li-num">1)</span>

<p>Converts a sequence of wide characters from the array whose first element is pointed to by</p>

<code>*src</code>

<p>to its narrow multibyte representation that begins in the conversion state described by</p>

<code>*ps</code>

<p>. If</p>

<code>dst</code>

<p>is not null, converted characters are stored in the successive elements of the char array pointed to by</p>

<code>dst</code>

<p>. No more than</p>

<code>len</code>

<p>bytes are written to the destination array. Each character is converted as if by a call to</p>

<a href="/reference/c/string/multibyte/wcrtomb/">wcrtomb</a>

<p>. The conversion stops if:</p>

<ul>
<li>
<p>The null character</p>

<code>L&#x27;\0&#x27;</code>

<p>was converted and stored. The bytes stored in this case are the unshift sequence (if necessary) followed by</p>

<code>&#x27;\0&#x27;</code>

<p>,</p>

<code>*src</code>

<p>is set to null pointer value and</p>

<code>*ps</code>

<p>represents the initial shift state.</p>
</li>
<li>
<p>A</p>

<code>wchar_t</code>

<p>was found that does not correspond to a valid character in the current C locale.</p>

<code>*src</code>

<p>is set to point at the first unconverted wide character.</p>
</li>
<li>
<p>the next multibyte character to be stored would exceed</p>

<code>len</code>

<p>.</p>

<code>*src</code>

<p>is set to point at the first unconverted wide character. This condition is not checked if</p>

<code>dst</code>

<p>is a null pointer.</p>
</li>
</ul></div>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that</p>

<ul>
<li>
<p>the function returns its result as an out-parameter</p>

<code>retval</code>
</li>
<li>
<p>if the conversion stops without writing a null character, the function will store</p>

<code>&#x27;\0&#x27;</code>

<p>in the next byte in</p>

<code>dst</code>

<p>, which may be</p>

<code>dst[len]</code>

<p>or</p>

<code>dst[dstsz]</code>

<p>, whichever comes first (meaning up to len+1/dstsz+1 total bytes may be written). In this case, there may be no unshift sequence written before the terminating null.</p>
</li>
<li>
<p>the function clobbers the destination array from the terminating null and until</p>

<code>dstsz</code>
</li>
<li>
<p>If</p>

<code>src</code>

<p>and</p>

<code>dst</code>

<p>overlap, the behavior is unspecified.</p>
</li>
<li>
<p>the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<code>retval</code>

<p>,</p>

<code>ps</code>

<p>,</p>

<code>src</code>

<p>, or</p>

<code>*src</code>

<p>is a null pointer</p>
</li>
<li>
<code>dstsz</code>

<p>or</p>

<code>len</code>

<p>is greater than</p>

RSIZE_MAX

<p>(unless</p>

<code>dst</code>

<p>is null)</p>
</li>
<li>
<code>dstsz</code>

<p>is not zero (unless</p>

<code>dst</code>

<p>is null)</p>
</li>
<li>
<code>len</code>

<p>is greater than</p>

<code>dstsz</code>

<p>and the conversion does not encounter null or encoding error in the</p>

<code>src</code>

<p>array by the time</p>

<code>dstsz</code>

<p>is reached (unless</p>

<code>dst</code>

<p>is null)</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>wcsrtombs_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  On success, returns the number of bytes (including any shift sequences, but excluding the terminating <code>&#x27;\0&#x27;</code>) written to the character array whose first element is pointed to by <code>dst</code>. If <code>dst</code> is a null pointer, returns the number of bytes that would have been written. On conversion error (if invalid wide character was encountered), returns <code>(size_t)-1</code>, stores <a href="/reference/c/error/errno_macros/">EILSEQ</a> in <a href="/reference/c/error/errno/">errno</a>, and leaves <code>*ps</code> in unspecified state.</p>

<p class="li-note"><span class="li-num">2)</span>  Returns zero on success (in which case the number of bytes excluding terminating zero that were, or would be written to <code>dst</code>, is stored in <code>*retval</code>), non-zero on error. In case of a runtime constraint violation, stores <code>(size_t)-1</code> in <code>*retval</code> (unless <code>retval</code> is null) and sets <code>dst[0]</code> to <code>&#x27;\0&#x27;</code> (unless <code>dst</code> is null or <code>dstmax</code> is zero or greater than RSIZE_MAX)</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <locale.h>
#include <string.h>
#include <wchar.h>
 
void print_wide(const wchar_t* wstr)
{
    mbstate_t state;
    memset(&state, 0, sizeof state);
    size_t len = 1 + wcsrtombs(NULL, &wstr, 0, &state);
    char mbstr[len];
    wcsrtombs(mbstr, &wstr, len, &state);
    printf("Multibyte string: %s\n", mbstr);
    printf("Length, including '\\0': %zu\n", len);
}
 
int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    print_wide(L"z\u00df\u6c34\U0001f34c"); // or L"zß水🍌"
}
```

<p>Output:</p>

```text
Multibyte string: zß水🍌
Length, including '\0': 11
```
