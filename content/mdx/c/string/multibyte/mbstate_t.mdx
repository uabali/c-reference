```c
struct mbstate_t;
```

<p class="decl-note"><span class="std std-since std-c95">(since C95)</span></p>

<p>The type <code>mbstate_t</code> is a trivial non-array type that can represent any of the conversion states that can occur in an implementation-defined set of supported multibyte character encoding rules. Zero-initialized value of <code>mbstate_t</code> represents the initial conversion state, although other values of <code>mbstate_t</code> may exist that also represent the initial conversion state.</p>

<p>Possible implementation of <code>mbstate_t</code> is a struct type holding an array representing the incomplete multibyte character, an integer counter indicating the number of bytes in the array that have been processed, and a representation of the current shift state.</p>

<p>The following functions should not be called from multiple threads without synchronization with the <code>mbstate_t*</code> argument of a null pointer due to possible data races: <a href="/reference/c/string/multibyte/mbrlen/">mbrlen</a>, <a href="/reference/c/string/multibyte/mbrtowc/">mbrtowc</a>, <a href="/reference/c/string/multibyte/mbsrtowcs/">mbsrtowcs</a>, <a href="/reference/c/string/multibyte/mbtowc/">mbtowc</a>, <a href="/reference/c/string/multibyte/wcrtomb/">wcrtomb</a>, <a href="/reference/c/string/multibyte/wcsrtombs/">wcsrtombs</a>, <a href="/reference/c/string/multibyte/wctomb/">wctomb</a>.</p>
