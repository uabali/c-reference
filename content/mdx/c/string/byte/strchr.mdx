<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

```c
char* strchr( const char* str, int ch );
```

<p class="decl-note">(1)</p>

```c
/*QChar*/ *strchr( /*QChar*/ *str, int ch );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Finds the first occurrence of <code>ch</code> (after conversion to <code>char</code> as if by <code>(char)ch</code>) in the null-terminated byte string pointed to by <code>str</code> (each character interpreted as <code>unsigned char</code>). The terminating null character is considered to be a part of the string and can be found when searching for <code>&#x27;\0&#x27;</code>.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified character object type.</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>str</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const char*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>str</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>char*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(strchr)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<p>The behavior is undefined if <code>str</code> is not a pointer to a null-terminated byte string.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>pointer to the null-terminated byte string to be analyzed</td></tr>
<tr><td>ch</td><td>-</td><td>character to search for</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the found character in <code>str</code>, or null pointer if no such character is found.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <string.h>
 
int main(void)
{
    const char *str = "Try not. Do, or do not. There is no try.";
    char target = 'T';
    const char* result = str;
 
    while((result = strchr(result, target)) != NULL)
    {
        printf("Found '%c' starting at '%s'\n", target, result);
        ++result; // Increment result, otherwise we'll find target at the same location
    }
}
```

<p>Output:</p>

```text
Found 'T' starting at 'Try not. Do, or do not. There is no try.'
Found 'T' starting at 'There is no try.'
```
