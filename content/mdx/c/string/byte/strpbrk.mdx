<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

```c
char *strpbrk( const char *dest, const char *breakset );
```

<p class="decl-note">(1)</p>

```c
/*QChar*/ *strpbrk( /*QChar*/ *dest, const char *breakset );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1 )</span>  Scans the null-terminated byte string pointed to by <code>dest</code> for any character from the null-terminated byte string pointed to by <code>breakset</code>, and returns a pointer to that character.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified character object type.</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>dest</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const char*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>dest</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>char*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(strpbrk)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<p>The behavior is undefined if either <code>dest</code> or <code>breakset</code> is not a pointer to a null-terminated byte string.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>dest</td><td>-</td><td>pointer to the null-terminated byte string to be analyzed</td></tr>
<tr><td>breakset</td><td>-</td><td>pointer to the null-terminated byte string that contains the characters to search for</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the first character in <code>dest</code>, that is also in <code>breakset</code>, or null pointer if no such character exists.</p>

<h3 id="Notes">Notes</h3>

<p>The name stands for "string pointer break", because it returns a pointer to the first of the separator ("break") characters.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <string.h>
 
int main(void)
{
    const char* str = "hello world, friend of mine!";
    const char* sep = " ,!";
 
    unsigned int cnt = 0;
    do
    {
       str = strpbrk(str, sep); // find separator
       if(str) str += strspn(str, sep); // skip separator
       ++cnt; // increment word count
    }
    while(str && *str);
 
    printf("There are %u words\n", cnt);
}
```

<p>Output:</p>

```text
There are 5 words
```
