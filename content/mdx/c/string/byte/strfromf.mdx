<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int strfromf( char* restrict s, size_t n, const char* restrict format, float fp );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

```c
int strfromd( char* restrict s, size_t n, const char* restrict format, double fp );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

```c
int strfroml( char* restrict s, size_t n, const char* restrict format, long double fp );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Converts a floating-point value to a byte string.</p>

<p>The functions are equivalent to <code>snprintf(s, n, format, fp)</code>, except that the format string shall only contain the character <code>%</code>, an optional precision that does not contain an asterisk <code>*</code>, and one of the conversion specifiers <code>a</code>, <code>A</code>, <code>e</code>, <code>E</code>, <code>f</code>, <code>F</code>, <code>g</code>, or <code>G</code>, which applies to the type <code>double</code>, <code>float</code>, or <code>long double</code>) indicated by the function suffix (rather than by a length modifier). Use of these functions with any other format string results in undefined behavior.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>s</td><td>-</td><td>pointer to a character string to write to</td></tr>
<tr><td>n</td><td>-</td><td>up to n - 1 characters may be written, plus the null terminator</td></tr>
<tr><td>format</td><td>-</td><td>pointer to a null-terminated byte string specifying how to interpret the data</td></tr>
<tr><td>fp</td><td>-</td><td>floating-point value to convert</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The number of characters that would have been written had <code>n</code> been sufficiently large, not counting the terminating null character. Thus, the null-terminated output has been completely written if and only if the returned value is both nonnegative and less than <code>n</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main()
{
    char buffer[32];
    int written;
    const char* format[] = {"%a", "%A", "%e", "%E", "%f", "%F", "%g", "%G"};
 
    for (size_t fmt = 0; fmt != sizeof format / sizeof format[0]; ++fmt)
    {
        written = strfromf(buffer, sizeof buffer, format[fmt], 3.1415f);
        printf("strfromf(... %s ...) = %2i, buffer: \"%s\"\n",
               format[fmt], written, buffer);
    }
    puts("");
 
    for (size_t fmt = 0; fmt != sizeof format / sizeof format[0]; ++fmt)
    {
        written = strfromd(buffer, sizeof buffer, format[fmt], 3.1415);
        printf("strfromd(... %s ...) = %2i, buffer: \"%s\"\n",
               format[fmt], written, buffer);
    }
    puts("");
 
    for (size_t fmt = 0; fmt != sizeof format / sizeof format[0]; ++fmt)
    {
        written = strfroml(buffer, sizeof buffer, format[fmt], 3.1415);
        printf("strfroml(... %s ...) = %2i, buffer: \"%s\"\n",
               format[fmt], written, buffer);
    }
}
```
