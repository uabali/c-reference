<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

```c
char *strdup( const char *src );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Returns a pointer to a null-terminated byte string, which is a duplicate of the string pointed to by <code>src</code>. The space for the new string is obtained as if the <a href="/reference/c/memory/malloc/">malloc</a> was invoked. The returned pointer must be passed to <a href="/reference/c/memory/free/">free</a> to avoid a memory leak.</p>

<p>If an error occurs, a null pointer is returned and <a href="/reference/c/error/errno/">errno</a> might be set.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>src</td><td>-</td><td>pointer to the null-terminated byte string to duplicate</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>A pointer to the newly allocated string, or a null pointer if an error occurred.</p>

<h3 id="Notes">Notes</h3>

<p>The function is identical to the <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/strdup.html" rel="noreferrer" target="_blank">POSIX strdup</a>.</p>

<h3 id="Example">Example</h3>

```c
#include <string.h>
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    const char *s1 = "Duplicate me!";
    char *s2 = strdup(s1);
    printf("s2 = \"%s\"\n", s2);
    free(s2);
}
```

<p>Output:</p>

```text
s2 = "Duplicate me!"
```
