<p class="decl-header">Defined in header <code>&lt;ctype.h&gt;</code></p>

```c
int isblank( int ch );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Checks if the given character is a blank character in the current C locale. In the default C locale, only space (<code>0x20</code>) and horizontal tab (<code>0x09</code>) are classified as blank.</p>

<p>The behavior is undefined if the value of <code>ch</code> is not representable as <code>unsigned char</code> and is not equal to <code>EOF</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ch</td><td>-</td><td>character to classify</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Non-zero value if the character is a blank character, zero otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <ctype.h>
#include <limits.h>
 
int main(void)
{
    for (int ndx=0; ndx<=UCHAR_MAX; ndx++)
        if (isblank(ndx)) printf("0x%02x\n", ndx);
}
```

<p>Output:</p>

```text
0x09
0x20
```
