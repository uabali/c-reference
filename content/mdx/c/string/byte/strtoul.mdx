<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
unsigned long      strtoul( const char          *str, char          **str_end, 
                            int base );
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
unsigned long      strtoul( const char *restrict str, char **restrict str_end, 
                            int base );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
unsigned long long strtoull( const char *restrict str, char **restrict str_end,
                             int base );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Interprets an unsigned integer value in a byte string pointed to by <code>str</code>.</p>

<p>Discards any whitespace characters (as identified by calling <a href="/reference/c/string/byte/isspace/"><code>isspace</code></a>) until the first non-whitespace character is found, then takes as many characters as possible to form a valid <em>base-n</em> (where n=<code>base</code>) unsigned integer number representation and converts them to an integer value. The valid unsigned integer value consists of the following parts:</p>

<ul>
<li>
<span class="mark-note">(optional)</span>

<p>plus or minus sign</p>
</li>
<li>
<span class="mark-note">(optional)</span>

<p>prefix (</p>

<code>0</code>

<p>) indicating octal base (applies only when the base is</p>

<code>8</code>

<p>or</p>

<code>0</code>

<p>)</p>
</li>
<li>
<span class="mark-note">(optional)</span>

<p>prefix (</p>

<code>0x</code>

<p>or</p>

<code>0X</code>

<p>) indicating hexadecimal base (applies only when the base is</p>

<code>16</code>

<p>or</p>

<code>0</code>

<p>)</p>
</li>
<li>
<p>a sequence of digits</p>
</li>
</ul>

<p>The set of valid values for base is <code>{0, 2, 3, ..., 36}</code>. The set of valid digits for base-<code>2</code> integers is <code>{0, 1}</code>, for base-<code>3</code> integers is <code>{0, 1, 2}</code>, and so on. For bases larger than <code>10</code>, valid digits include alphabetic characters, starting from <code>Aa</code> for base-<code>11</code> integer, to <code>Zz</code> for base-<code>36</code> integer. The case of the characters is ignored.</p>

<p>Additional numeric formats may be accepted by the currently installed C <a href="/reference/c/locale/setlocale/">locale</a>.</p>

<p>If the value of <code>base</code> is <code>0</code>, the numeric base is auto-detected: if the prefix is <code>0</code>, the base is octal, if the prefix is <code>0x</code> or <code>0X</code>, the base is hexadecimal, otherwise the base is decimal.</p>

<p>If the minus sign was part of the input sequence, the numeric value calculated from the sequence of digits is negated as if by <a href="/reference/c/language/operator_arithmetic/#Unary_arithmetic">unary minus</a> in the result type, which applies unsigned integer wraparound rules.</p>

<p>The functions sets the pointer pointed to by <code>str_end</code> to point to the character past the last character interpreted. If <code>str_end</code> is a null pointer, it is ignored.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>pointer to the null-terminated byte string to be interpreted</td></tr>
<tr><td>str_end</td><td>-</td><td>pointer to a pointer to character, might be set to a position past the last character interpreted</td></tr>
<tr><td>base</td><td>-</td><td><em>base</em> of the interpreted integer value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Integer value corresponding to the contents of <code>str</code> on success. If the converted value falls out of range of corresponding return type, range error occurs (<a href="/reference/c/error/errno/">errno</a> is set to <code>ERANGE</code>) and <a href="/reference/c/types/limits/">ULONG_MAX</a> or <a href="/reference/c/types/limits/">ULLONG_MAX</a> is returned. If no conversion can be performed, <code>0</code> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    const char *p = "10 200000000000000000000000000000 30 -40 - 42";
    printf("Parsing '%s':\n", p);
    char *end = NULL;
    for (unsigned long i = strtoul(p, &end, 10);
         p != end;
         i = strtoul(p, &end, 10))
    {
        printf("'%.*s' -> ", (int)(end - p), p);
        p = end;
        if (errno == ERANGE)
        {
            errno = 0;
            printf("range error, got ");
        }
        printf("%lu\n", i);
    }
    printf("After the loop p points to '%s'\n", p);
}
```

<p>Output:</p>

```text
Parsing '10 200000000000000000000000000000 30 -40 - 42':
'10' -> 10
' 200000000000000000000000000000' -> range error, got 18446744073709551615
' 30' -> 30
' -40' -> 18446744073709551576
After the loop p points to ' - 42'
```
