<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

```c
void* memchr( const void* ptr, int ch, size_t count );
```

<p class="decl-note">(1)</p>

```c
/*QVoid*/ *memchr( /*QVoid*/ *ptr, int ch, size_t count );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Finds the first occurrence of <code>(unsigned char)ch</code> in the initial <code>count</code> bytes (each interpreted as <code>unsigned char</code>) of the object pointed to by <code>ptr</code>.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified object type (including</p>

<code>void</code>

<p>).</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>ptr</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const void*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>ptr</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>void*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(memchr)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<p>The behavior is undefined if access occurs beyond the end of the array searched. The behavior is undefined if <code>ptr</code> is a null pointer.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p>This function behaves as if it reads the bytes sequentially and stops as soon as a matching bytes is found: if the array pointed to by <code>ptr</code> is smaller than <code>count</code>, but the match is found within the array, the behavior is well-defined.</p></aside>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ptr</td><td>-</td><td>pointer to the object to be examined</td></tr>
<tr><td>ch</td><td>-</td><td>bytes to search for</td></tr>
<tr><td>count</td><td>-</td><td>max number of bytes to examine</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the location of the byte, or a null pointer if no such byte is found.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <string.h>
 
int main(void)
{
    const char str[] = "ABCDEFG";
    const int chars[] = {'D', 'd'};
    for (size_t i = 0; i < sizeof chars / (sizeof chars[0]); ++i)
    {
        const int c = chars[i];
        const char *ps = memchr(str, c, strlen(str));
        ps ? printf ("character '%c'(%i) found: %s\n", c, c, ps)
           : printf ("character '%c'(%i) not found\n", c, c);
    }
    return 0;
}
```

<p>Possible output:</p>

```text
character 'D'(68) found: DEFG
character 'd'(100) not found
```
