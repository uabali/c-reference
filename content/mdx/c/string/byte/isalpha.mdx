<p class="decl-header">Defined in header <code>&lt;ctype.h&gt;</code></p>

```c
int isalpha( int ch );
```

<p>Checks if the given character is an alphabetic character, i.e. either an uppercase letter (<code>ABCDEFGHIJKLMNOPQRSTUVWXYZ</code>), or a lowercase letter (<code>abcdefghijklmnopqrstuvwxyz</code>).</p>

<p>In locales other than <code>&quot;C&quot;</code>, an alphabetic character is a character for which <a href="/reference/c/string/byte/isupper/">isupper()</a> or <a href="/reference/c/string/byte/islower/">islower()</a> returns <code>true</code> or any other character considered alphabetic by the locale. In any case, <a href="/reference/c/string/byte/iscntrl/">iscntrl()</a>, <a href="/reference/c/string/byte/isdigit/">isdigit()</a>, <a href="/reference/c/string/byte/ispunct/">ispunct()</a> and <a href="/reference/c/string/byte/isspace/">isspace()</a> will return <code>false</code> for this character.</p>

<p>The behavior is undefined if the value of <code>ch</code> is not representable as <code>unsigned char</code> and is not equal to <code>EOF</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ch</td><td>-</td><td>character to classify</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Non-zero value if the character is an alphabetic character, zero otherwise.</p>

<h3 id="Example">Example</h3>

<p>Demonstrates the use of <code>isalpha</code> with different locales (OS-specific).</p>

```c
#include <ctype.h>
#include <stdio.h>
#include <locale.h>
 
int main(void)
{
    unsigned char c = '\xdf'; // German letter ß in ISO-8859-1
 
    printf("isalpha('\\xdf') in default C locale returned %d\n", !!isalpha(c));
 
    setlocale(LC_CTYPE, "de_DE.iso88591");
    printf("isalpha('\\xdf') in ISO-8859-1 locale returned %d\n", !!isalpha(c));
}
```

<p>Possible output:</p>

```text
isalpha('\xdf') in default C locale returned 0
isalpha('\xdf') in ISO-8859-1 locale returned 1
```
