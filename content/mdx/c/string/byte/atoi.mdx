<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int       atoi ( const char* str );
```

<p class="decl-note">(1)</p>

```c
long      atol ( const char* str );
```

<p class="decl-note">(2)</p>

```c
long long atoll( const char* str );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p>Interprets an integer value in a byte string pointed to by <code>str</code>. The implied radix is always 10.</p>

<p>Discards any whitespace characters until the first non-whitespace character is found, then takes as many characters as possible to form a valid integer number representation and converts them to an integer value. The valid integer value consists of the following parts:</p>

<ul>
<li>
<span class="mark-note">(optional)</span>

<p>plus or minus sign</p>
</li>
<li>
<p>numeric digits</p>
</li>
</ul>

<p>If the value of the result cannot be represented, i.e. the converted value falls out of range of the corresponding return type, the behavior is undefined.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>pointer to the null-terminated byte string to be interpreted</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Integer value corresponding to the contents of <code>str</code> on success.</p>

<p>If no conversion can be performed, <code>0</code> is returned.</p>

<h3 id="Notes">Notes</h3>

<p>The name stands for "ASCII to integer".</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    printf("%i\n", atoi(" -123junk"));
    printf("%i\n", atoi(" +321dust"));
    printf("%i\n", atoi("0"));
    printf("%i\n", atoi("0042")); // treated as a decimal number with leading zeros
    printf("%i\n", atoi("0x2A")); // only leading zero is converted discarding "x2A"
    printf("%i\n", atoi("junk")); // no conversion can be performed
    printf("%i\n", atoi("2147483648")); // UB: out of range of int
}
```

<p>Possible output:</p>

```text
-123
321
0
42
0
0
-2147483648
```
