<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

```c
char* strstr( const char* str, const char* substr );
```

<p class="decl-note">(1)</p>

```c
/*QChar*/* strstr( /*QChar*/* str, const char* substr );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Finds the first occurrence of the null-terminated byte string pointed to by <code>substr</code> in the null-terminated byte string pointed to by <code>str</code>. The terminating null characters are not compared.</p>

<div class="li-note"><span class="li-num">2)</span>

<p>Type-generic function equivalent to</p>

(1)

<p>. Let</p>

<code>T</code>

<p>be an unqualified character object type.</p>

<dl>
<dd><ul>
<li>
<p>If</p>

<code>str</code>

<p>is of type</p>

<code>const T*</code>

<p>, the return type is</p>

<code>const char*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, if</p>

<code>str</code>

<p>is of type</p>

<code>T*</code>

<p>, the return type is</p>

<code>char*</code>

<p>.</p>
</li>
<li>
<p>Otherwise, the behavior is undefined.</p>
</li>
</ul></dd>
</dl>

<p>If a macro definition of each of these generic functions is suppressed to access an actual function (e.g. if</p>

<code>(strstr)</code>

<p>or a function pointer is used), the actual function declaration</p>

(1)

<p>becomes visible.</p></div>

<p>The behavior is undefined if either <code>str</code> or <code>substr</code> is not a pointer to a null-terminated byte string.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>pointer to the null-terminated byte string to examine</td></tr>
<tr><td>substr</td><td>-</td><td>pointer to the null-terminated byte string to search for</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Pointer to the first character of the found substring in <code>str</code>, or a null pointer if such substring is not found. If <code>substr</code> points to an empty string, <code>str</code> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <string.h>
 
void find_str(char const* str, char const* substr)
{
    char const* pos = strstr(str, substr);
    if (pos)
        printf(
            "Found the string [%s] in [%s] at position %td\n",
            substr, str, pos - str
        );
    else
        printf(
            "The string [%s] was not found in [%s]\n",
            substr, str
        );
}
 
int main(void)
{
    char const* str = "one two three";
    find_str(str, "two");
    find_str(str, "");
    find_str(str, "nine");
    find_str(str, "n");
 
    return 0;
}
```

<p>Output:</p>

```text
Found the string [two] in [one two three] at position 4
Found the string [] in [one two three] at position 0
The string [nine] was not found in [one two three]
Found the string [n] in [one two three] at position 1
```
