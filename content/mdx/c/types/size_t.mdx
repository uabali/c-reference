<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

<p class="decl-header">Defined in header <code>&lt;uchar.h&gt;</code></p>

<p class="decl-header">Defined in header <code>&lt;wchar.h&gt;</code></p>

```c
typedef /*implementation-defined*/ size_t;
```

<p><code>size_t</code> is the unsigned integer type of the result of <a href="/reference/c/language/sizeof/"><code>sizeof</code></a>, <a href="/reference/c/types/offsetof/">offsetof</a> and _Alignof<span class="std std-until std-c23">(until C23)</span>alignof<span class="std std-since std-c23">(since C23)</span>, depending on the <a href="/reference/c/language/arithmetic_types/#Data_models">data model</a>.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><p>The bit width of <code>size_t</code> is not less than 16.</p></aside>

<h3 id="Notes">Notes</h3>

<p><code>size_t</code> can store the maximum size of a theoretically possible object of any type (including array).</p>

<p><code>size_t</code> is commonly used for array indexing and loop counting. Programs that use other types, such as <code>unsigned int</code>, for array indexing may fail on, e.g. 64-bit systems when the index exceeds <a href="/reference/c/types/limits/">UINT_MAX</a> or if it relies on 32-bit modular arithmetic.</p>

<h3 id="Possible_implementation">Possible implementation</h3>

<table class="ref-table">
<tr><td>```c
typedef typeof(sizeof(0)) size_t; // valid since C23
```</td></tr>
</table>

<h3 id="Example">Example</h3>

```c
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
 
int main(void)
{
    const size_t N = 101;
    int numbers[N];
    size_t sum = 0;
    for (size_t ndx = 0; ndx < N; ++ndx)
        sum += numbers[ndx] = ndx;
    size_t size = sizeof numbers;
    printf("sum = %zu\n", sum);
    printf("size = %zu\n", size);
    printf("SIZE_MAX = %zu\n", SIZE_MAX);
}
```

<p>Possible output:</p>

```text
sum = 5050
size = 404
SIZE_MAX = 18446744073709551615
```
