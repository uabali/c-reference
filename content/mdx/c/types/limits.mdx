<h4 id="Notes">Notes</h4>

<p>The types of these constants, other than <code>CHAR_BIT</code> and <code>MB_LEN_MAX</code>, are required to match the results of the <a href="/reference/c/language/conversion/#Integer_promotions">integral promotions</a> as applied to objects of the types they describe: <code>CHAR_MAX</code> may have type <code>int</code> or <code>unsigned int</code>, but never <code>char</code>. Similarly <code>USHRT_MAX</code> may not be of an unsigned type: its type may be <code>int</code>.</p>

<p>A freestanding implementation may lack <a href="/reference/c/program/sig_atomic_t/">sig_atomic_t</a> and/or <code>wint_t</code> typedef names, in which case the <code>SIG_ATOMIC_*</code> and/or <code>WINT_*</code> macros are correspondingly absent.</p>

<h4 id="Example">Example</h4>

```c
#include <limits.h>
#include <stdint.h>
#include <stdio.h>
 
int main(void)
{
    printf("CHAR_BIT       = %d\n", CHAR_BIT);
    printf("MB_LEN_MAX     = %d\n\n", MB_LEN_MAX);
 
    printf("CHAR_MIN       = %+d\n", CHAR_MIN);
    printf("CHAR_MAX       = %+d\n", CHAR_MAX);
    printf("SCHAR_MIN      = %+d\n", SCHAR_MIN);
    printf("SCHAR_MAX      = %+d\n", SCHAR_MAX);
    printf("UCHAR_MAX      = %u\n\n", UCHAR_MAX);
 
    printf("SHRT_MIN       = %+d\n", SHRT_MIN);
    printf("SHRT_MAX       = %+d\n", SHRT_MAX);
    printf("USHRT_MAX      = %u\n\n", USHRT_MAX);
 
    printf("INT_MIN        = %+d\n", INT_MIN);
    printf("INT_MAX        = %+d\n", INT_MAX);
    printf("UINT_MAX       = %u\n\n", UINT_MAX);
 
    printf("LONG_MIN       = %+ld\n", LONG_MIN);
    printf("LONG_MAX       = %+ld\n", LONG_MAX);
    printf("ULONG_MAX      = %lu\n\n", ULONG_MAX);
 
    printf("LLONG_MIN      = %+lld\n", LLONG_MIN);
    printf("LLONG_MAX      = %+lld\n", LLONG_MAX);
    printf("ULLONG_MAX     = %llu\n\n", ULLONG_MAX);
 
    printf("PTRDIFF_MIN    = %td\n", PTRDIFF_MIN);
    printf("PTRDIFF_MAX    = %+td\n", PTRDIFF_MAX);
    printf("SIZE_MAX       = %zu\n", SIZE_MAX);
    printf("SIG_ATOMIC_MIN = %+jd\n",(intmax_t)SIG_ATOMIC_MIN);
    printf("SIG_ATOMIC_MAX = %+jd\n",(intmax_t)SIG_ATOMIC_MAX);
    printf("WCHAR_MIN      = %+jd\n",(intmax_t)WCHAR_MIN);
    printf("WCHAR_MAX      = %+jd\n",(intmax_t)WCHAR_MAX);
    printf("WINT_MIN       = %jd\n", (intmax_t)WINT_MIN);
    printf("WINT_MAX       = %jd\n", (intmax_t)WINT_MAX);
}
```

<span class="std std-since std-c99">(C99)</span></td><td>conversion from <code>long double</code> to decimal with at least <code>DECIMAL_DIG</code> digits and back to <code>long double</code> is the identity conversion: this is the decimal precision required to serialize/deserialize a <code>long double</code>   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_DECIMAL_DIG<br />DBL_DECIMAL_DIG<br />LDBL_DECIMAL_DIG

<span class="std std-since std-c11">(C11)</span></td><td>conversion from <code>float</code>/<code>double</code>/<code>long double</code> to decimal with at least <code>FLT_DECIMAL_DIG</code>/<code>DBL_DECIMAL_DIG</code>/<code>LDBL_DECIMAL_DIG</code> digits and back is the identity conversion: this is the decimal precision required to serialize/deserialize a floating-point value. Defined to at least <code>6</code>, <code>10</code>, and <code>10</code> respectively, or <code>9</code> for IEEE float and <code>17</code> for IEEE double (see also the C++ analog: <a href="https://en.cppreference.com/w/cpp/types/numeric_limits/max_digits10" rel="noreferrer" target="_blank"><code>max_digits10</code></a>)   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_MIN<br />DBL_MIN<br />LDBL_MIN</td><td>minimum, normalized, positive value of <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_TRUE_MIN<br />DBL_TRUE_MIN<br />LDBL_TRUE_MIN

<span class="std std-since std-c11">(C11)</span></td><td>minimum positive value of <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_MAX<br />DBL_MAX<br />LDBL_MAX</td><td>maximum finite value of <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_EPSILON<br />DBL_EPSILON<br />LDBL_EPSILON</td><td>absolute value difference between <code>1.0</code> and the next representable value for <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_DIG<br />DBL_DIG<br />LDBL_DIG</td><td>number of decimal digits that are guaranteed to be preserved in text → <code>float</code>/<code>double</code>/<code>long double</code> → text roundtrip without change due to rounding or overflow (see the C++ analog <a href="https://en.cppreference.com/w/cpp/types/numeric_limits/digits10" rel="noreferrer" target="_blank"><code>digits10</code></a> for detail)   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_MANT_DIG<br />DBL_MANT_DIG<br />LDBL_MANT_DIG</td><td>number of base-<code>FLT_RADIX</code> digits that are in the floating-point mantissa and that can be represented without losing precision for <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>

<tr><td>FLT_MIN_10_EXP<br />DBL_MIN_10_EXP<br />LDBL_MIN_10_EXP</td><td>minimum negative integer such that 10 raised to that power is a normalized <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_MAX_EXP<br />DBL_MAX_EXP<br />LDBL_MAX_EXP</td><td>maximum positive integer such that <code>FLT_RADIX</code> raised by power one less than that integer is a representable finite <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td>FLT_MAX_10_EXP<br />DBL_MAX_10_EXP<br />LDBL_MAX_10_EXP</td><td>maximum positive integer such that 10 raised to that power is a representable finite <code>float</code>, <code>double</code> and <code>long double</code> respectively   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td><a href="/reference/c/types/limits/FLT_ROUNDS/">FLT_ROUNDS</a></td><td>rounding mode of floating-point arithmetic   <span class="mark-note">(macro constant)</span></td></tr>

<h4 id="Example_2">Example</h4>

```c
#include <float.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("DECIMAL_DIG     = %d\n", DECIMAL_DIG);
    printf("FLT_DECIMAL_DIG = %d\n", FLT_DECIMAL_DIG);
    printf("FLT_RADIX       = %d\n", FLT_RADIX);
    printf("FLT_MIN         = %e\n", FLT_MIN);
    printf("FLT_MAX         = %e\n", FLT_MAX);
    printf("FLT_EPSILON     = %e\n", FLT_EPSILON);
    printf("FLT_DIG         = %d\n", FLT_DIG);
    printf("FLT_MANT_DIG    = %d\n", FLT_MANT_DIG);
    printf("FLT_MIN_EXP     = %d\n", FLT_MIN_EXP);
    printf("FLT_MIN_10_EXP  = %d\n", FLT_MIN_10_EXP);
    printf("FLT_MAX_EXP     = %d\n", FLT_MAX_EXP);
    printf("FLT_MAX_10_EXP  = %d\n", FLT_MAX_10_EXP);
    printf("FLT_ROUNDS      = %d\n", FLT_ROUNDS);
    printf("FLT_EVAL_METHOD = %d\n", FLT_EVAL_METHOD);
    printf("FLT_HAS_SUBNORM = %d\n", FLT_HAS_SUBNORM);
}
```
