<p class="decl-header">Defined in header <code>&lt;stddef.h&gt;</code></p>

```c
typedef /*implementation-defined*/ ptrdiff_t;
```

<p><code>ptrdiff_t</code> is the signed integer type of the result of <a href="/reference/c/language/operator_arithmetic/#Pointer_arithmetic">subtracting two pointers</a>.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span> <span class="std std-until std-c23">(until C23)</span></p><p>The bit width of <code>ptrdiff_t</code> is not less than 17.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>The bit width of <code>ptrdiff_t</code> is not less than 16.</p></aside>

<h3 id="Notes">Notes</h3>

<p><code>ptrdiff_t</code> is used for pointer arithmetic and array indexing, if negative values are possible. Programs that use other types, such as <code>int</code>, may fail on, e.g. 64-bit systems when the index exceeds <a href="/reference/c/types/limits/">INT_MAX</a> or if it relies on 32-bit modular arithmetic.</p>

<p>Only pointers to elements of the same array (including the pointer one past the end of the array) may be subtracted from each other.</p>

<p>If an array is so large (greater than <a href="/reference/c/types/limits/">PTRDIFF_MAX</a> elements, but equal to or less than <a href="/reference/c/types/limits/">SIZE_MAX</a> bytes), that the difference between two pointers may not be representable as <code>ptrdiff_t</code>, the result of subtracting two such pointers is undefined.</p>

<p>For char arrays shorter than <a href="/reference/c/types/limits/">PTRDIFF_MAX</a>, <code>ptrdiff_t</code> acts as the signed counterpart of <a href="/reference/c/types/size_t/">size_t</a>: it can store the size of the array of any type and is, on most platforms, synonymous with <code>intptr_t</code>).</p>

<h3 id="Possible_implementation">Possible implementation</h3>

<table class="ref-table">
<tr><td>```c
typedef typeof((int*)nullptr - (int*)nullptr) ptrdiff_t; // valid since C23
```</td></tr>
</table>

<h3 id="Example">Example</h3>

```c
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
 
int main(void)
{
    const size_t N = 100;
    int numbers[N];
 
    printf("PTRDIFF_MAX = %ld\n", PTRDIFF_MAX);
    int *p1 = &numbers[18], *p2 = &numbers[23];
    ptrdiff_t diff = p2 - p1;
    printf("p2-p1 = %td\n", diff);
}
```

<p>Possible output:</p>

```text
PTRDIFF_MAX = 9223372036854775807
p2-p1 = 5
```
