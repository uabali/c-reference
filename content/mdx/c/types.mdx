<h3 id="Notes">Notes</h3>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span> <span class="std std-until std-c23">(until C23)</span></p><p>The type of <code>true</code> and <code>false</code> is <code>int</code> rather than <code>_Bool</code>.</p>

<p>A program may undefine and perhaps then redefine the macros <code>bool</code>, <code>true</code> and <code>false</code>. However, such ability is a deprecated feature.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>The type of <code>true</code> and <code>false</code> is <code>bool</code>. It is unspecified whether any of <code>bool</code>, <code>_Bool</code>, <code>true</code>, or <code>false</code> is implemented as a predefined macro.</p>

<p>If <code>bool</code>, <code>true</code>, or <code>false</code> (but not <code>_Bool</code>) is defined as a predefined macro, a program may undefine and perhaps redefine it.</p></aside>

<h3 id="Example">Example</h3>

```c
#include <stdalign.h>
#include <stdbool.h>
#include <stdio.h>
 
int main(void)
{
    printf("%d %d %d\n", true && false, true || false, !false);
    printf("%d %d\n", true ^ true, true + true);
    printf("%zu\n", alignof(short));
}
```

<p>Possible output:</p>

```text
0 1 1
0 2
2
```
