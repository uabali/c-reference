<p>The preprocessor is executed at <a href="/reference/c/language/translation_phases/#Phase_4">translation phase 4</a>, before the compilation. The result of preprocessing is a single file which is then passed to the actual compiler.</p>

<h3 id="Directives">Directives</h3>

<p>The preprocessing directives control the behavior of the preprocessor. Each directive occupies one line and has the following format:</p>

<ul>
<li>
<code>#</code>

<p>character</p>
</li>
<li>
<p>preprocessing instruction (one of</p>

<code>define</code>

<p>,</p>

<code>undef</code>

<p>,</p>

<code>include</code>

<p>,</p>

<code>if</code>

<p>,</p>

<code>ifdef</code>

<p>,</p>

<code>ifndef</code>

<p>,</p>

<code>else</code>

<p>,</p>

<code>elif</code>

, <code>elifdef</code>, <code>elifndef</code><span class="std std-since std-c23">(since C23)</span>

<p>,</p>

<code>endif</code>

<p>,</p>

<code>line</code>

, <code>embed</code><span class="std std-since std-c23">(since C23)</span>

<p>,</p>

<code>error</code>

, <code>warning</code><span class="std std-since std-c23">(since C23)</span>

<p>,</p>

<code>pragma</code>

<p>)</p>

<sup><a href="/reference/c/preprocessor/#cite_note-1">[1]</a></sup>
</li>
<li>
<p>arguments (depends on the instruction)</p>
</li>
<li>
<p>line break.</p>
</li>
</ul>

<p>The null directive (<code>#</code> followed by a line break) is allowed and has no effect.</p>

<h3 id="Capabilities">Capabilities</h3>

<p>The preprocessor has the source file translation capabilities:</p>

<ul>
<li>
<strong><a href="/reference/c/preprocessor/conditional/">conditionally</a></strong>

<p>compile of parts of source file (controlled by directive</p>

<code>#if</code>

<p>,</p>

<code>#ifdef</code>

<p>,</p>

<code>#ifndef</code>

<p>,</p>

<code>#else</code>

<p>,</p>

<code>#elif</code>

, <code>#elifdef</code>, <code>#elifndef</code><span class="std std-since std-c23">(since C23)</span>

<p>and</p>

<code>#endif</code>

<p>).</p>
</li>
<li>
<strong><a href="/reference/c/preprocessor/replace/">replace</a></strong>

<p>text macros while possibly concatenating or quoting identifiers (controlled by directives</p>

<code>#define</code>

<p>and</p>

<code>#undef</code>

<p>, and operators</p>

<code>#</code>

<p>and</p>

<code>##</code>

<p>)</p>
</li>
<li>
<strong><a href="/reference/c/preprocessor/include/">include</a></strong>

<p>other files (controlled by directive</p>

<code>#include</code>

and checked with <code>__has_include</code><span class="std std-since std-c23">(since C23)</span>

<p>)</p>
</li>
<li>
<p>cause an</p>

<strong><a href="/reference/c/preprocessor/error/">error</a></strong>

or <strong><a href="/reference/c/preprocessor/error/">warning</a></strong><span class="std std-since std-c23">(since C23)</span>

<p>(controlled by directive</p>

<code>#error</code>

or <code>#warning</code> respectively<span class="std std-since std-c23">(since C23)</span>

<p>)</p>
</li>
</ul>

<p>The following aspects of the preprocessor can be controlled:</p>

<ul>
<li>
<strong><a href="/reference/c/preprocessor/impl/">implementation defined</a></strong>

<p>behavior (controlled by directive</p>

<code>#pragma</code>

and operator <code>_Pragma</code><span class="std std-since std-c99">(since C99)</span>

<p>)</p>
</li>
<li>
<strong><a href="/reference/c/preprocessor/line/">file name and line information</a></strong>

<p>available to the preprocessor (controlled by directives</p>

<code>#line</code>

<p>)</p>
</li>
</ul>

<h3 id="Footnotes">Footnotes</h3>

<ol>
<li>
<a href="/reference/c/preprocessor/#cite_ref-1">↑</a>

These are the directives defined by the standard. The standard does not define behavior for other directives: they might be ignored, have some useful meaning, or make the program ill-formed. Even if otherwise ignored, they are removed from the source code when the preprocessor is done. A common non-standard extension is the directive <a href="/reference/c/preprocessor/error/">#warning</a> which emits a user-defined message during compilation.<span class="std std-until std-c23">(until C23)</span>
</li>
</ol>
