<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

```c
size_t strftime( char*          str, size_t count,
                 const char*          format, const struct tm*          tp );
```

<p class="decl-note"><span class="std std-until std-c99">(until C99)</span></p>

```c
size_t strftime( char* restrict str, size_t count,
                 const char* restrict format, const struct tm* restrict tp );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Converts the date and time information from a given calendar time <code>tp</code> to a null-terminated multibyte character string <code>str</code> according to <a href="/reference/c/chrono/strftime/#Format_string">format string</a> <code>format</code>. Up to <code>count</code> bytes are written.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str</td><td>-</td><td>pointer to the first element of the char array for output</td></tr>
<tr><td>count</td><td>-</td><td>maximum number of bytes to write</td></tr>
<tr><td>format</td><td>-</td><td>pointer to a null-terminated multibyte character string specifying the <a href="/reference/c/chrono/strftime/#Format_string">format of conversion</a></td></tr>
<tr><td>tp</td><td>-</td><td>pointer to a <code>struct tm</code> object specifying the time to format</td></tr>
</table>

<h3 id="Format_string">Format string</h3>

<p>The format string consists of zero or more conversion specifiers and ordinary characters (except <code>%</code>). All ordinary characters, including the terminating null character, are copied to the output string without modification. Each conversion specification begins with <code>%</code> character, optionally followed by <code>E</code> or <code>O</code> modifier (ignored if unsupported by the locale), followed by the character that determines the behavior of the specifier. The following format specifiers are available:</p>

<h3 id="Return_value">Return value</h3>

<p>The number of bytes written into the character array pointed to by <code>str</code> not including the terminating <code>&#x27;\0&#x27;</code> on success. If <code>count</code> was reached before the entire string could be stored, <code>0</code> is returned and the contents are indeterminate.</p>

<h3 id="Example">Example</h3>

```c
#include <locale.h>
#include <stdio.h>
#include <time.h>
 
int main(void)
{
    char buff[70];
    struct tm my_time = { .tm_year=112, // = year 2012
                          .tm_mon=9,    // = 10th month
                          .tm_mday=9,   // = 9th day
                          .tm_hour=8,   // = 8 hours
                          .tm_min=10,   // = 10 minutes
                          .tm_sec=20    // = 20 secs
    };
 
    if (strftime(buff, sizeof buff, "%A %c", &my_time))
        puts(buff);
    else
        puts("strftime failed");
 
    setlocale(LC_TIME, "el_GR.utf8");
 
    if (strftime(buff, sizeof buff, "%A %c", &my_time))
        puts(buff);
    else
        puts("strftime failed");
}
```

<p>Possible output:</p>

```text
Sunday Sun Oct  9 08:10:20 2012
Κυριακή Κυρ 09 Οκτ 2012 08:10:20 πμ EST
```
