<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

<p class="decl-note">(1)</p>

```c
char*                ctime( const time_t* timer );
```

<p class="decl-note"><span class="std std-until std-c23">(until C23)</span></p>

```c
[[deprecated]] char* ctime( const time_t* timer );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

```c
errno_t ctime_s( char *buf, rsize_t bufsz, const time_t* timer );
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Converts given time since epoch to a calendar local time and then to a textual representation, as if by calling <code>asctime(localtime(timer))</code> or <code>asctime(localtime_r(timer, &amp;(struct tm){0}))</code><span class="std std-since std-c23">(since C23)</span>. This function is deprecated and should not be used in new code.<span class="std std-since std-c23">(since C23)</span></p>

<div class="li-note"><span class="li-num">2)</span>

<p>Same as</p>

(1)

<p>, except that the function is equivalent to</p>

<code>asctime_s(buf, bufsz, localtime_s(timer, &amp;(struct tm){0}))</code>

<p>, and the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>buf</code>

<p>or</p>

<code>timer</code>

<p>is a null pointer</p>
</li>
<li>
<code>bufsz</code>

<p>is less than</p>

<code>26</code>

<p>or greater than</p>

RSIZE_MAX
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>ctime_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/chrono/"><code>&lt;time.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>timer</td><td>-</td><td>pointer to a <a href="/reference/c/chrono/time_t/">time_t</a> object specifying the time to print</td></tr>
<tr><td>buf</td><td>-</td><td>pointer to the first element of a char array of size at least <code>bufsz</code></td></tr>
<tr><td>bufsz</td><td>-</td><td>max number of bytes to output, typically the size of the buffer pointed to by <code>buf</code></td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  pointer to a static null-terminated character string holding the textual representation of date and time. The string may be shared between <a href="/reference/c/chrono/asctime/">asctime</a> and <code>ctime</code>, and may be overwritten on each invocation of any of those functions.</p>

<p class="li-note"><span class="li-num">2)</span>  zero on success (in which case the string representation of time has been written out to the array pointed to by <code>buf</code>), or non-zero on failure (in which case, the terminating null character is always written to <code>buf[0]</code> unless <code>buf</code> is a null pointer or <code>bufsz</code> is zero or greater than RSIZE_MAX.</p>

<h3 id="Notes">Notes</h3>

<p><code>ctime</code> returns a pointer to static data and is not thread-safe. In addition, it modifies the static <a href="/reference/c/chrono/tm/">tm</a> object which may be shared with <a href="/reference/c/chrono/gmtime/">gmtime</a> and <a href="/reference/c/chrono/localtime/">localtime</a>. POSIX marks this function obsolete and recommends <a href="/reference/c/chrono/strftime/">strftime</a> instead. The C standard also recommends <a href="/reference/c/chrono/strftime/">strftime</a> instead of <code>ctime</code> and <code>ctime_s</code> because <code>strftime</code> is more flexible and locale-sensitive.</p>

<p>The behavior of <code>ctime</code> is undefined for the values of <a href="/reference/c/chrono/time_t/">time_t</a> that result in the string longer than 25 characters (e.g. year 10000).</p>

<h3 id="Example">Example</h3>

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <time.h>
#include <stdio.h>
 
int main(void)
{
    time_t result = time(NULL);
    printf("%s", ctime(&result));
 
#ifdef __STDC_LIB_EXT1__
    char str[26];
    ctime_s(str,sizeof str,&result);
    printf("%s", str);
#endif
}
```

<p>Possible output:</p>

```text
Tue May 26 21:51:03 2015
Tue May 26 21:51:03 2015
```
