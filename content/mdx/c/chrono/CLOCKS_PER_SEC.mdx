<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

```c
#define CLOCKS_PER_SEC /* implementation-defined */
```

<p>Expands to an expression (not necessarily a compile-time constant) of type <a href="/reference/c/chrono/clock_t/">clock_t</a> equal to the number of clock ticks per second, as returned by <a href="/reference/c/chrono/clock/">clock()</a>.</p>

<h3 id="Notes">Notes</h3>

<p>POSIX defines <a href="https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/time.h.html" rel="noreferrer" target="_blank"><code>CLOCKS_PER_SEC</code></a> as <code>1&#x27;000&#x27;000</code>, regardless of the actual precision of <a href="/reference/c/chrono/clock/">clock</a>.</p>

<p>Until standardized as <code>CLOCKS_PER_SEC</code> in C89, this macro was sometimes known by its IEEE std 1003.1-1988 name <code>CLK_TCK</code>: that name was not included in C89 and was removed from POSIX itself in 1996 over ambiguity with <code>_SC_CLK_TCK</code>, which gives number of clocks per second for the function <a href="https://pubs.opengroup.org/onlinepubs/9799919799/functions/times.html" rel="noreferrer" target="_blank"><code>times</code></a>).</p>
