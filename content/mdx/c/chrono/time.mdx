<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

```c
time_t time( time_t* arg );
```

<p>Returns the current calendar time encoded as a <a href="/reference/c/chrono/time_t/">time_t</a> object, and also stores it in the <a href="/reference/c/chrono/time_t/">time_t</a> object pointed to by <code>arg</code> (unless <code>arg</code> is a null pointer)</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>pointer to a <a href="/reference/c/chrono/time_t/">time_t</a> object where the time will be stored, or a null pointer</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Current calendar time encoded as <a href="/reference/c/chrono/time_t/">time_t</a> object on success, <code>(time_t)(-1)</code> on error. If <code>arg</code> is not a null pointer, the return value is also stored in the object pointed to by <code>arg</code>.</p>

<h3 id="Notes">Notes</h3>

<p>The encoding of calendar time in <a href="/reference/c/chrono/time_t/">time_t</a> is unspecified, but most systems conform to <a href="https://pubs.opengroup.org/onlinepubs/9799919799/functions/time.html" rel="noreferrer" target="_blank">POSIX specification</a> and return a value of integral type holding the number of seconds since <a href="https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap04.html#tag_04_15" rel="noreferrer" target="_blank">the Epoch</a>. Implementations in which <a href="/reference/c/chrono/time_t/">time_t</a> is a 32-bit signed integer (many historical implementations) fail in the year <a href="https://en.wikipedia.org/wiki/Year_2038_problem" rel="noreferrer" target="_blank">2038</a>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdint.h>
#include <stdio.h>
#include <time.h>
 
int main(void)
{
    time_t result = time(NULL);
    if (result != (time_t)(-1))
        printf("The current time is %s(%jd seconds since the Epoch)\n",
               asctime(gmtime(&result)), (intmax_t)result);
}
```

<p>Possible output:</p>

```text
The current time is Fri Apr 24 15:05:25 2015
(1429887925 seconds since the Epoch)
```
