<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

```c
struct tm;
```

<p>Structure holding a calendar date and time broken down into its components.</p>

<h6 id="Notes">Notes</h6>

<p>The Standard mandates only the presence of the aforementioned members in either order. The implementations usually add more data-members to this structure.</p>

<ol>
<li>
<a href="/reference/c/chrono/tm/#cite_ref-leapsecond_1-0">↑</a>

Range allows for a positive leap second. Two leap seconds in the same minute are not allowed (the C89 range 0..61 was a defect)
</li>
</ol>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <time.h>
 
int main(void)
{
    struct tm start = {.tm_year = 2022 - 1900, .tm_mday = 1};
    mktime(&start);
    printf("%s", asctime(&start)); // note implicit trailing '\n'
}
```

<p>Output:</p>

```text
Sat Jan  1 00:00:00 2022
```
