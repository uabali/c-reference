<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

```c
struct tm* gmtime  ( const time_t* timer );
```

<p class="decl-note">(1)</p>

```c
struct tm* gmtime_r( const time_t* timer, struct tm* buf );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

```c
struct tm* gmtime_s( const time_t* restrict timer, struct tm* restrict buf );
```

<p class="decl-note">(3) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Converts given time since epoch (a <a href="/reference/c/chrono/time_t/">time_t</a> value pointed to by <code>timer</code>) into calendar time, expressed in Coordinated Universal Time (UTC) in the <a href="/reference/c/chrono/tm/"><code>struct tm</code></a> format. The result is stored in static storage and a pointer to that static storage is returned.</p>

<p class="li-note"><span class="li-num">2)</span>  Same as (1), except that the function uses user-provided storage <code>buf</code> for the result.</p>

<div class="li-note"><span class="li-num">3)</span>

<p>Same as</p>

(1)

<p>, except that the function uses user-provided storage</p>

<code>buf</code>

<p>for the result and that the following errors are detected at runtime and call the currently installed</p>

<a href="/reference/c/error/set_constraint_handler_s/">constraint handler</a>

<p>function:</p>

<dl>
<dd><ul>
<li>
<code>timer</code>

<p>or</p>

<code>buf</code>

<p>is a null pointer</p>
</li>
</ul></dd>
<dd><p>As with all bounds-checked functions,</p>

<code>gmtime_s</code>

<p>is only guaranteed to be available if</p>

<code>__STDC_LIB_EXT1__</code>

<p>is defined by the implementation and if the user defines</p>

<code>__STDC_WANT_LIB_EXT1__</code>

<p>to the integer constant</p>

<code>1</code>

<p>before including</p>

<a href="/reference/c/chrono/"><code>&lt;time.h&gt;</code></a>

<p>.</p></dd>
</dl></div>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>timer</td><td>-</td><td>pointer to a <a href="/reference/c/chrono/time_t/">time_t</a> object to convert</td></tr>
<tr><td>buf</td><td>-</td><td>pointer to a <code>struct tm</code> object to store the result</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p class="li-note"><span class="li-num">1)</span>  pointer to a static internal <a href="/reference/c/chrono/tm/">tm</a> object on success, or null pointer otherwise. The structure may be shared between <code>gmtime</code>, <a href="/reference/c/chrono/localtime/">localtime</a>, and <a href="/reference/c/chrono/ctime/">ctime</a> and may be overwritten on each invocation.</p>

<p class="li-note"><span class="li-num">2,3)</span>  copy of the <code>buf</code> pointer, or null pointer on error (which may be a runtime constraint violation or a failure to convert the specified time to UTC).</p>

<h3 id="Notes">Notes</h3>

<p><code>gmtime</code> may not be thread-safe.</p>

<p>POSIX requires that <code>gmtime</code> and <code>gmtime_r</code> set <a href="/reference/c/error/errno/">errno</a> to <a href="/reference/c/error/errno_macros/">EOVERFLOW</a> if they fail because the argument is too large.</p>

<p>The implementation of <code>gmtime_s</code> in <a href="https://docs.microsoft.com/en-us/cpp/c-runtime-library/reference/gmtime-s-gmtime32-s-gmtime64-s?view=vs-2019" rel="noreferrer" target="_blank">Microsoft CRT</a> is incompatible with the C standard since it has reversed parameter order.</p>

<h3 id="Example">Example</h3>

```c
#define __STDC_WANT_LIB_EXT1__ 1
#define _XOPEN_SOURCE // for putenv
#include <stdio.h>
#include <stdlib.h>   // for putenv
#include <time.h>
 
int main(void)
{
    time_t t = time(NULL);
    printf("UTC:       %s", asctime(gmtime(&t)));
    printf("local:     %s", asctime(localtime(&t)));
    // POSIX-specific
    putenv("TZ=Asia/Singapore");
    printf("Singapore: %s", asctime(localtime(&t)));
 
#ifdef __STDC_LIB_EXT1__
    struct tm buf;
    char str[26];
    asctime_s(str, sizeof str, gmtime_s(&t, &buf));
    printf("UTC:       %s", str);
    asctime_s(str, sizeof str, localtime_s(&t, &buf));
    printf("local:     %s", str);
#endif
}
```

<p>Possible output:</p>

```text
UTC:       Fri Sep 15 14:22:05 2017
local:     Fri Sep 15 14:22:05 2017
Singapore: Fri Sep 15 22:22:05 2017
UTC:       Fri Sep 15 14:22:05 2017
local:     Fri Sep 15 14:22:05 2017
```
