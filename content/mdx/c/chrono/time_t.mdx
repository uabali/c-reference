<p class="decl-header">Defined in header <code>&lt;time.h&gt;</code></p>

```c
typedef /* unspecified */ time_t;
```

<p>Real arithmetic type capable of representing times.</p>

<p>Although not defined by the C standard, this is almost always an integral value holding the number of seconds (not counting leap seconds) since 00:00, Jan 1 1970 UTC, corresponding to <a href="https://en.wikipedia.org/wiki/Unix_time" rel="noreferrer" target="_blank">POSIX time</a>.</p>

<h3 id="Notes">Notes</h3>

<p>The standard uses the term <em>calendar time</em> when referring to a value of type <strong>time_t</strong>.</p>

<h3 id="Example">Example</h3>

<p>Show the start of the epoch.</p>

```c
#include <stdio.h>
#include <time.h>
#include <stdint.h>
 
int main(void)
{
    time_t epoch = 0;
    printf("%jd seconds since the epoch began\n", (intmax_t)epoch);
    printf("%s", asctime(gmtime(&epoch)));
}
```

<p>Possible output:</p>

```text
0 seconds since the epoch began
Thu Jan  1 00:00:00 1970
```
