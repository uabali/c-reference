<h3 id="Feature_test_macros_for_optional_features">Feature test macros for optional features</h3>

<ul>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_IEC_559__</code></a>

<ul>
<li>
<p>Indicates IEEE-754 binary floating-point arithmetic and required math functions are supported.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_IEC_559_COMPLEX__</code></a>

<ul>
<li>
<p>Indicates IEEE-754 complex arithmetic and required math functions are supported.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_HOSTED__</code></a>

<ul>
<li>
<p>Indicates that the implementation is</p>

<a href="/reference/c/language/conformance/">hosted</a>

<p>.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_ISO_10646__</code></a>

<ul>
<li>
<p>Indicates that Unicode is used by the wide literal encodings and expands to the latest supported revision.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_MB_MIGHT_NEQ_WC__</code></a>

<ul>
<li>
<p>Indicates that there are some characters in the basic character set having different code unit values in</p>

<a href="/reference/c/language/character_constant/">ordinary and wide literal encodings</a>

<p>.</p>
</li>
</ul>
</li>
</ul>
