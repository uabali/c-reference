<p>C includes a variety of utility libraries. These libraries can be broadly divided into two groups:</p>

<ul>
<li>
<p>language support libraries, and</p>
</li>
<li>
<p>general-purpose libraries.</p>
</li>
</ul>

<h2 id="Language_support">Language support</h2>

<p>Language support libraries provide functions that interact closely with language features and support common language idioms.</p>

<h3 id="Type_support"><a href="/reference/c/types/">Type support</a></h3>

<p>Basic types (e.g. <a href="/reference/c/types/size_t/">size_t</a>, <a href="/reference/c/types/NULL/">NULL</a>)</p>

<h3 id="Dynamic_memory_management"><a href="/reference/c/memory/">Dynamic memory management</a></h3>

<p>(e.g. <a href="/reference/c/memory/malloc/">malloc</a>)</p>

<h3 id="Error_handling"><a href="/reference/c/error/">Error handling</a></h3>

<p>Assertions (e.g. <a href="/reference/c/error/assert/">assert</a>)</p>

<h3 id="Variadic_functions"><a href="/reference/c/variadic/">Variadic functions</a></h3>

<p>Support for functions that take an arbitrary number of parameters (via e.g. va_start, va_arg, va_end)</p>

<h2 id="General-purpose_utilities">General-purpose utilities</h2>

<h3 id="Program_utilities"><a href="/reference/c/program/">Program utilities</a></h3>

<p>Termination (e.g. <a href="/reference/c/program/abort/">abort</a>, <a href="/reference/c/program/atexit/">atexit</a>), environment (e.g. <a href="/reference/c/program/system/">system</a>), signals (e.g. <a href="/reference/c/program/raise/">raise</a>)</p>

<h3 id="Date_and_time"><a href="/reference/c/chrono/">Date and time</a></h3>

<p>Time tracking (e.g. <a href="/reference/c/chrono/time/">time</a>, <a href="/reference/c/chrono/clock/">clock</a>)</p>
