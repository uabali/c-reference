<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int tss_set( tss_t tss_id, void *val );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Sets the value of the thread-specific storage identified by <code>tss_id</code> for the current thread to <code>val</code>. Different threads may set different values to the same key.</p>

<p>The destructor, if available, is not invoked.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>tss_id</td><td>-</td><td>thread-specific storage key, obtained from <a href="/reference/c/thread/tss_create/">tss_create</a> and not deleted by <a href="/reference/c/thread/tss_delete/">tss_delete</a></td></tr>
<tr><td>val</td><td>-</td><td>value to set thread-specific storage to</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if successful, <a href="/reference/c/thread/thrd_errors/">thrd_error</a> otherwise.</p>

<h3 id="Notes">Notes</h3>

<p>The POSIX equivalent of this function is <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/pthread_setspecific.html" rel="noreferrer" target="_blank"><code>pthread_setspecific</code></a>.</p>

<p>Typically TSS is used to store pointers to blocks of dynamically allocated memory that have been reserved for use by the calling thread.</p>

<p><code>tss_set</code> may be called in the TSS destructor. If the destructor exits with non-NULL value in the TSS storage, it will be retried by <a href="/reference/c/thread/thrd_exit/">thrd_exit</a> up to <a href="/reference/c/thread/TSS_DTOR_ITERATIONS/">TSS_DTOR_ITERATIONS</a> times, after which the storage will be lost.</p>

<h3 id="Example">Example</h3>

<table class="ref-table">
<tr><td></td><td>This section is incomplete Reason: improve, perhaps look for POSIX examples for inspiration</td></tr>
</table>

```c
int thread_func(void *arg) {
    tss_t key;
    if (thrd_success == tss_create(&key, free)) {
        tss_set(key, malloc(4)); // stores a pointer on TSS
        // ...
    }
} // calls free() for the pointer stored on TSS
```
