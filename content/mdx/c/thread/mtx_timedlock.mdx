<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int mtx_timedlock( mtx_t *restrict mutex,
                   const struct timespec *restrict time_point );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Blocks the current thread until the mutex pointed to by <code>mutex</code> is locked or until the <code>TIME_UTC</code> based absolute calendar time point pointed to by <code>time_point</code> has been reached.</p>

<p>Since this function takes an absolute time, if a duration is required, the calendar time point must be calculated manually.</p>

<p>The behavior is undefined if the current thread has already locked the mutex and the mutex is not recursive.</p>

<p>The behavior is undefined if the mutex does not support timeout.</p>

<p>Prior calls to <a href="/reference/c/thread/mtx_unlock/">mtx_unlock</a> on the same mutex <em>synchronize-with</em> this operation (if this operation succeeds), and all lock/unlock operations on any given mutex form a single total order (similar to the modification order of an atomic)</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>mutex</td><td>-</td><td>pointer to the mutex to lock</td></tr>
<tr><td>time_point</td><td>-</td><td>pointer to the absolute calendar time until which to wait for the timeout</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if successful, <code>thrd_timedout</code> if the timeout time has been reached before the mutex is locked, <a href="/reference/c/thread/thrd_errors/">thrd_error</a> if an error occurs.</p>
