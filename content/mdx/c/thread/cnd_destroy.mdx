<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
void cnd_destroy( cnd_t* cond );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Destroys the condition variable pointed to by <code>cond</code>.</p>

<p>If there are threads waiting on <code>cond</code>, the behavior is undefined.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>cond</td><td>-</td><td>pointer to the condition variable to destroy</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>
