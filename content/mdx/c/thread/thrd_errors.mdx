<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Identifiers for thread states and errors.</p>

<table class="ref-table ref-dsc">
<tr><td>Constant</td><td>Explanation</td></tr>
<tr><td><code>thrd_success</code></td><td>indicates successful return value</td></tr>
<tr><td><code>thrd_nomem</code></td><td>indicates unsuccessful return value due to out of memory condition</td></tr>
<tr><td><code>thrd_timedout</code></td><td>indicates timed out return value</td></tr>
<tr><td><code>thrd_busy</code></td><td>indicates unsuccessful return value due to resource temporary unavailable</td></tr>
<tr><td><code>thrd_error</code></td><td>indicates unsuccessful return value</td></tr>
</table>
