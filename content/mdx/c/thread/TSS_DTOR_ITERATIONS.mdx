<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
#define TSS_DTOR_ITERATIONS /* unspecified */
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Expands to a positive integral <a href="/reference/c/language/constant_expression/">constant expression</a> defining the maximum number of times a destructor for thread-local storage pointer will be called by <a href="/reference/c/thread/thrd_exit/">thrd_exit</a>.</p>

<p>This constant is equivalent to the POSIX <code>PTHREAD_DESTRUCTOR_ITERATIONS</code>.</p>
