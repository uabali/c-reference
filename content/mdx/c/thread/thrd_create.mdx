<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int thrd_create( thrd_t *thr, thrd_start_t func, void *arg );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Creates a new thread executing the function <code>func</code>. The function is invoked as <code>func(arg)</code>.</p>

<p>If successful, the object pointed to by <code>thr</code> is set to the identifier of the new thread.</p>

<p>The completion of this function <em>synchronizes-with</em> the beginning of the thread.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>thr</td><td>-</td><td>pointer to memory location to put the identifier of the new thread</td></tr>
<tr><td>func</td><td>-</td><td>function to execute</td></tr>
<tr><td>arg</td><td>-</td><td>argument to pass to the function</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if the creation of the new thread was successful. Otherwise returns <a href="/reference/c/thread/thrd_errors/">thrd_nomem</a> if there was insufficient amount of memory or <a href="/reference/c/thread/thrd_errors/">thrd_error</a> if another error occurred.</p>

<h3 id="Notes">Notes</h3>

<p>The thread identifiers may be reused for new threads once the thread has finished and joined or detached.</p>

<p>The type <a href="/reference/c/thread/">thrd_start_t</a> is a typedef of <code>int(*)(void*)</code>, which differs from the POSIX equivalent <code>void*(*)(void*)</code></p>

<p>All thread-specific storage values (see <a href="/reference/c/thread/tss_create/">tss_create</a>) are initialized to <a href="/reference/c/types/NULL/">NULL</a>.</p>

<p>Return from the function <code>func</code> is equivalent to calling <a href="/reference/c/thread/thrd_exit/">thrd_exit</a> with the argument equal to the return value of <code>func</code>.</p>
