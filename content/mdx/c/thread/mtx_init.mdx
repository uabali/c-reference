<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int mtx_init( mtx_t* mutex, int type );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Creates a new mutex object with <code>type</code>. The object pointed to by <code>mutex</code> is set to an identifier of the newly created mutex.</p>

<p><code>type</code> must have one of the following values:</p>

<ul>
<li>
<a href="/reference/c/thread/mtx_types/">mtx_plain</a>

<p>- a simple, non-recursive mutex is created.</p>
</li>
<li>
<a href="/reference/c/thread/mtx_types/">mtx_timed</a>

<p>- a non-recursive mutex, that supports timeout, is created.</p>
</li>
<li>
<code>mtx_plain | mtx_recursive</code>

<p>- a recursive mutex is created.</p>
</li>
<li>
<code>mtx_timed | mtx_recursive</code>

<p>- a recursive mutex, that supports timeout, is created.</p>
</li>
</ul>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>mutex</td><td>-</td><td>pointer to the mutex to initialize</td></tr>
<tr><td>type</td><td>-</td><td>the type of the mutex</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if successful, <a href="/reference/c/thread/thrd_errors/">thrd_error</a> otherwise.</p>
