<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
void *tss_get( tss_t tss_key );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Returns the value held in thread-specific storage for the current thread identified by <code>tss_key</code>. Different threads may get different values identified by the same key.</p>

<p>On thread startup (see <a href="/reference/c/thread/thrd_create/">thrd_create</a>), the values associated with all TSS keys are NULL. Different value may be placed in the thread-specific storage with <a href="/reference/c/thread/tss_set/">tss_set</a>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>tss_key</td><td>-</td><td>thread-specific storage key, obtained from <a href="/reference/c/thread/tss_create/">tss_create</a> and not deleted by <a href="/reference/c/thread/tss_delete/">tss_delete</a></td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The value on success, <a href="/reference/c/types/NULL/">NULL</a> on failure.</p>

<h3 id="Notes">Notes</h3>

<p>The POSIX equivalent for this function is <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/pthread_getspecific.html" rel="noreferrer" target="_blank"><code>pthread_getspecific</code></a>.</p>
