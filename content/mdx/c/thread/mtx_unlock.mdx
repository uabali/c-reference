<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int mtx_unlock( mtx_t *mutex );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Unlocks the mutex pointed to by <code>mutex</code>.</p>

<p>The behavior is undefined if the mutex is not locked by the calling thread.</p>

<p>This function <em>synchronizes-with</em> subsequent <a href="/reference/c/thread/mtx_lock/">mtx_lock</a>, <a href="/reference/c/thread/mtx_trylock/">mtx_trylock</a>, or <a href="/reference/c/thread/mtx_timedlock/">mtx_timedlock</a> on the same mutex. All lock/unlock operations on any given mutex form a single total order (similar to the modification order of an atomic).</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>mutex</td><td>-</td><td>pointer to the mutex to unlock</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if successful, <a href="/reference/c/thread/thrd_errors/">thrd_error</a> otherwise.</p>
