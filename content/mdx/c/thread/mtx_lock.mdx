<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int mtx_lock( mtx_t* mutex );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Blocks the current thread until the mutex pointed to by <code>mutex</code> is locked.</p>

<p>The behavior is undefined if the current thread has already locked the mutex and the mutex is not recursive.</p>

<p>Prior calls to <a href="/reference/c/thread/mtx_unlock/">mtx_unlock</a> on the same mutex <em>synchronize-with</em> this operation, and all lock/unlock operations on any given mutex form a single total order (similar to the modification order of an atomic)</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>mutex</td><td>-</td><td>pointer to the mutex to lock</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if successful, <a href="/reference/c/thread/thrd_errors/">thrd_error</a> otherwise.</p>
