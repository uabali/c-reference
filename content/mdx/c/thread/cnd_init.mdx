<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
int cnd_init( cnd_t* cond );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Initializes new condition variable. The object pointed to by <code>cond</code> will be set to value that identifies the condition variable.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>cond</td><td>-</td><td>pointer to a variable to store identifier of the condition variable to</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><a href="/reference/c/thread/thrd_errors/">thrd_success</a> if the condition variable was successfully created. Otherwise returns <a href="/reference/c/thread/thrd_errors/">thrd_nomem</a> if there was insufficient amount of memory or <code>thrd_error</code> if another error occurred.</p>
