<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
void call_once( once_flag* flag, void (*func)(void) );
```

<p class="decl-note">(1) <span class="std std-since std-c11">(since C11)</span></p>

```c
typedef /* unspecified */ once_flag
```

<p class="decl-note">(2) <span class="std std-since std-c11">(since C11)</span></p>

```c
#define ONCE_FLAG_INIT /* unspecified */
```

<p class="decl-note">(3) <span class="std std-since std-c11">(since C11)</span></p>

<p class="li-note"><span class="li-num">1)</span>  Calls function <code>func</code> exactly once, even if invoked from several threads. The completion of the function <code>func</code> synchronizes with all previous or subsequent calls to <code>call_once</code> with the same <code>flag</code> variable.</p>

<p class="li-note"><span class="li-num">2)</span>  Complete object type capable of holding a flag used by <code>call_once</code>.</p>

<p class="li-note"><span class="li-num">3)</span>  Expands to a value that can be used to initialize an object of type <code>once_flag</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>flag</td><td>-</td><td>pointer to an object of type <code>call_once</code> that is used to ensure <code>func</code> is called only once</td></tr>
<tr><td>func</td><td>-</td><td>the function to execute only once</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Notes">Notes</h3>

<p>The POSIX equivalent of this function is <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/pthread_once.html" rel="noreferrer" target="_blank"><code>pthread_once</code></a>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <threads.h>
 
void do_once(void) {
    puts("called once");
}
 
static once_flag flag = ONCE_FLAG_INIT;
int func(void* data)
{
    call_once(&flag, do_once);
}
 
int main(void)
{
    thrd_t t1, t2, t3, t4;
    thrd_create(&t1, func, NULL);
    thrd_create(&t2, func, NULL);
    thrd_create(&t3, func, NULL);
    thrd_create(&t4, func, NULL);
 
    thrd_join(t1, NULL);
    thrd_join(t2, NULL);
    thrd_join(t3, NULL);
    thrd_join(t4, NULL);
}
```

<p>Output:</p>

```text
called once
```
