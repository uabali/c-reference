<p class="decl-header">Defined in header <code>&lt;threads.h&gt;</code></p>

```c
_Noreturn void thrd_exit( int res );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span>  <span class="std std-until std-c23">(until C23)</span></p>

```c
[[noreturn]] void thrd_exit( int res );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>First, for every thread-specific storage key which was created with a non-null destructor and for which the associated value is non-null (see <a href="/reference/c/thread/tss_create/">tss_create</a>), <code>thrd_exit</code> sets the value associated with the key to <code>NULL</code> and then invokes the destructor with the previous value of the key. The order in which the destructors are invoked is unspecified.</p>

<p>If, after this, there remain keys with both non-null destructors and values (e.g. if a destructor executed <a href="/reference/c/thread/tss_set/">tss_set</a>), the process is repeated up to <a href="/reference/c/thread/TSS_DTOR_ITERATIONS/">TSS_DTOR_ITERATIONS</a> times.</p>

<p>Finally, the <code>thrd_exit</code> function terminates execution of the calling thread and sets its result code to <code>res</code>.</p>

<p>If the last thread in the program is terminated with <code>thrd_exit</code>, the entire program terminates as if by calling <a href="/reference/c/program/exit/">exit</a> with <a href="/reference/c/program/EXIT_status/">EXIT_SUCCESS</a> as the argument (so the functions registered by <a href="/reference/c/program/atexit/">atexit</a> are executed in the context of that last thread)</p>
