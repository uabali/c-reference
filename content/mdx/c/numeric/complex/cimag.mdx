<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float       cimagf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      cimag( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double cimagl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define cimag( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Returns the imaginary part of <code>z</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: if <code>z</code> has type <code>long double complex</code>, <code>long double imaginary</code>, or <code>long double</code>, <code>cimagl</code> is called. If <code>z</code> has type <code>float complex</code>, <code>float imaginary</code>, or <code>float</code>, <code>cimagf</code> is called. If <code>z</code> has type <code>double complex</code>, <code>double imaginary</code>, <code>double</code>, or any integer type, <code>cimag</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>z</td><td>-</td><td>complex argument</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The imaginary part of <code>z</code>.</p>

<p>This function is fully specified for all possible inputs and is not subject to any errors described in <a href="/reference/c/numeric/math/math_errhandling/">math_errhandling</a></p>

<h3 id="Notes">Notes</h3>

<p>For any complex variable <code>z</code>, <code>z == creal(z) + I*cimag(z)</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <complex.h>
 
int main(void)
{    
    double complex z = 1.0 + 2.0*I;
    printf("%f%+fi\n", creal(z), cimag(z));
}
```

<p>Output:</p>

```text
1.000000+2.000000i
```
