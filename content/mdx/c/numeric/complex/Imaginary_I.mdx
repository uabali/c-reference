<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
#define _Imaginary_I /* unspecified */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>The <code>_Imaginary_I</code> macro expands to a value of type <code>const float _Imaginary</code> with the value of the imaginary unit.</p>

<p>As with any pure imaginary number support in C, this macro is only defined if the imaginary numbers are supported.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span> <span class="std std-until std-c11">(until C11)</span></p><p>A compiler that defines <code>__STDC_IEC_559_COMPLEX__</code> is not required to support imaginary numbers. POSIX recommends checking if the macro <code>_Imaginary_I</code> is defined to identify imaginary number support.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p>Imaginary numbers are supported if <code>__STDC_IEC_559_COMPLEX__</code> is defined.</p></aside>

<h3 id="Notes">Notes</h3>

<p>This macro allows for the precise way to assemble a complex number from its real and imaginary components, e.g. with <code>(double complex)((double)x + _Imaginary_I * (double)y)</code>. This pattern was standardized in C11 as the macro <code>CMPLX</code>. Note that if <code>_Complex_I</code> is used instead, this expression is allowed to convert negative zero to positive zero in the imaginary position.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>
 
int main(void)
{
    double complex z1 = 0.0 + INFINITY * _Imaginary_I;
    printf("z1 = %.1f%+.1fi\n", creal(z1), cimag(z1));
 
    double complex z2 = 0.0 + INFINITY * _Complex_I;
    printf("z2 = %.1f%+.1fi\n", creal(z2), cimag(z2));
}
```

<p>Output:</p>

```text
z1 = 0.0+Infi 
z2 = NaN+Infi
```
