<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float complex       cacosf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double complex      cacos( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double complex cacosl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define acos( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the complex arc cosine of <code>z</code> with branch cuts outside the interval [−1,+1] along the real axis.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>z</code> has type <code>long double complex</code>, <code>cacosl</code> is called. if <code>z</code> has type <code>double complex</code>, <code>cacos</code> is called, if <code>z</code> has type <code>float complex</code>, <code>cacosf</code> is called. If <code>z</code> is real or integer, then the macro invokes the corresponding real function (<code>acosf</code>, <code>acos</code>, <code>acosl</code>). If <code>z</code> is imaginary, then the macro invokes the corresponding complex number version.</p>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, complex arc cosine of <code>z</code> is returned, in the range a strip unbounded along the imaginary axis and in the interval [0; π] along the real axis.</p>

<h3 id="Notes">Notes</h3>

<p>Inverse cosine (or arc cosine) is a multivalued function and requires a branch cut on the complex plane. The branch cut is conventially placed at the line segments (-∞,-1) and (1,∞) of the real axis.</p>

<p>The mathematical definition of the principal value of arc cosine is</p>

acos z = 12π + <em>i</em>ln(<em>i</em>z + √1-z2 )

<p>For any z, acos(z) = π - acos(-z)</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <math.h>
#include <complex.h>
 
int main(void)
{
    double complex z = cacos(-2);
    printf("cacos(-2+0i) = %f%+fi\n", creal(z), cimag(z));
 
    double complex z2 = cacos(conj(-2)); // or CMPLX(-2, -0.0)
    printf("cacos(-2-0i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));
 
    // for any z, acos(z) = pi - acos(-z)
    double pi = acos(-1);
    double complex z3 = ccos(pi-z2);
    printf("ccos(pi - cacos(-2-0i) = %f%+fi\n", creal(z3), cimag(z3));
}
```

<p>Output:</p>

```text
cacos(-2+0i) = 3.141593-1.316958i
cacos(-2-0i) (the other side of the cut) = 3.141593+1.316958i
ccos(pi - cacos(-2-0i) = 2.000000+0.000000i
```
