<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
#define _Complex_I /* unspecified */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>The <code>_Complex_I</code> macro expands to a value of type <code>const float _Complex</code> with the value of the imaginary unit.</p>

<h3 id="Notes">Notes</h3>

<p>This macro may be used when I is not available, such as when it has been undefined by the application.</p>

<p>Unlike <a href="/reference/c/numeric/complex/Imaginary_I/">_Imaginary_I</a> and <a href="/reference/c/numeric/complex/CMPLX/">CMPLX</a>, use of this macro to construct a complex number may lose the sign of zero on the imaginary part.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <complex.h>
 
#undef I
#define J _Complex_I // can be used to redefine I
 
int main(void)
{
    // can be used to construct a complex number
    double complex z = 1.0 + 2.0 * _Complex_I;
    printf("1.0 + 2.0 * _Complex_I = %.1f%+.1fi\n", creal(z), cimag(z));
 
    // sign of zero may not be preserved
    double complex z2 = 0.0 + -0.0 * _Complex_I;
    printf("0.0 + -0.0 * _Complex_I = %.1f%+.1fi\n", creal(z2), cimag(z2));
}
```

<p>Possible output:</p>

```text
1.0 + 2.0 * _Complex_I = 1.0+2.0i
0.0 + -0.0 * _Complex_I = 0.0+0.0i
```
