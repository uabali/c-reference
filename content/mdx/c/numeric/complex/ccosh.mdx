<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float complex       ccoshf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double complex      ccosh( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double complex ccoshl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define cosh( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the complex hyperbolic cosine of <code>z</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>z</code> has type <code>long double complex</code>, <code>ccoshl</code> is called. if <code>z</code> has type <code>double complex</code>, <code>ccosh</code> is called, if <code>z</code> has type <code>float complex</code>, <code>ccoshf</code> is called. If <code>z</code> is real or integer, then the macro invokes the corresponding real function (<code>coshf</code>, <code>cosh</code>, <code>coshl</code>). If <code>z</code> is imaginary, then the macro invokes the corresponding real version of the function <a href="/reference/c/numeric/math/cos/">cos</a>, implementing the formula cosh(iy) = cos(y), and the return type is real.</p>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, complex hyperbolic cosine of <code>z</code> is returned</p>

<p>where cis(y) is cos(y) + i sin(y)</p>

<h3 id="Notes">Notes</h3>

<p>Mathematical definition of hyperbolic cosine is</p>

cosh z = ez +e-z 2

<p>Hyperbolic cosine is an entire function in the complex plane and has no branch cuts. It is periodic with respect to the imaginary component, with period 2πi</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <math.h>
#include <complex.h>
 
int main(void)
{
    double complex z = ccosh(1);  // behaves like real cosh along the real line
    printf("cosh(1+0i) = %f%+fi (cosh(1)=%f)\n", creal(z), cimag(z), cosh(1));
 
    double complex z2 = ccosh(I); // behaves like real cosine along the imaginary line
    printf("cosh(0+1i) = %f%+fi ( cos(1)=%f)\n", creal(z2), cimag(z2), cos(1));
}
```

<p>Output:</p>

```text
cosh(1+0i) = 1.543081+0.000000i (cosh(1)=1.543081)
cosh(0+1i) = 0.540302+0.000000i ( cos(1)=0.540302)
```
