<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float       cargf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      carg( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double cargl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define carg( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the argument (also called phase angle) of <code>z</code>, with a branch cut along the negative real axis.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: if <code>z</code> has type <code>long double complex</code>, <code>long double imaginary</code>, or <code>long double</code>, <code>cargl</code> is called. If <code>z</code> has type <code>float complex</code>, <code>float imaginary</code>, or <code>float</code>, <code>cargf</code> is called. If <code>z</code> has type <code>double complex</code>, <code>double imaginary</code>, <code>double</code>, or any integer type, <code>carg</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>z</td><td>-</td><td>complex argument</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, returns the phase angle of <code>z</code> in the interval [−π; π].</p>

<p>Errors and special cases are handled as if the function is implemented as <code>atan2(cimag(z), creal(z))</code></p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <complex.h>
 
int main(void) 
{
    double complex z1 = 1.0+0.0*I;
    printf("phase angle of %.1f%+.1fi is %f\n", creal(z1), cimag(z1), carg(z1));
 
    double complex z2 = 0.0+1.0*I;
    printf("phase angle of %.1f%+.1fi is %f\n", creal(z2), cimag(z2), carg(z2));
 
    double complex z3 = -1.0+0.0*I;
    printf("phase angle of %.1f%+.1fi is %f\n", creal(z3), cimag(z3), carg(z3));
 
    double complex z4 = conj(z3); // or CMPLX(-1, -0.0)
    printf("phase angle of %.1f%+.1fi (the other side of the cut) is %f\n",
             creal(z4), cimag(z4), carg(z4));
}
```

<p>Output:</p>

```text
phase angle of 1.0+0.0i is 0.000000
phase angle of 0.0+1.0i is 1.570796
phase angle of -1.0+0.0i is 3.141593
phase angle of -1.0-0.0i (the other side of the cut) is -3.141593
```
