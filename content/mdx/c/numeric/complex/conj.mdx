<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float complex       conjf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double complex      conj( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double complex conjl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define conj( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the <a href="https://en.wikipedia.org/wiki/Complex_conjugate" rel="noreferrer" target="_blank">complex conjugate</a> of <code>z</code> by reversing the sign of the imaginary part.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: if <code>z</code> has type <code>long double complex</code>, <code>long double imaginary</code>, or <code>long double</code>, <code>conjl</code> is called. If <code>z</code> has type <code>float complex</code>, <code>float imaginary</code>, or <code>float</code>, <code>conjf</code> is called. If <code>z</code> has type <code>double complex</code>, <code>double imaginary</code>, <code>double</code>, or any integer type, <code>conj</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>z</td><td>-</td><td>complex argument</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The complex conjugate of <code>z</code>.</p>

<h3 id="Notes">Notes</h3>

<p>On C99 implementations that do not implement I as <a href="/reference/c/numeric/complex/Imaginary_I/">_Imaginary_I</a>, <code>conj</code> may be used to obtain complex numbers with negative zero imaginary part. In C11, the macro <a href="/reference/c/numeric/complex/CMPLX/">CMPLX</a> is used for that purpose.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <complex.h>
 
int main(void)
{
    double complex z = 1.0 + 2.0*I;
    double complex z2 = conj(z);
    printf("The conjugate of %.1f%+.1fi is %.1f%+.1fi\n",
            creal(z), cimag(z), creal(z2), cimag(z2));
 
    printf("Their product is %.1f%+.1fi\n", creal(z*z2), cimag(z*z2));
}
```

<p>Output:</p>

```text
The conjugate of 1.0+2.0i is 1.0-2.0i
Their product is 5.0+0.0i
```
