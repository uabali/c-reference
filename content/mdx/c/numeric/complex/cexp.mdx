<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float complex       cexpf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double complex      cexp( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double complex cexpl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define exp( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the complex base-<em>e</em> exponential of <code>z</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>z</code> has type <code>long double complex</code>, <code>cexpl</code> is called. if <code>z</code> has type <code>double complex</code>, <code>cexp</code> is called, if <code>z</code> has type <code>float complex</code>, <code>cexpf</code> is called. If <code>z</code> is real or integer, then the macro invokes the corresponding real function (<code>expf</code>, <code>exp</code>, <code>expl</code>). If <code>z</code> is imaginary, the corresponding complex argument version is called.</p>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, <em>e</em> raised to the power of <code>z</code>, \(\small e^z\)ez  is returned.</p>

<p>where \(\small{\rm cis}(y)\)cis(y) is \(\small \cos(y)+{\rm i}\sin(y)\)cos(y) + i sin(y)</p>

<h3 id="Notes">Notes</h3>

<p>The complex exponential function \(\small e^z\)ez  for \(\small z = x + {\rm i}y\)z = x+iy equals \(\small e^x {\rm cis}(y)\)ex  cis(y), or, \(\small e^x (\cos(y)+{\rm i}\sin(y))\)ex  (cos(y) + i sin(y))</p>

<p>The exponential function is an <em>entire function</em> in the complex plane and has no branch cuts.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <math.h>
#include <complex.h>
 
int main(void)
{
    double PI = acos(-1);
    double complex z = cexp(I * PI); // Euler's formula
    printf("exp(i*pi) = %.1f%+.1fi\n", creal(z), cimag(z));
 
}
```

<p>Output:</p>

```text
exp(i*pi) = -1.0+0.0i
```
