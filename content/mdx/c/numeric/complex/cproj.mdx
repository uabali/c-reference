<p class="decl-header">Defined in header <code>&lt;complex.h&gt;</code></p>

```c
float complex       cprojf( float complex z );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double complex      cproj( double complex z );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double complex cprojl( long double complex z );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define cproj( z )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the projection of <code>z</code> on the Riemann sphere.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: if <code>z</code> has type <code>long double complex</code>, <code>long double imaginary</code>, or <code>long double</code>, <code>cprojl</code> is called. If <code>z</code> has type <code>float complex</code>, <code>float imaginary</code>, or <code>float</code>, <code>cprojf</code> is called. If <code>z</code> has type <code>double complex</code>, <code>double imaginary</code>, <code>double</code>, or any integer type, <code>cproj</code> is called.</p>

<p>For most <code>z</code>, <code>cproj(z)==z</code>, but all complex infinities, even the numbers where one component is infinite and the other is NaN, become positive real infinity, <code>INFINITY+0.0*I</code> or <code>INFINITY-0.0*I</code>. The sign of the imaginary (zero) component is the sign of <code>cimag(z)</code>.</p>

<table class="ref-table ref-params">
<tr><td>z</td><td>-</td><td>complex argument</td></tr>

<h3 id="Return_value">Return value</h3>

<p>The projection of <code>z</code> on the Riemann sphere.</p>

<p>This function is fully specified for all possible inputs and is not subject to any errors described in <a href="/reference/c/numeric/math/math_errhandling/">math_errhandling</a></p>

<h3 id="Notes">Notes</h3>

<p>The <code>cproj</code> function helps model the Riemann sphere by mapping all infinities to one (give or take the sign of the imaginary zero), and should be used just before any operation, especially comparisons, that might give spurious results for any of the other infinities.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>
 
int main(void)
{
    double complex z1 = cproj(1 + 2*I);
    printf("cproj(1+2i) = %.1f%+.1fi\n", creal(z1),cimag(z1));
 
    double complex z2 = cproj(INFINITY+2.0*I);
    printf("cproj(Inf+2i) = %.1f%+.1fi\n", creal(z2),cimag(z2));
 
    double complex z3 = cproj(INFINITY-2.0*I);
    printf("cproj(Inf-2i) = %.1f%+.1fi\n", creal(z3),cimag(z3));
}
```

<p>Output:</p>

```text
cproj(1+2i) = 1.0+2.0i
cproj(Inf+2i) = inf+0.0i
cproj(Inf-2i) = inf-0.0i
```
