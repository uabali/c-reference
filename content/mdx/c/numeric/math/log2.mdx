<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       log2f( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      log2( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double log2l( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define log2( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the base <code>2</code> logarithm of <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>log2l</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>log2</code> is called. Otherwise, <code>log2f</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the base-<em>2</em> logarithm of <code>arg</code> (log2(arg) or lb(arg)) is returned.</p>

<p>If a domain error occurs, an implementation-defined value is returned (NaN where supported).</p>

<p>If a pole error occurs, <a href="/reference/c/numeric/math/HUGE_VAL/">-HUGE_VAL</a>, <code>-HUGE_VALF</code>, or <code>-HUGE_VALL</code> is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>Domain error occurs if <code>arg</code> is less than zero.</p>

<p>Pole error may occur if <code>arg</code> is zero.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If the argument is ±0, -∞ is returned and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_DIVBYZERO</a>

<p>is raised.</p>
</li>
<li>
<p>If the argument is 1, +0 is returned</p>
</li>
<li>
<p>If the argument is negative, NaN is returned and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INVALID</a>

<p>is raised.</p>
</li>
<li>
<p>If the argument is +∞, +∞ is returned</p>
</li>
<li>
<p>If the argument is NaN, NaN is returned</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>For integer <code>arg</code>, the binary logarithm can be interpreted as the zero-based index of the most significant 1 bit in the input.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <math.h>
#include <float.h>
#include <errno.h>
#include <fenv.h>
// #pragma STDC FENV_ACCESS ON
int main(void)
{
    printf("log2(65536) = %f\n", log2(65536));
    printf("log2(0.125) = %f\n", log2(0.125));
    printf("log2(0x020f) = %f (highest set bit is in position 9)\n", log2(0x020f));
    printf("base-5 logarithm of 125 = %f\n", log2(125)/log2(5));
    // special values
    printf("log2(1) = %f\n", log2(1));
    printf("log2(+Inf) = %f\n", log2(INFINITY));
    //error handling
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("log2(0) = %f\n", log2(0));
    if(errno == ERANGE) perror("    errno == ERANGE");
    if(fetestexcept(FE_DIVBYZERO)) puts("    FE_DIVBYZERO raised");
}
```

<p>Possible output:</p>

```text
log2(65536) = 16.000000
log2(0.125) = -3.000000
log2(0x020f) = 9.041659 (highest set bit is in position 9)
base-5 logarithm of 125 = 3.000000
log2(1) = 0.000000
log2(+Inf) = inf
log2(0) = -inf
    errno == ERANGE: Numerical result out of range
    FE_DIVBYZERO raised
```
