<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       atanhf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      atanh( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double atanhl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define atanh( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the inverse hyperbolic tangent of <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If the argument has type <code>long double</code>, <code>atanhl</code> is called. Otherwise, if the argument has integer type or the type <code>double</code>, <code>atanh</code> is called. Otherwise, <code>atanhf</code> is called. If the argument is complex, then the macro invokes the corresponding complex function (<a href="/reference/c/numeric/complex/catanh/">catanhf</a>, <a href="/reference/c/numeric/complex/catanh/">catanh</a>, <a href="/reference/c/numeric/complex/catanh/">catanhl</a>).</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating_point value representing the area of a hyperbolic sector</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the inverse hyperbolic tangent of <code>arg</code> (tanh-1 (arg), or artanh(arg)), is returned.</p>

<p>If a domain error occurs, an implementation-defined value is returned (NaN where supported).</p>

<p>If a pole error occurs, <code>±HUGE_VAL</code>, <code>±HUGE_VALF</code>, or <code>±HUGE_VALL</code> is returned (with the correct sign).</p>

<p>If a range error occurs due to underflow, the correct result (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the argument is not on the interval <code>[</code><code>-1</code><code>,</code><code>+1</code><code>]</code>, a range error occurs.</p>

<p>If the argument is ±1, a pole error occurs.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If the argument is ±0, it is returned unmodified.</p>
</li>
<li>
<p>If the argument is ±1, ±∞ is returned and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_DIVBYZERO</a>

<p>is raised.</p>
</li>
<li>
<p>If</p>

|arg|&gt;1

<p>, NaN is returned and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INVALID</a>

<p>is raised.</p>
</li>
<li>
<p>If the argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>Although the C standard names this function "arc hyperbolic tangent", the inverse functions of the hyperbolic functions are the area functions. Their argument is the area of a hyperbolic sector, not an arc. The correct name is "inverse hyperbolic tangent" (used by POSIX) or "area hyperbolic tangent".</p>

<p><a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/atanh.html" rel="noreferrer" target="_blank">POSIX specifies</a> that in case of underflow, <code>arg</code> is returned unmodified, and if that is not supported, an implementation-defined value no greater than <a href="/reference/c/types/limits/">DBL_MIN</a>, <a href="/reference/c/types/limits/">FLT_MIN</a>, and <a href="/reference/c/types/limits/">LDBL_MIN</a> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON
 
int main(void)
{
    printf("atanh(0) = %f\natanh(-0) = %f\n", atanh(0), atanh(-0.0));
    printf("atanh(0.9) = %f\n", atanh(0.9));
 
    // error handling
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("atanh(-1) = %f\n", atanh(-1));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
}
```

<p>Possible output:</p>

```text
atanh(0) = 0.000000
atanh(-0) = -0.000000
atanh(0.9) = 1.472219
atanh(-1) = -inf
    errno == ERANGE: Numerical result out of range
    FE_DIVBYZERO raised
```
