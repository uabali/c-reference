<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       asinhf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      asinh( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double asinhl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define asinh( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the inverse hyperbolic sine of <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If the argument has type <code>long double</code>, <code>asinhl</code> is called. Otherwise, if the argument has integer type or the type <code>double</code>, <code>asinh</code> is called. Otherwise, <code>asinhf</code> is called. If the argument is complex, then the macro invokes the corresponding complex function (<a href="/reference/c/numeric/complex/casinh/">casinhf</a>, <a href="/reference/c/numeric/complex/casinh/">casinh</a>, <a href="/reference/c/numeric/complex/casinh/">casinhl</a>).</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value representing the area of a hyperbolic sector</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the inverse hyperbolic sine of <code>arg</code> (sinh-1 (arg), or arsinh(arg)), is returned.</p>

<p>If a range error occurs due to underflow, the correct result (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If the argument is ±0 or ±∞, it is returned unmodified.</p>
</li>
<li>
<p>If the argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>Although the C standard names this function "arc hyperbolic sine", the inverse functions of the hyperbolic functions are the area functions. Their argument is the area of a hyperbolic sector, not an arc. The correct name is "inverse hyperbolic sine" (used by POSIX) or "area hyperbolic sine".</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("asinh(1) = %f\nasinh(-1) = %f\n", asinh(1), asinh(-1));
    // special values
    printf("asinh(+0) = %f\nasinh(-0) = %f\n", asinh(0.0), asinh(-0.0));
}
```

<p>Output:</p>

```text
asinh(1) = 0.881374
asinh(-1) = -0.881374
asinh(+0) = 0.000000
asinh(-0) = -0.000000
```
