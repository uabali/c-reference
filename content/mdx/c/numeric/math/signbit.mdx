<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define signbit( arg ) /* implementation defined */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Determines if the given floating-point number <code>arg</code> is negative. The macro returns an integral value.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Nonzero integral value if <code>arg</code> is negative, <code>0</code> otherwise.</p>

<h3 id="Notes">Notes</h3>

<p>This macro detects the sign bit of zeroes, infinities, and NaNs. Along with <a href="/reference/c/numeric/math/copysign/">copysign</a>, this macro is one of the only two portable ways to examine the sign of a NaN.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("signbit(+0.0) = %d\n", signbit(+0.0));
    printf("signbit(-0.0) = %d\n", signbit(-0.0));
}
```

<p>Possible output:</p>

```text
signbit(+0.0) = 0
signbit(-0.0) = 128
```
