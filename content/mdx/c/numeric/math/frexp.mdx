<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       frexpf( float arg, int* exp );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      frexp( double arg, int* exp );
```

<p class="decl-note">(2)</p>

```c
long double frexpl( long double arg, int* exp );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define frexp( arg, exp )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Decomposes given floating-point value <code>x</code> into a normalized fraction and an integral power of two.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>frexpl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>frexp</code> is called. Otherwise, <code>frexpf</code> is called, respectively.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
<tr><td>exp</td><td>-</td><td>pointer to integer value to store the exponent to</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If <code>arg</code> is zero, returns zero and stores zero in <code>*exp</code>.</p>

<p>Otherwise (if <code>arg</code> is not zero), if no errors occur, returns the value <code>x</code> in the range <code>(-1;-0.5], [0.5; 1)</code> and stores an integer value in <code>*exp</code> such that x×2(*exp) =arg.</p>

<p>If the value to be stored in <code>*exp</code> is outside the range of <code>int</code>, the behavior is unspecified.</p>

<p>If <code>arg</code> is not a floating-point number, the behavior is unspecified.</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any errors specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If</p>

<code>arg</code>

<p>is ±0, it is returned, unmodified, and</p>

<code>0</code>

<p>is stored in</p>

<code>*exp</code>

<p>.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±∞, it is returned, and an unspecified value is stored in</p>

<code>*exp</code>

<p>.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is NaN, NaN is returned, and an unspecified value is stored in</p>

<code>*exp</code>

<p>.</p>
</li>
<li>
<p>No floating-point exceptions are raised.</p>
</li>
<li>
<p>If</p>

<a href="/reference/c/types/limits/">FLT_RADIX</a>

<p>is</p>

<code>2</code>

<p>(or a power of 2), the returned value is exact,</p>

<a href="/reference/c/numeric/fenv/FE_round/">the current rounding mode</a>

<p>is ignored.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>On a binary system (where <a href="/reference/c/types/limits/">FLT_RADIX</a> is <code>2</code>), <code>frexp</code> may be implemented as</p>

```c
{
    *exp = (value == 0) ? 0 : (int)(1 + logb(value));
    return scalbn(value, -(*exp));
}
```

<p>The function <code>frexp</code>, together with its dual, <a href="/reference/c/numeric/math/ldexp/">ldexp</a>, can be used to manipulate the representation of a floating-point number without direct bit manipulations.</p>

<h3 id="Example">Example</h3>

```c
#include <float.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    double f = 123.45;
    printf("Given the number %.2f or %a in hex,\n", f, f);
 
    double f3;
    double f2 = modf(f, &f3);
    printf("modf() makes %.0f + %.2f\n", f3, f2);
 
    int i;
    f2 = frexp(f, &i);
    printf("frexp() makes %f * 2^%d\n", f2, i);
 
    i = ilogb(f);
    printf("logb()/ilogb() make %f * %d^%d\n", f/scalbn(1.0, i), FLT_RADIX, i);
}
```

<p>Possible output:</p>

```text
Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
```
