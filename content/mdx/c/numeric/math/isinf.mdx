<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define isinf(arg) /* implementation defined */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Determines if the given floating-point number <code>arg</code> is positive or negative infinity. The macro returns an integral value.</p>

<p><a href="/reference/c/types/limits/FLT_EVAL_METHOD/">FLT_EVAL_METHOD</a> is ignored: even if the argument is evaluated with more range and precision than its type, it is first converted to its semantic type, and the classification is based on that.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Nonzero integral value if <code>arg</code> has an infinite value, <code>0</code> otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <math.h>
#include <float.h>
 
int main(void)
{
    printf("isinf(NAN)         = %d\n", isinf(NAN));
    printf("isinf(INFINITY)    = %d\n", isinf(INFINITY));
    printf("isinf(0.0)         = %d\n", isinf(0.0));
    printf("isinf(DBL_MIN/2.0) = %d\n", isinf(DBL_MIN/2.0));
    printf("isinf(1.0)         = %d\n", isinf(1.0));
    printf("isinf(exp(800))    = %d\n", isinf(exp(800)));
}
```

<p>Possible output:</p>

```text
isinf(NAN)         = 0
isinf(INFINITY)    = 1
isinf(0.0)         = 0
isinf(DBL_MIN/2.0) = 0
isinf(1.0)         = 0
isinf(exp(800))    = 1
```
