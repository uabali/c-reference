<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       erfcf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      erfc( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double erfcl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define erfc( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the <a href="https://en.wikipedia.org/wiki/Complementary_error_function" rel="noreferrer" target="_blank">complementary error function</a> of <code>arg</code>, that is <code>1.0 - erf(arg)</code>, but without loss of precision for large <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>erfcl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>erfc</code> is called. Otherwise, <code>erfcf</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, value of the complementary error function of</p>

<code>arg</code>

<p>, that is</p>

\(\frac{2}{\sqrt{\pi} }\int_{arg}^{\infty}{e^{-{t^2} }\mathsf{d}t}\)

2√π∫∞ arg<em>e</em><sup>-t2 </sup>d<em>t</em>

<p>or</p>

\({\small 1-\operatorname{erf}(arg)}\)

1-erf(arg)

<p>, is returned.</p>

<p>If a range error occurs due to underflow, the correct result (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If the argument is +∞, +0 is returned.</p>
</li>
<li>
<p>If the argument is -∞, 2 is returned.</p>
</li>
<li>
<p>If the argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>For the IEEE-compatible type <code>double</code>, underflow is guaranteed if <code>arg</code> &gt; <code>26.55</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
double normalCDF(double x) // Phi(-∞, x) aka N(x)
{
    return erfc(-x / sqrt(2)) / 2;
}
 
int main(void)
{
    puts("normal cumulative distribution function:");
    for (double n = 0; n < 1; n += 0.1)
        printf("normalCDF(%.2f) %5.2f%%\n", n, 100 * normalCDF(n));
 
    printf("special values:\n"
           "erfc(-Inf) = %f\n"
           "erfc(Inf) = %f\n",
           erfc(-INFINITY),
           erfc(INFINITY));
}
```

```text

normalCDF(0.80) 78.81%
normalCDF(0.90) 81.59%
normalCDF(1.00) 84.13%

erfc(-Inf) = 2.000000
erfc(Inf) = 0.000000
```
