<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       roundevenf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c23">(since C23)</span></p>

```c
double      roundeven( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c23">(since C23)</span></p>

```c
long double roundevenl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c23">(since C23)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define roundeven( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the nearest integer value to <code>arg</code> (in floating-point format), rounding halfway cases to nearest even integer, regardless of the current rounding mode.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>roundevenl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>roundeven</code> is called. Otherwise, <code>roundevenf</code> is called, respectively.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the nearest integer value to <code>arg</code>, rounding halfway cases to nearest even integer, is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any of the errors specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559):</p>

<ul>
<li>
<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>

<p>is never raised.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±∞, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±0, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("roundeven(+2.4) = %+.1f\n", roundeven(2.4));
    printf("roundeven(-2.4) = %+.1f\n", roundeven(-2.4));
    printf("roundeven(+2.5) = %+.1f\n", roundeven(2.5));
    printf("roundeven(-2.5) = %+.1f\n", roundeven(-2.5));
    printf("roundeven(+2.6) = %+.1f\n", roundeven(2.6));
    printf("roundeven(-2.6) = %+.1f\n", roundeven(-2.6));
    printf("roundeven(+3.5) = %+.1f\n", roundeven(3.5));
    printf("roundeven(-3.5) = %+.1f\n", roundeven(-3.5));
    printf("roundeven(-0.0) = %+.1f\n", roundeven(-0.0));
    printf("roundeven(-Inf) = %+f\n",   roundeven(-INFINITY));
}
```

<p>Possible output:</p>

```text
roundeven(+2.4) = +2.0
roundeven(-2.4) = -2.0
roundeven(+2.5) = +2.0
roundeven(-2.5) = -2.0
roundeven(+2.6) = +3.0
roundeven(-2.6) = -3.0
roundeven(+3.5) = +4.0
roundeven(-3.5) = -4.0
roundeven(-0.0) = -0.0
roundeven(-Inf) = -inf
```
