<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       nearbyintf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      nearbyint( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double nearbyintl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define nearbyint( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Rounds the floating-point argument <code>arg</code> to an integer value in floating-point format, using the <a href="/reference/c/numeric/fenv/FE_round/">current rounding mode</a>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>nearbyintl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>nearbyint</code> is called. Otherwise, <code>nearbyintf</code> is called, respectively.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The nearest integer value to <code>arg</code>, according to the <a href="/reference/c/numeric/fenv/FE_round/">current rounding mode</a>, is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any of the errors specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>

<p>is never raised.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±∞, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±0, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>The only difference between <code>nearbyint</code> and <a href="/reference/c/numeric/math/rint/">rint</a> is that <code>nearbyint</code> never raises <a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>.</p>

<p>The largest representable floating-point values are exact integers in all standard floating-point formats, so <code>nearbyint</code> never overflows on its own; however the result may overflow any integer type (including <a href="/reference/c/types/integer/">intmax_t</a>), when stored in an integer variable.</p>

<p>If the current rounding mode is <a href="/reference/c/numeric/fenv/FE_round/">FE_TONEAREST</a>, this function rounds to even in halfway cases (like <a href="/reference/c/numeric/math/rint/">rint</a>, but unlike <a href="/reference/c/numeric/math/round/">round</a>).</p>

<h3 id="Example">Example</h3>

```c
#include <fenv.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
// #pragma STDC FENV_ACCESS ON
    fesetround(FE_TONEAREST);
    printf("rounding to nearest:\nnearbyint(+2.3) = %+.1f  ", nearbyint(2.3));
    printf("nearbyint(+2.5) = %+.1f  ", nearbyint(2.5));
    printf("nearbyint(+3.5) = %+.1f\n", nearbyint(3.5));
    printf("nearbyint(-2.3) = %+.1f  ", nearbyint(-2.3));
    printf("nearbyint(-2.5) = %+.1f  ", nearbyint(-2.5));
    printf("nearbyint(-3.5) = %+.1f\n", nearbyint(-3.5));
 
    fesetround(FE_DOWNWARD);
    printf("rounding down: \nnearbyint(+2.3) = %+.1f  ", nearbyint(2.3));
    printf("nearbyint(+2.5) = %+.1f  ", nearbyint(2.5));
    printf("nearbyint(+3.5) = %+.1f\n", nearbyint(3.5));
    printf("nearbyint(-2.3) = %+.1f  ", nearbyint(-2.3));
    printf("nearbyint(-2.5) = %+.1f  ", nearbyint(-2.5));
    printf("nearbyint(-3.5) = %+.1f\n", nearbyint(-3.5));
 
    printf("nearbyint(-0.0) = %+.1f\n", nearbyint(-0.0));
    printf("nearbyint(-Inf) = %+.1f\n", nearbyint(-INFINITY));
}
```

<p>Output:</p>

```text
rounding to nearest:
nearbyint(+2.3) = +2.0  nearbyint(+2.5) = +2.0  nearbyint(+3.5) = +4.0
nearbyint(-2.3) = -2.0  nearbyint(-2.5) = -2.0  nearbyint(-3.5) = -4.0
rounding down:
nearbyint(+2.3) = +2.0  nearbyint(+2.5) = +2.0  nearbyint(+3.5) = +3.0
nearbyint(-2.3) = -3.0  nearbyint(-2.5) = -3.0  nearbyint(-3.5) = -4.0
nearbyint(-0.0) = -0.0
nearbyint(-Inf) = -inf
```
