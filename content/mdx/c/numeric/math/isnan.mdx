<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define isnan(arg) /* implementation defined */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Determines if the given floating-point number <code>arg</code> is a not-a-number (NaN) value. The macro returns an integral value.</p>

<p><a href="/reference/c/types/limits/FLT_EVAL_METHOD/">FLT_EVAL_METHOD</a> is ignored: even if the argument is evaluated with more range and precision than its type, it is first converted to its semantic type, and the classification is based on that (this matters if the evaluation type supports NaNs, while the semantic type does not).</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Nonzero integral value if <code>arg</code> is a NaN, <code>0</code> otherwise.</p>

<h3 id="Notes">Notes</h3>

<p>There are many different NaN values with different sign bits and payloads, see <a href="/reference/c/numeric/math/nan.2/">nan</a>.</p>

<p>NaN values never compare equal to themselves or to other NaN values. Copying a NaN may change its bit pattern.</p>

<p>Another way to test if a floating-point value is NaN is to compare it with itself: <code>bool is_nan(double x) { return x != x; }</code></p>

<h3 id="Example">Example</h3>

```c
#include <float.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("isnan(NAN)         = %d\n", isnan(NAN));
    printf("isnan(INFINITY)    = %d\n", isnan(INFINITY));
    printf("isnan(0.0)         = %d\n", isnan(0.0));
    printf("isnan(DBL_MIN/2.0) = %d\n", isnan(DBL_MIN / 2.0));
    printf("isnan(0.0 / 0.0)   = %d\n", isnan(0.0 / 0.0));
    printf("isnan(Inf - Inf)   = %d\n", isnan(INFINITY - INFINITY));
}
```

<p>Possible output:</p>

```text
isnan(NAN)         = 1
isnan(INFINITY)    = 0
isnan(0.0)         = 0
isnan(DBL_MIN/2.0) = 0
isnan(0.0 / 0.0)   = 1
isnan(Inf - Inf)   = 1
```
