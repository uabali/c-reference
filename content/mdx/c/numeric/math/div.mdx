<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
div_t     div( int x, int y );
```

<p class="decl-note">(1)</p>

```c
ldiv_t    ldiv( long x, long y );
```

<p class="decl-note">(2)</p>

```c
lldiv_t   lldiv( long long x, long long y );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;inttypes.h&gt;</code></p>

```c
imaxdiv_t imaxdiv( intmax_t x, intmax_t y );
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p>Computes both the quotient and the remainder of the division of the numerator <code>x</code> by the denominator <code>y</code>.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c99">(until C99)</span></p><p>Computes quotient and remainder simultaneously. The quotient is the algebraic quotient with any fractional part discarded (truncated towards zero). The remainder is such that <code>quot * y + rem == x</code>.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><p>Computes the quotient (the result of the expression <code>x / y</code>) and remainder (the result of the expression <code>x % y</code>) simultaneously.</p></aside>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x, y</td><td>-</td><td>integer values</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If both the remainder and the quotient can be represented as objects of the corresponding type (<code>int</code>, <code>long</code>, <code>long long</code>, <code>intmax_t</code>, respectively), returns both as an object of type <code>div_t</code>, <code>ldiv_t</code>, <code>lldiv_t</code>, <code>imaxdiv_t</code> defined as follows:</p>

<h2 id="div_t">div_t</h2>

```c
struct div_t { int quot; int rem; };
```

<p>or</p>

```c
struct div_t { int rem; int quot; };
```

<h2 id="ldiv_t">ldiv_t</h2>

```c
struct ldiv_t { long quot; long rem; };
```

<p>or</p>

```c
struct ldiv_t { long rem; long quot; };
```

<h2 id="lldiv_t">lldiv_t</h2>

```c
struct lldiv_t { long long quot; long long rem; };
```

<p>or</p>

```c
struct lldiv_t { long long rem; long long quot; };
```

<h2 id="imaxdiv_t">imaxdiv_t</h2>

```c
struct imaxdiv_t { intmax_t quot; intmax_t rem; };
```

<p>or</p>

```c
struct imaxdiv_t { intmax_t rem; intmax_t quot; };
```

<p>If either the remainder or the quotient cannot be represented, the behavior is undefined.</p>

<h3 id="Notes">Notes</h3>

<p>Until C99, the rounding direction of the quotient and the sign of the remainder in the built-in division and remainder operators was implementation-defined if either of the operands was negative, but it was well-defined in <code>div</code> and <code>ldiv</code>.</p>

<p>On many platforms, a single CPU instruction obtains both the quotient and the remainder, and this function may leverage that, although compilers are generally able to merge nearby <code>/</code> and <code>%</code> where suitable.</p>

<h3 id="Example">Example</h3>

```c
#include <assert.h>
#include <limits.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
 
void reverse(char* first, char* last)
{
    for (--last; first < last; ++first, --last)
    {
        char c = *last;
        *last = *first;
        *first = c;
    }
}
 
// returns empty buffer in case of buffer overflow
char* itoa(int n, int base, char* buf, size_t buf_size)
{
    assert(2 <= base && base <= 16 && buf && buf_size);
    div_t dv = {.quot = n};
    char* p = buf;
    do
    {
        if (!--buf_size)
            return (*buf = '\0'), buf;
        dv = div(dv.quot, base);
        *p++ = "0123456789abcdef"[abs(dv.rem)];
    }
    while(dv.quot);
    if (n < 0)
        *p++ = '-';
    *p = '\0';
    reverse(buf, p);
    return buf;
}
 
int main(void)
{
    char buf[16];
    printf("%s\n", itoa(0, 2, buf, sizeof buf));
    printf("%s\n", itoa(007, 3, buf, sizeof buf));
    printf("%s\n", itoa(12346, 10, buf, sizeof buf));
    printf("%s\n", itoa(-12346, 10, buf, sizeof buf));
    printf("%s\n", itoa(-42, 2, buf, sizeof buf));
    printf("%s\n", itoa(INT_MAX, 16, buf, sizeof buf));
    printf("%s\n", itoa(INT_MIN, 16, buf, sizeof buf));
}
```

<p>Possible output:</p>

```text
0
21
12346
-12346
-101010
7fffffff
-80000000
```
