<p class="decl-note">(7) <span class="std std-since std-c99">(since C99)</span></p>

<div class="li-note"><span class="li-num">1-6)</span>

<p>Computes the absolute value of a floating-point value</p>

<code>arg</code>

<p>.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>The functions with decimal floating-point parameters are declared if and only if the implementation predefines <code>__STDC_IEC_60559_DFP__</code> (i.e. the implementation supports decimal floating-point numbers).</p></aside></div>

<p class="li-note"><span class="li-num">7)</span>  Type-generic macro: If the argument has type <code>_Decimal128</code>, <code>_Decimal64</code>, <code>_Decimal32</code>,<span class="std std-since std-c23">(since C23)</span><code>long double</code>, <code>double</code>, or <code>float</code>, <code>fabsd128</code>, <code>fabsd64</code>, <code>fabsd32</code>,<span class="std std-since std-c23">(since C23)</span><code>fabsl</code>, <code>fabs</code>, or <code>fabsf</code> is called, respectively. Otherwise, if the argument has integer type, <code>fabs</code> is called. Otherwise, if the argument is complex, then the macro invokes the corresponding complex function (<a href="/reference/c/numeric/complex/cabs/">cabsf</a>, <a href="/reference/c/numeric/complex/cabs/">cabs</a>, <a href="/reference/c/numeric/complex/cabs/">cabsl</a>). Otherwise, the behavior is undefined.</p>

<h3 id="Return_value">Return value</h3>

<p>If successful, returns the absolute value of <code>arg</code> (\(\small |arg| \)|arg|). The value returned is exact and does not depend on any rounding modes.</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any of the error conditions specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If the argument is ±0, +0 is returned.</p>
</li>
<li>
<p>If the argument is ±∞, +∞ is returned.</p>
</li>
<li>
<p>If the argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
#define PI 3.14159
 
// This numerical integration assumes all area is positive.
double integrate(double f(double),
                 double a, double b, // assume a < b
                 unsigned steps) // assume steps > 0
{
    const double dx = (b - a) / steps;
    double sum = 0.0;
    for (double x = a; x < b; x += dx)
        sum += fabs(f(x));
    return dx * sum;
}
 
int main(void)
{
    printf("fabs(+3) = %f\n", fabs(+3.0));
    printf("fabs(-3) = %f\n", fabs(-3.0));
    // special values
    printf("fabs(-0) = %f\n", fabs(-0.0));
    printf("fabs(-Inf) = %f\n", fabs(-INFINITY));
 
    printf("Area under sin(x) in [-PI, PI] = %f\n", integrate(sin, -PI, PI, 5101));
}
```

<p>Output:</p>

```text
fabs(+3) = 3.000000
fabs(-3) = 3.000000
fabs(-0) = 0.000000
fabs(-Inf) = inf
Area under sin(x) in [-PI, PI] = 4.000000
```
