<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       nextafterf( float from, float to );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      nextafter( double from, double to );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double nextafterl( long double from, long double to );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

```c
float       nexttowardf( float from, long double to );
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      nexttoward( double from, long double to );
```

<p class="decl-note">(5) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double nexttowardl( long double from, long double to );
```

<p class="decl-note">(6) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define nextafter(from, to)
```

<p class="decl-note">(7) <span class="std std-since std-c99">(since C99)</span></p>

```c
#define nexttoward(from, to)
```

<p class="decl-note">(8) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  First, converts both arguments to the type of the function, then returns the next representable value of <code>from</code> in the direction of <code>to</code>. If <code>from</code> equals to <code>to</code>, <code>to</code> is returned.</p>

<p class="li-note"><span class="li-num">4-6)</span>  First, converts the first argument to the type of the function, then returns the next representable value of <code>from</code> in the direction of <code>to</code>. If <code>from</code> equals to <code>to</code>, <code>to</code> is returned, converted from <code>long double</code> to the return type of the function without loss of range or precision.</p>

<p class="li-note"><span class="li-num">7)</span>  Type-generic macro: If any argument has type <code>long double</code>, <code>nextafterl</code> is called. Otherwise, if any argument has integer type or has type <code>double</code>, <code>nextafter</code> is called. Otherwise, <code>nextafterf</code> is called.</p>

<p class="li-note"><span class="li-num">8)</span>  Type-generic macro: If the argument <code>from</code> has type <code>long double</code>, <code>nexttowardl</code> is called. Otherwise, if <code>from</code> has integer type or the type <code>double</code>, <code>nexttoward</code> is called. Otherwise, <code>nexttowardf</code> is called.</p>

<table class="ref-table ref-params">
<tr><td>from, to</td><td>-</td><td>floating-point values</td></tr>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the next representable value of <code>from</code> in the direction of <code>to</code>. is returned. If <code>from</code> equals <code>to</code>, then <code>to</code> is returned, converted to the type of the function.</p>

<p>If a range error due to overflow occurs, <code>±HUGE_VAL</code>, <code>±HUGE_VALF</code>, or <code>±HUGE_VALL</code> is returned (with the same sign as <code>from</code>).</p>

<p>If a range error occurs due to underflow, the correct result is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>if</p>

<code>from</code>

<p>is finite, but the expected result is an infinity, raises</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>

<p>and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_OVERFLOW</a>

<p>.</p>
</li>
<li>
<p>if</p>

<code>from</code>

<p>does not equal</p>

<code>to</code>

<p>and the result is subnormal or zero, raises</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>

<p>and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_UNDERFLOW</a>

<p>.</p>
</li>
<li>
<p>in any case, the returned value is independent of the current rounding mode</p>
</li>
<li>
<p>if either</p>

<code>from</code>

<p>or</p>

<code>to</code>

<p>is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p><a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/nextafter.html" rel="noreferrer" target="_blank">POSIX specifies</a> that the overflow and the underflow conditions are range errors (<a href="/reference/c/error/errno/">errno</a> may be set).</p>

<p>IEC 60559 recommends that <code>from</code> is returned whenever <code>from == to</code>. These functions return <code>to</code> instead, which makes the behavior around zero consistent: <code>nextafter(-0.0, +0.0)</code> returns <code>+0.0</code> and <code>nextafter(+0.0, -0.0)</code> returns <code>-0.0</code>.</p>

<p><code>nextafter</code> is typically implemented by manipulation of IEEE representation (<a href="https://github.com/bminor/glibc/blob/master/math/s_nextafter.c" rel="noreferrer" target="_blank">glibc</a> <a href="https://github.com/ifduyue/musl/blob/master/src/math/nextafter.c" rel="noreferrer" target="_blank">musl</a>).</p>

<h3 id="Example">Example</h3>

```c
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    float from1 = 0, to1 = nextafterf(from1, 1);
    printf("The next representable float after %.2f is %.20g (%a)\n", from1, to1, to1);
 
    float from2 = 1, to2 = nextafterf(from2, 2);
    printf("The next representable float after %.2f is %.20f (%a)\n", from2, to2, to2);
 
    double from3 = nextafter(0.1, 0), to3 = 0.1;
    printf("The number 0.1 lies between two valid doubles:\n"
           "    %.56f (%a)\nand %.55f  (%a)\n", from3, from3, to3, to3);
 
    // difference between nextafter and nexttoward:
    long double dir = nextafterl(from1, 1); // first subnormal long double
    float x = nextafterf(from1, dir); // first converts dir to float, giving 0
    printf("Using nextafter, next float after %.2f (%a) is %.20g (%a)\n",
           from1, from1, x, x);
    x = nexttowardf(from1, dir);
    printf("Using nexttoward, next float after %.2f (%a) is %.20g (%a)\n",
           from1, from1, x, x);
 
    // special values
    {
        #pragma STDC FENV_ACCESS ON
        feclearexcept(FE_ALL_EXCEPT);
        double from4 = DBL_MAX, to4 = nextafter(from4, INFINITY);
        printf("The next representable double after %.2g (%a) is %.23f (%a)\n",
               from4, from4, to4, to4);
        if(fetestexcept(FE_OVERFLOW)) puts("   raised FE_OVERFLOW");
        if(fetestexcept(FE_INEXACT)) puts("   raised FE_INEXACT");
    } // end FENV_ACCESS block
 
    float from5 = 0.0, to5 = nextafter(from5, -0.0);
    printf("nextafter(+0.0, -0.0) gives %.2g (%a)\n", to5, to5);
}
```
