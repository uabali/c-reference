<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define FP_NORMAL    /*implementation defined*/
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
#define FP_SUBNORMAL /*implementation defined*/
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
#define FP_ZERO      /*implementation defined*/
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
#define FP_INFINITE  /*implementation defined*/
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

```c
#define FP_NAN       /*implementation defined*/
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>The <code>FP_NORMAL</code>, <code>FP_SUBNORMAL</code>, <code>FP_ZERO</code>, <code>FP_INFINITE</code>, <code>FP_NAN</code> macros each represent a distinct category of floating-point numbers. They all expand to an integer constant expression.</p>

<table class="ref-table ref-dsc">
<tr><td>Constant</td><td>Explanation</td></tr>
<tr><td><code>FP_NORMAL</code></td><td>indicates that the value is <em>normal</em>, i.e. not an infinity, subnormal, not-a-number or zero</td></tr>
<tr><td><code>FP_SUBNORMAL</code></td><td>indicates that the value is <a href="https://en.wikipedia.org/wiki/Subnormal_number" rel="noreferrer" target="_blank"><em>subnormal</em></a></td></tr>
<tr><td><code>FP_ZERO</code></td><td>indicates that the value is positive or negative zero</td></tr>
<tr><td><code>FP_INFINITE</code></td><td>indicates that the value is not representable by the underlying type (positive or negative infinity)</td></tr>
<tr><td><code>FP_NAN</code></td><td>indicates that the value is not-a-number (NaN)</td></tr>
</table>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <math.h>
#include <float.h>
 
const char *show_classification(double x) {
    switch(fpclassify(x)) {
        case FP_INFINITE:  return "Inf";
        case FP_NAN:       return "NaN";
        case FP_NORMAL:    return "normal";
        case FP_SUBNORMAL: return "subnormal";
        case FP_ZERO:      return "zero";
        default:           return "unknown";
    }
}
int main(void)
{
    printf("1.0/0.0 is %s\n", show_classification(1/0.0));
    printf("0.0/0.0 is %s\n", show_classification(0.0/0.0));
    printf("DBL_MIN/2 is %s\n", show_classification(DBL_MIN/2));
    printf("-0.0 is %s\n", show_classification(-0.0));
    printf(" 1.0 is %s\n", show_classification(1.0));
}
```

<p>Output:</p>

```text
1.0/0.0 is Inf
0.0/0.0 is NaN
DBL_MIN/2 is subnormal
-0.0 is zero
 1.0 is normal
```
