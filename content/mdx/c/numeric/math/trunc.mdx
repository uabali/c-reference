<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       truncf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      trunc( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double truncl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define trunc( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the nearest integer not greater in magnitude than <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>truncl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>trunc</code> is called. Otherwise, <code>truncf</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the nearest integer value not greater in magnitude than <code>arg</code> (in other words, <code>arg</code> rounded towards zero), is returned.</p>

<p>Argument</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559):</p>

<ul>
<li>
<p>The current</p>

<a href="/reference/c/numeric/fenv/FE_round/">rounding mode</a>

<p>has no effect.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±∞, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±0, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p><a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a> may be (but isn't required to be) raised when truncating a non-integer finite value.</p>

<p>The largest representable floating-point values are exact integers in all standard floating-point formats, so this function never overflows on its own; however the result may overflow any integer type (including <a href="/reference/c/types/integer/">intmax_t</a>), when stored in an integer variable.</p>

<p>The implicit conversion from floating-point to integral types also rounds towards zero, but is limited to the values that can be represented by the target type.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("trunc(+2.7) = %+.1f\n", trunc(+2.7));
    printf("trunc(-2.7) = %+.1f\n", trunc(-2.7));
    printf("trunc(-0.0) = %+.1f\n", trunc(-0.0));
    printf("trunc(-Inf) = %+f\n",   trunc(-INFINITY));
}
```

<p>Possible output:</p>

```text
trunc(+2.7) = +2.0
trunc(-2.7) = -2.0
trunc(-0.0) = -0.0
trunc(-Inf) = -inf
```
