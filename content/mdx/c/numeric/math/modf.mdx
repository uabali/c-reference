<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       modff( float arg, float* iptr );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      modf( double arg, double* iptr );
```

<p class="decl-note">(2)</p>

```c
long double modfl( long double arg, long double* iptr );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Decomposes given floating-point value <code>arg</code> into integral and fractional parts, each having the same type and sign as <code>arg</code>. The integral part (in floating-point format) is stored in the object pointed to by <code>iptr</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
<tr><td>iptr</td><td>-</td><td>pointer to floating-point value to store the integral part to</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, returns the fractional part of <code>arg</code> with the same sign as <code>arg</code>. The integral part is put into the value pointed to by <code>iptr</code>.</p>

<p>The sum of the returned value and the value stored in <code>*iptr</code> gives <code>arg</code> (allowing for rounding).</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any errors specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If</p>

<code>arg</code>

<p>is ±0, ±0 is returned, and ±0 is stored in</p>

<code>*iptr</code>

<p>.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±∞, ±0 is returned, and ±∞ is stored in</p>

<code>*iptr</code>

<p>.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is NaN, NaN is returned, and NaN is stored in</p>

<code>*iptr</code>

<p>.</p>
</li>
<li>
<p>The returned value is exact,</p>

<a href="/reference/c/numeric/fenv/FE_round/">the current rounding mode</a>

<p>is ignored.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>This function behaves as if implemented as follows:</p>

```c
double modf(double value, double *iptr)
{
#pragma STDC FENV_ACCESS ON
    int save_round = fegetround();
    fesetround(FE_TOWARDZERO);
    *iptr = std::nearbyint(value);
    fesetround(save_round);
    return copysign(isinf(value) ? 0.0 : value - (*iptr), value);
}
```

<h3 id="Example">Example</h3>

```c
#include <float.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    double f = 123.45;
    printf("Given the number %.2f or %a in hex,\n", f, f);
 
    double f3;
    double f2 = modf(f, &f3);
    printf("modf() makes %.2f + %.2f\n", f3, f2);
 
    int i;
    f2 = frexp(f, &i);
    printf("frexp() makes %f * 2^%d\n", f2, i);
 
    i = ilogb(f);
    printf("logb()/ilogb() make %f * %d^%d\n", f / scalbn(1.0, i), FLT_RADIX, i);
 
    // special values
    f2 = modf(-0.0, &f3);
    printf("modf(-0) makes %.2f + %.2f\n", f3, f2);
    f2 = modf(-INFINITY, &f3);
    printf("modf(-Inf) makes %.2f + %.2f\n", f3, f2);
}
```

<p>Possible output:</p>

```text
Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123.00 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
modf(-0) makes -0.00 + -0.00
modf(-Inf) makes -INF + -0.00
```
