<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       floorf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      floor( double arg );
```

<p class="decl-note">(2)</p>

```c
long double floorl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define floor( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the largest integer value not greater than <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>floorl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>floor</code> is called. Otherwise, <code>floorf</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the largest integer value not greater than <code>arg</code>, that is ⌊arg⌋, is returned.</p>

<img src="/media/cppref/206842cf-math-floor.svg" alt="math-floor.svg" />

<p>Argument</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559):</p>

<ul>
<li>
<p>The current</p>

<a href="/reference/c/numeric/fenv/FE_round/">rounding mode</a>

<p>has no effect.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±∞, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is ±0, it is returned, unmodified.</p>
</li>
<li>
<p>If</p>

<code>arg</code>

<p>is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p><a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a> may be (but isn't required to be) raised when rounding a non-integer finite value.</p>

<p>The largest representable floating-point values are exact integers in all standard floating-point formats, so this function never overflows on its own; however the result may overflow any integer type (including <a href="/reference/c/types/integer/">intmax_t</a>), when stored in an integer variable.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("floor(+2.7) = %+.1f\n", floor(2.7));
    printf("floor(-2.7) = %+.1f\n", floor(-2.7));
    printf("floor(-0.0) = %+.1f\n", floor(-0.0));
    printf("floor(-Inf) = %+f\n",   floor(-INFINITY));
}
```

<p>Possible output:</p>

```text
floor(+2.7) = +2.0
floor(-2.7) = -3.0
floor(-0.0) = -0.0
floor(-Inf) = -inf
```
