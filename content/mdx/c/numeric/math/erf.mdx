<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       erff( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      erf( double arg );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double erfl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define erf( arg )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the <a href="https://en.wikipedia.org/wiki/Error_function" rel="noreferrer" target="_blank">error function</a> of <code>arg</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If <code>arg</code> has type <code>long double</code>, <code>erfl</code> is called. Otherwise, if <code>arg</code> has integer type or the type <code>double</code>, <code>erf</code> is called. Otherwise, <code>erff</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, value of the error function of</p>

<code>arg</code>

<p>, that is</p>

\(\frac{2}{\sqrt{\pi} }\int_{0}^{arg}{e^{-{t^2} }\mathsf{d}t}\)

2√π∫arg 0<em>e</em><sup>-t2 </sup>d<em>t</em>

<p>, is returned. If a range error occurs due to underflow, the correct result (after rounding), that is</p>

\(\frac{2\cdot arg}{\sqrt{\pi} }\)

2*arg√π

<p>, is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If the argument is ±0, ±0 is returned</p>
</li>
<li>
<p>If the argument is ±∞, ±1 is returned</p>
</li>
<li>
<p>If the argument is NaN, NaN is returned</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>Underflow is guaranteed if <code>|arg| &lt; DBL_MIN*(sqrt(π)/2)</code>.</p>

\(\operatorname{erf}(\frac{x}{\sigma \sqrt{2} })\)

erf(xσ√2)

<p>is the probability that a measurement whose errors are subject to a normal distribution with standard deviation</p>

\(\sigma\)

σ

<p>is less than</p>

\(x\)

x

<p>away from the mean value.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
double phi(double x1, double x2)
{
    return (erf(x2 / sqrt(2)) - erf(x1 / sqrt(2))) / 2;
}
 
int main(void)
{
    puts("normal variate probabilities:");
    for (int n = -4; n < 4; ++n)
        printf("[%2d:%2d]: %5.2f%%\n", n, n + 1, 100 * phi(n, n + 1));
 
    puts("special values:");
    printf("erf(-0) = %f\n", erf(-0.0));
    printf("erf(Inf) = %f\n", erf(INFINITY));
}
```

<p>Output:</p>

```text
normal variate probabilities:
[-4:-3]:  0.13%
[-3:-2]:  2.14%
[-2:-1]: 13.59%
[-1: 0]: 34.13%
[ 0: 1]: 34.13%
[ 1: 2]: 13.59%
[ 2: 3]:  2.14%
[ 3: 4]:  0.13%
special values:
erf(-0) = -0.000000
erf(Inf) = 1.000000
```
