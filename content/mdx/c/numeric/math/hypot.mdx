<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       hypotf( float x, float y );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      hypot( double x, double y );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double hypotl( long double x, long double y );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define hypot( x, y )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the square root of the sum of the squares of <code>x</code> and <code>y</code>, without undue overflow or underflow at intermediate stages of the computation.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If any argument has type <code>long double</code>, the long double version of the function is called. Otherwise, if any argument has integer type or has type <code>double</code>, the double version of the function is called. Otherwise, the <code>float</code> version of the function is called.</p>

<p>The value computed by this function is the length of the hypotenuse of a right-angled triangle with sides of length <code>x</code> and <code>y</code>, or the distance of the point <code>(x, y)</code> from the origin <code>(0, 0)</code>, or the magnitude of a complex number <code>x+iy</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x</td><td>-</td><td>floating-point value</td></tr>
<tr><td>y</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the hypotenuse of a right-angled triangle, \(\scriptsize{\sqrt{x^2+y^2} }\)√x2 +y2 , is returned.</p>

<p>If a range error due to overflow occurs, <a href="/reference/c/numeric/math/HUGE_VAL/">+HUGE_VAL</a>, <code>+HUGE_VALF</code>, or <code>+HUGE_VALL</code> is returned.</p>

<p>If a range error due to underflow occurs, the correct result (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<code>hypot(x, y)</code>

<p>,</p>

<code>hypot(y, x)</code>

<p>, and</p>

<code>hypot(x, -y)</code>

<p>are equivalent</p>
</li>
<li>
<p>if one of the arguments is ±0,</p>

<code>hypot</code>

<p>is equivalent to</p>

<code>fabs</code>

<p>called with the non-zero argument</p>
</li>
<li>
<p>if one of the arguments is ±∞,</p>

<code>hypot</code>

<p>returns +∞ even if the other argument is NaN</p>
</li>
<li>
<p>otherwise, if any of the arguments is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>Implementations usually guarantee precision of less than 1 ulp (<a href="https://en.wikipedia.org/wiki/Unit_in_the_last_place" rel="noreferrer" target="_blank">units in the last place</a>): <a href="https://sourceware.org/git/?p=glibc.git;a=blob_plain;f=sysdeps/ieee754/dbl-64/e_hypot.c" rel="noreferrer" target="_blank">GNU</a>, <a href="https://www.freebsd.org/cgi/cvsweb.cgi/src/lib/msun/src/e_hypot.c" rel="noreferrer" target="_blank">BSD</a>.</p>

<p><code>hypot(x, y)</code> is equivalent to <code>cabs(x + I*y)</code>.</p>

<p><a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/hypot.html" rel="noreferrer" target="_blank">POSIX specifies</a> that underflow may only occur when both arguments are subnormal and the correct result is also subnormal (this forbids naive implementations).</p>

<p><code>hypot(INFINITY, NAN)</code> returns +∞, but <code>sqrt(INFINITY * INFINITY + NAN * NAN)</code> returns NaN.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON
 
int main(void)
{
    // typical usage
    printf("(1,1) cartesian is (%f,%f) polar\n", hypot(1,1), atan2(1, 1));
 
    // special values
    printf("hypot(NAN,INFINITY) = %f\n", hypot(NAN, INFINITY));
 
    // error handling
    errno = 0;
    feclearexcept(FE_ALL_EXCEPT);
    printf("hypot(DBL_MAX,DBL_MAX) = %f\n", hypot(DBL_MAX, DBL_MAX));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
```

<p>Possible output:</p>

```text
(1,1) cartesian is (1.414214,0.785398) polar
hypot(NAN,INFINITY) = inf
hypot(DBL_MAX,DBL_MAX) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
```
