<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       sinf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      sin( double arg );
```

<p class="decl-note">(2)</p>

```c
long double sinl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

```c
_Decimal32  sind32( _Decimal32 arg );
```

<p class="decl-note">(4) <span class="std std-since std-c23">(since C23)</span></p>

```c
_Decimal64  sind64( _Decimal64 arg );
```

<p class="decl-note">(5) <span class="std std-since std-c23">(since C23)</span></p>

```c
_Decimal128 sind128( _Decimal128 arg );
```

<p class="decl-note">(6) <span class="std std-since std-c23">(since C23)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define sin( arg )
```

<p class="decl-note">(7) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Computes the sine of <code>arg</code> (measured in radians).</p>

<p class="li-note"><span class="li-num">7)</span>  Type-generic macro: If the argument has type <code>long double</code>, (3) (<code>sinl</code>) is called. Otherwise, if the argument has integer type or the type <code>double</code>, (2) (<code>sin</code>) is called. Otherwise, (1) (<code>sinf</code>) is called. If the argument is complex, then the macro invokes the corresponding complex function (<a href="/reference/c/numeric/complex/csin/">csinl</a>, <a href="/reference/c/numeric/complex/csin/">csin</a>, <a href="/reference/c/numeric/complex/csin/">csinf</a>).</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>The functions (4-6) are declared if and only if the implementation predefines <code>__STDC_IEC_60559_DFP__</code> (i.e. the implementation supports decimal floating-point numbers).</p></aside>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value representing an angle in radians</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the sine of <code>arg</code> (sin(arg)) in the range [-1 ; +1], is returned.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c99">(until C99)</span></p><p>The result may have little or no significance if the magnitude of <code>arg</code> is large.</p></aside>

<p>If a domain error occurs, an implementation-defined value is returned (NaN where supported).</p>

<p>If a range error occurs due to underflow, the correct result (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559):</p>

<ul>
<li>
<p>if the argument is ±0, it is returned unmodified;</p>
</li>
<li>
<p>if the argument is ±∞, NaN is returned and</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INVALID</a>

<p>is raised;</p>
</li>
<li>
<p>if the argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>The case where the argument is infinite is not specified to be a domain error in C, but it is defined as a <a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/sin.html" rel="noreferrer" target="_blank">domain error in POSIX</a>.</p>

<p>POSIX also specifies that in case of underflow, <code>arg</code> is returned unmodified, and if that is not supported, an implementation-defined value no greater than <a href="/reference/c/types/limits/">DBL_MIN</a>, <a href="/reference/c/types/limits/">FLT_MIN</a>, and <a href="/reference/c/types/limits/">LDBL_MIN</a> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
 
#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif
 
int main(void)
{
    const double pi = acos(-1);
 
    // typical usage
    printf("sin(pi/6) = %f\n", sin(pi / 6));
    printf("sin(pi/2) = %f\n", sin(pi / 2));
    printf("sin(-3*pi/4) = %f\n", sin(-3 * pi / 4));
 
    // special values
    printf("sin(+0) = %f\n", sin(0.0));
    printf("sin(-0) = %f\n", sin(-0.0));
 
    // error handling
    feclearexcept(FE_ALL_EXCEPT);
    printf("sin(INFINITY) = %f\n", sin(INFINITY));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}
```

<p>Possible output:</p>

```text
sin(pi/6) = 0.500000
sin(pi/2) = 1.000000
sin(-3*pi/4) = -0.707107
sin(+0) = 0.000000
sin(-0) = -0.000000
sin(INFINITY) = -nan
    FE_INVALID raised
```
