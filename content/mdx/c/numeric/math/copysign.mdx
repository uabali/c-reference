<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       copysignf( float x, float y );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      copysign( double x, double y );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double copysignl( long double x, long double y );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define copysign(x, y)
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Composes a floating-point value with the magnitude of <code>x</code> and the sign of <code>y</code>.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If any argument has type <code>long double</code>, <code>copysignl</code> is called. Otherwise, if any argument has integer type or has type <code>double</code>, <code>copysign</code> is called. Otherwise, <code>copysignf</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x, y</td><td>-</td><td>floating-point values</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the floating-point value with the magnitude of <code>x</code> and the sign of <code>y</code> is returned.</p>

<p>If <code>x</code> is NaN, then NaN with the sign of <code>y</code> is returned.</p>

<p>If <code>y</code> is -0, the result is only negative if the implementation supports the signed zero consistently in arithmetic operations.</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any errors specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>The returned value is exact (</p>

<a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>

<p>is never raised) and independent of the current</p>

<a href="/reference/c/numeric/fenv/FE_round/">rounding mode</a>

<p>.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p><code>copysign</code> is the only portable way to manipulate the sign of a NaN value (to examine the sign of a NaN, <a href="/reference/c/numeric/math/signbit/">signbit</a> may also be used).</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("copysign(1.0,+2.0)      = %+.1f\n", copysign(1.0,+2.0));
    printf("copysign(1.0,-2.0)      = %+.1f\n", copysign(1.0,-2.0));
    printf("copysign(INFINITY,-2.0) = %f\n",    copysign(INFINITY,-2.0));
    printf("copysign(NAN,-2.0)      = %f\n",    copysign(NAN,-2.0));
}
```

<p>Possible output:</p>

```text
copysign(1.0,+2.0)      = +1.0
copysign(1.0,-2.0)      = -1.0
copysign(INFINITY,-2.0) = -inf
copysign(NAN,-2.0)      = -nan
```
