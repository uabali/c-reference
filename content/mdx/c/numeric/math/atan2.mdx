<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       atan2f( float y, float x );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      atan2( double y, double x );
```

<p class="decl-note">(2)</p>

```c
long double atan2l( long double y, long double x );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

```c
_Decimal32  atan2d32( _Decimal32 y, _Decimal32 x );
```

<p class="decl-note">(4) <span class="std std-since std-c23">(since C23)</span></p>

```c
_Decimal64  atan2d64( _Decimal64 y, _Decimal64 x );
```

<p class="decl-note">(5) <span class="std std-since std-c23">(since C23)</span></p>

```c
_Decimal128 atan2d128( _Decimal128 y, _Decimal128 x );
```

<p class="decl-note">(6) <span class="std std-since std-c23">(since C23)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define atan2( y, x )
```

<p class="decl-note">(7) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-6)</span>  Computes the arc tangent of <code>y / x</code> using the signs of arguments to determine the correct quadrant.</p>

<p class="li-note"><span class="li-num">7)</span>  Type-generic macro: If any argument has type <code>long double</code>, (3) (<code>atan2l</code>) is called. Otherwise, if any argument has integer type or has type <code>double</code>, (2) (<code>atan2</code>) is called. Otherwise, (1) (<code>atan2f</code>) is called.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>The functions (4-6) are declared if and only if the implementation predefines <code>__STDC_IEC_60559_DFP__</code> (i.e. the implementation supports decimal floating-point numbers).</p></aside>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the arc tangent of</p>

<code>y / x</code>

<p>(</p>

arctan(yx)

<p>) in the range</p>

[-π ; +π]

<p>radians, is returned.</p>

<p>Y argument</p>

<p>Return value</p>

<p>X argument</p>

<p>If a domain error occurs, an implementation-defined value is returned.</p>

<p>If a range error occurs due to underflow, the correct result (after rounding) is returned.</p>

<h3 id="Notes">Notes</h3>

<p><code>atan2(y, x)</code> is equivalent to <code>carg(x + I*y)</code>.</p>

<p><a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/atan2.html" rel="noreferrer" target="_blank">POSIX specifies</a> that in case of underflow, <code>y / x</code> is the value returned, and if that is not supported, an implementation-defined value no greater than <a href="/reference/c/types/limits/">DBL_MIN</a>, <a href="/reference/c/types/limits/">FLT_MIN</a>, and <a href="/reference/c/types/limits/">LDBL_MIN</a> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    // normal usage: the signs of the two arguments determine the quadrant
    // atan2(1,1) = +pi/4, Quad I
    printf("(+1,+1) cartesian is (%f,%f) polar\n", hypot( 1, 1), atan2( 1, 1));
    // atan2(1, -1) = +3pi/4, Quad II
    printf("(+1,-1) cartesian is (%f,%f) polar\n", hypot( 1,-1), atan2( 1,-1));
    // atan2(-1,-1) = -3pi/4, Quad III
    printf("(-1,-1) cartesian is (%f,%f) polar\n", hypot(-1,-1), atan2(-1,-1));
    // atan2(-1,-1) = -pi/4, Quad IV
    printf("(-1,+1) cartesian is (%f,%f) polar\n", hypot(-1, 1), atan2(-1, 1));
 
    // special values
    printf("atan2(0, 0) = %f atan2(0, -0)=%f\n", atan2(0,0), atan2(0,-0.0));
    printf("atan2(7, 0) = %f atan2(7, -0)=%f\n", atan2(7,0), atan2(7,-0.0));
}
```

<p>Output:</p>

```text
(+1,+1) cartesian is (1.414214,0.785398) polar
(+1,-1) cartesian is (1.414214,2.356194) polar
(-1,-1) cartesian is (1.414214,-2.356194) polar
(-1,+1) cartesian is (1.414214,-0.785398) polar
atan2(0, 0) = 0.000000 atan2(0, -0)=3.141593
atan2(7, 0) = 1.570796 atan2(7, -0)=1.570796
```
