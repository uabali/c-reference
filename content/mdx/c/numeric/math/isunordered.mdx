<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define isunordered(x, y) /* implementation defined */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Determines if the floating point numbers <code>x</code> and <code>y</code> are unordered, that is, one or both are NaN and thus cannot be meaningfully compared with each other.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x</td><td>-</td><td>floating point value</td></tr>
<tr><td>y</td><td>-</td><td>floating point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Nonzero integral value if either <code>x</code> or <code>y</code> is NaN, <code>0</code> otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("isunordered(NAN,1.0) = %d\n", isunordered(NAN, 1.0));
    printf("isunordered(1.0,NAN) = %d\n", isunordered(1.0, NAN));
    printf("isunordered(NAN,NAN) = %d\n", isunordered(NAN, NAN));
    printf("isunordered(1.0,0.0) = %d\n", isunordered(1.0, 0.0));
 
    return 0;
}
```

<p>Possible output:</p>

```text
isunordered(NAN,1.0) = 1
isunordered(1.0,NAN) = 1
isunordered(NAN,NAN) = 1
isunordered(1.0,0.0) = 0
```
