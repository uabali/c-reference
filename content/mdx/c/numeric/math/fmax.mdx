<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       fmaxf( float x, float y );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      fmax( double x, double y );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double fmaxl( long double x, long double y );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define fmax( x, y )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Returns the larger of two floating-point arguments, treating NaNs as missing data (between a NaN and a numeric value, the numeric value is chosen).</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If any argument has type <code>long double</code>, <code>fmaxl</code> is called. Otherwise, if any argument has integer type or has type <code>double</code>, <code>fmax</code> is called. Otherwise, <code>fmaxf</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x, y</td><td>-</td><td>floating-point values</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If successful, returns the larger of two floating-point values. The value returned is exact and does not depend on any rounding modes.</p>

<h3 id="Error_handling">Error handling</h3>

<p>This function is not subject to any of the error conditions specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If one of the two arguments is NaN, the value of the other argument is returned.</p>
</li>
<li>
<p>Only if both arguments are NaN is NaN returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>This function is not required to be sensitive to the sign of zero, although some implementations additionally enforce that if one argument is +0 and the other is -0, then +0 is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("fmax(2,1)    = %f\n", fmax(2,1));
    printf("fmax(-Inf,0) = %f\n", fmax(-INFINITY,0));
    printf("fmax(NaN,-1) = %f\n", fmax(NAN,-1));
}
```

<p>Output:</p>

```text
fmax(2,1)    = 2.000000
fmax(-Inf,0) = 0.000000
fmax(NaN,-1) = -1.000000
```
