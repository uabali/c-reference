<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       fdimf( float x, float y );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      fdim( double x, double y );
```

<p class="decl-note">(2) <span class="std std-since std-c99">(since C99)</span></p>

```c
long double fdiml( long double x, long double y );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define fdim( x, y )
```

<p class="decl-note">(4) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-3)</span>  Returns the positive difference between <code>x</code> and <code>y</code>, that is, if <code>x&gt;y</code>, returns <code>x-y</code>, otherwise (if <code>x≤y</code>), returns +0.</p>

<p class="li-note"><span class="li-num">4)</span>  Type-generic macro: If any argument has type <code>long double</code>, <code>fdiml</code> is called. Otherwise, if any argument has integer type or has type <code>double</code>, <code>fdim</code> is called. Otherwise, <code>fdimf</code> is called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x, y</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If successful, returns the positive difference between <code>x</code> and <code>y</code>.</p>

<p>If a range error due to overflow occurs, <a href="/reference/c/numeric/math/HUGE_VAL/">+HUGE_VAL</a>, <code>+HUGE_VALF</code>, or <code>+HUGE_VALL</code> is returned.</p>

<p>If a range error due to underflow occurs, the correct value (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="https://en.cppreference.com/mwiki/index.php?title=Template:rllpt&amp;action=edit&amp;redlink=1" rel="noreferrer" target="_blank">Template:rllpt</a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559),</p>

<ul>
<li>
<p>If either argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p>Equivalent to <code>fmax(x-y, 0)</code> except for the NaN handling requirements.</p>

<h3 id="Example">Example</h3>

```c
#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON
 
int main(void)
{
    printf("fdim(4, 1) = %f, fdim(1, 4)=%f\n", fdim(4,1), fdim(1,4));
    printf("fdim(4,-1) = %f, fdim(1,-4)=%f\n", fdim(4,-1), fdim(1,-4));
    //error handling
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("fdim(1e308, -1e308) = %f\n", fdim(1e308, -1e308));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
```

<p>Possible output:</p>

```text
fdim(4, 1) = 3.000000, fdim(1, 4)=0.000000
fdim(4,-1) = 5.000000, fdim(1,-4)=5.000000
fdim(1e308, -1e308) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
```
