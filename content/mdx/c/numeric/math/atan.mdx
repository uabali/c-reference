<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
float       atanf( float arg );
```

<p class="decl-note">(1) <span class="std std-since std-c99">(since C99)</span></p>

```c
double      atan( double arg );
```

<p class="decl-note">(2)</p>

```c
long double atanl( long double arg );
```

<p class="decl-note">(3) <span class="std std-since std-c99">(since C99)</span></p>

```c
_Decimal32  atand32( _Decimal32 arg );
```

<p class="decl-note">(4) <span class="std std-since std-c23">(since C23)</span></p>

```c
_Decimal64  atand64( _Decimal64 arg );
```

<p class="decl-note">(5) <span class="std std-since std-c23">(since C23)</span></p>

```c
_Decimal128 atand128( _Decimal128 arg );
```

<p class="decl-note">(6) <span class="std std-since std-c23">(since C23)</span></p>

<p class="decl-header">Defined in header <code>&lt;tgmath.h&gt;</code></p>

```c
#define atan( arg )
```

<p class="decl-note">(7) <span class="std std-since std-c99">(since C99)</span></p>

<p class="li-note"><span class="li-num">1-6)</span>  Computes the principal value of the arc tangent of <code>arg</code>.</p>

<p class="li-note"><span class="li-num">7)</span>  Type-generic macro: If the argument has type <code>long double</code>, (3) (<code>atanl</code>) is called. Otherwise, if the argument has integer type or the type <code>double</code>, (2) (<code>atan</code>) is called. Otherwise, (1) (<code>atanf</code>) is called. If the argument is complex, then the macro invokes the corresponding complex function (<a href="/reference/c/numeric/complex/catan/">catanf</a>, <a href="/reference/c/numeric/complex/catan/">catan</a>, <a href="/reference/c/numeric/complex/catan/">catanl</a>).</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>The functions (4-6) are declared if and only if the implementation predefines <code>__STDC_IEC_60559_DFP__</code> (i.e. the implementation supports decimal floating-point numbers).</p></aside>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>If no errors occur, the arc tangent of</p>

<code>arg</code>

<p>(</p>

arctan(arg)

<p>) in the range</p>

[- π2 ; +π2]

<p>radians, is returned.</p>

<p>If a range error occurs due to underflow, the correct result (after rounding) is returned.</p>

<h3 id="Error_handling">Error handling</h3>

<p>Errors are reported as specified in <a href="/reference/c/numeric/math/math_errhandling/"><code>math_errhandling</code></a>.</p>

<p>If the implementation supports IEEE floating-point arithmetic (IEC 60559):</p>

<ul>
<li>
<p>if the argument is ±0, it is returned unmodified;</p>
</li>
<li>
<p>if the argument is +∞, +π/2 is returned;</p>
</li>
<li>
<p>if the argument is -∞, -π/2 is returned;</p>
</li>
<li>
<p>if the argument is NaN, NaN is returned.</p>
</li>
</ul>

<h3 id="Notes">Notes</h3>

<p><a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/atan.html" rel="noreferrer" target="_blank">POSIX specifies</a> that in case of underflow, <code>arg</code> is returned unmodified, and if that is not supported, an implementation-defined value no greater than <a href="/reference/c/types/limits/">DBL_MIN</a>, <a href="/reference/c/types/limits/">FLT_MIN</a>, and <a href="/reference/c/types/limits/">LDBL_MIN</a> is returned.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("atan(1) = %f, 4*atan(1)=%f\n", atan(1), 4 * atan(1));
    // special values
    printf("atan(Inf) = %f, 2*atan(Inf) = %f\n", atan(INFINITY), 2 * atan(INFINITY));
    printf("atan(-0.0) = %+f, atan(+0.0) = %+f\n", atan(-0.0), atan(0));
}
```

<p>Output:</p>

```text
atan(1) = 0.785398, 4*atan(1)=3.141593
atan(Inf) = 1.570796, 2*atan(Inf) = 3.141593
atan(-0.0) = -0.000000, atan(+0.0) = +0.000000
```
