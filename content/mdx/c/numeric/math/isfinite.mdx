<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define isfinite(arg) /* implementation defined */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Determines if the given floating-point number <code>arg</code> has finite value i.e. it is normal, subnormal or zero, but not infinite or NaN. The macro returns an integral value.</p>

<p><a href="/reference/c/types/limits/FLT_EVAL_METHOD/">FLT_EVAL_METHOD</a> is ignored: even if the argument is evaluated with more range and precision than its type, it is first converted to its semantic type, and the classification is based on that.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>arg</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Nonzero integral value if <code>arg</code> has finite value, <code>0</code> otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <float.h>
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("isfinite(NAN)         = %d\n", isfinite(NAN));
    printf("isfinite(INFINITY)    = %d\n", isfinite(INFINITY));
    printf("isfinite(0.0)         = %d\n", isfinite(0.0));
    printf("isfinite(DBL_MIN/2.0) = %d\n", isfinite(DBL_MIN / 2.0));
    printf("isfinite(1.0)         = %d\n", isfinite(1.0));
    printf("isfinite(exp(800))    = %d\n", isfinite(exp(800)));
}
```

<p>Possible output:</p>

```text
isfinite(NAN)         = 0
isfinite(INFINITY)    = 0
isfinite(0.0)         = 1
isfinite(DBL_MIN/2.0) = 1
isfinite(1.0)         = 1
isfinite(exp(800))    = 0
```
