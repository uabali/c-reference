<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int        abs( int n );
```

```c
long       labs( long n );
```

```c
long long llabs( long long n );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p class="decl-header">Defined in header <code>&lt;inttypes.h&gt;</code></p>

```c
intmax_t imaxabs( intmax_t n );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Computes the absolute value of an integer number. The behavior is undefined if the result cannot be represented by the return type.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>n</td><td>-</td><td>integer value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>The absolute value of <code>n</code> (i.e. <code>|n|</code>), if it is representable.</p>

<h3 id="Notes">Notes</h3>

<p>In 2's complement systems, the absolute value of the most-negative value is out of range, e.g. for 32-bit 2's complement type <code>int</code>, <a href="/reference/c/types/limits/">INT_MIN</a> is <code>-2147483648</code>, but the would-be result <code>2147483648</code> is greater than <a href="/reference/c/types/limits/">INT_MAX</a>, which is <code>2147483647</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    printf("abs(+3) = %d\n", abs(+3));
    printf("abs(-3) = %d\n", abs(-3));
 
//  printf("%+d\n", abs(INT_MIN)); // undefined behavior on 2's complement systems
}
```

<p>Output:</p>

```text
abs(+3) = 3
abs(-3) = 3
```
