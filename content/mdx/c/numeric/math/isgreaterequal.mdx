<p class="decl-header">Defined in header <code>&lt;math.h&gt;</code></p>

```c
#define isgreaterequal(x, y) /* implementation defined */
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Determines if the floating-point number <code>x</code> is greater than or equal to the floating-point number <code>y</code>, without setting floating-point exceptions.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>x</td><td>-</td><td>floating-point value</td></tr>
<tr><td>y</td><td>-</td><td>floating-point value</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Nonzero integral value if <code>x &gt;= y</code>, <code>0</code> otherwise.</p>

<h3 id="Notes">Notes</h3>

<p>The built-in <code>operator&gt;=</code> for floating-point numbers may raise <a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INVALID</a> if one or both of the arguments is NaN. This function is a "quiet" version of <code>operator&gt;=</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <math.h>
#include <stdio.h>
 
int main(void)
{
    printf("isgreaterequal(2.0,1.0)      = %d\n", isgreaterequal(2.0, 1.0));
    printf("isgreaterequal(1.0,2.0)      = %d\n", isgreaterequal(1.0, 2.0));
    printf("isgreaterequal(1.0,1.0)      = %d\n", isgreaterequal(1.0, 1.0));
    printf("isgreaterequal(INFINITY,1.0) = %d\n", isgreaterequal(INFINITY, 1.0));
    printf("isgreaterequal(1.0,NAN)      = %d\n", isgreaterequal(1.0, NAN));
 
    return 0;
}
```

<p>Possible output:</p>

```text
isgreaterequal(2.0,1.0)      = 1
isgreaterequal(1.0,2.0)      = 0
isgreaterequal(1.0,1.0)      = 1
isgreaterequal(INFINITY,1.0) = 1
isgreaterequal(1.0,NAN)      = 0
```
