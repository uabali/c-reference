<p class="decl-header">Defined in header <code>&lt;fenv.h&gt;</code></p>

```c
int feraiseexcept( int excepts );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span></p>

<p>Attempts to raise all floating-point exceptions listed in <code>excepts</code> (a bitwise OR of the <a href="/reference/c/numeric/fenv/FE_exceptions/">floating-point exception macros</a>). If one of the exceptions is <a href="/reference/c/numeric/fenv/FE_exceptions/">FE_OVERFLOW</a> or <code>FE_UNDERFLOW</code>, this function may additionally raise <a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>. The order in which the exceptions are raised is unspecified, except that <a href="/reference/c/numeric/fenv/FE_exceptions/">FE_OVERFLOW</a> and <code>FE_UNDERFLOW</code> are always raised before <a href="/reference/c/numeric/fenv/FE_exceptions/">FE_INEXACT</a>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>excepts</td><td>-</td><td>bitmask listing the exception flags to raise</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>0</code> if all listed exceptions were raised, non-zero value otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <fenv.h>
 
#pragma STDC FENV_ACCESS ON
 
void show_fe_exceptions(void)
{
    printf("current exceptions raised: ");
    if(fetestexcept(FE_DIVBYZERO))     printf(" FE_DIVBYZERO");
    if(fetestexcept(FE_INEXACT))       printf(" FE_INEXACT");
    if(fetestexcept(FE_INVALID))       printf(" FE_INVALID");
    if(fetestexcept(FE_OVERFLOW))      printf(" FE_OVERFLOW");
    if(fetestexcept(FE_UNDERFLOW))     printf(" FE_UNDERFLOW");
    if(fetestexcept(FE_ALL_EXCEPT)==0) printf(" none");
    feclearexcept(FE_ALL_EXCEPT);
    printf("\n");
}
 
double some_computation(void)
{
    /* Computation reaches a state that causes overflow. */
    int r = feraiseexcept(FE_OVERFLOW | FE_INEXACT);
    printf("feraiseexcept() %s\n", (r?"fails":"succeeds"));
    return 0.0;
}
 
int main(void)
{
    some_computation();
    show_fe_exceptions();
 
    return 0;
}
```

<p>Output:</p>

```text
feraiseexcept() succeeds
current exceptions raised:  FE_INEXACT FE_OVERFLOW
```
