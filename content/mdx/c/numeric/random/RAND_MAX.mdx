<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
#define RAND_MAX /*implementation defined*/
```

<p>Expands to an integer constant expression equal to the maximum value returned by the function <a href="/reference/c/numeric/random/rand/">rand()</a>. This value is implementation dependent. It's guaranteed that this value is at least <code>32767</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
 
int main(void)
{
    srand(time(NULL)); // use current time as seed for random generator
    printf("RAND_MAX: %i\n", RAND_MAX);
    printf("INT_MAX: %i\n", INT_MAX);
    printf("Random value on [0,1]: %f\n", (double)rand() / RAND_MAX);
}
```

<p>Possible output:</p>

```text
RAND_MAX: 2147483647
INT_MAX: 2147483647
Random value on [0,1]: 0.362509
```
