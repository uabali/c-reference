<p class="decl-note">(6) <span class="std std-since std-c23">(since C23)</span></p>

<p class="li-note"><span class="li-num">1-5)</span>  Returns the number of consecutive <code>0</code> bits in the <code>value</code>, starting from the most significant bit.</p>

<div class="li-note"><span class="li-num">6)</span>

<p>The type-generic function (marked by its</p>

<code>generic_value_type</code>

<p>argument) returns the appropriate value based on the type of the input value, so long as it is a:</p>

<ul>
<li>
<p>standard unsigned integer type, excluding</p>

<code>bool</code>

<p>;</p>
</li>
<li>
<p>extended unsigned integer type;</p>
</li>
<li>
<p>or, bit-precise unsigned integer type whose width matches a standard or extended integer type, excluding</p>

<code>bool</code>

<p>.</p>
</li>
</ul>

<p>The</p>

<code>generic_return_type</code>

<p>shall be a suitable large unsigned integer type capable of representing the computed result.</p></div>

<h3 id="Return_value">Return value</h3>

<p>The number of consecutive <code>0</code> bits in the <code>value</code>, starting from the most significant bit.</p>

<h3 id="Example">Example</h3>

```c
#include <limits.h>
#include <stdbit.h>
#include <stdint.h>
#include <stdio.h>
 
#define bits_num(value) (sizeof(value) * CHAR_BIT)
 
#define bin_impl(T, suffix) \
const char* bin_##suffix(T x) \
{ \
    static char buf[bits_num(x) * CHAR_BIT + 1]; \
    for (T i = 0, mask = ((T)1 << (bits_num(x) - 1)); mask; mask >>= 1) \
        buf[i++] = x & mask ? '1' : '0'; \
    buf[bits_num(x)] = '\0'; \
    return buf; \
}
 
bin_impl(uint8_t, u8)
bin_impl(uint16_t, u16)
bin_impl(uint32_t, u32)
bin_impl(uint64_t, u64)
 
#define bin(x) _Generic((x), \
    uint8_t: bin_u8, uint16_t: bin_u16, uint32_t: bin_u32, default: bin_u64)(x)
 
int main()
{
    puts("uint8_t:");
    for (uint8_t x = 0b11000000; ; x >>= 1)
    {
        printf("x = [%s], leading zeros: %d\n", bin(x), stdc_leading_zeros(x));
        if (!x)
            break;
    }
 
    puts("uint16_t:");
    for (uint16_t x = 0b11000000; ; x >>= 1)
    {
        printf("x = [%s], leading zeros: %d\n", bin(x), stdc_leading_zeros(x));
        if (!x)
            break;
    }
}
```
