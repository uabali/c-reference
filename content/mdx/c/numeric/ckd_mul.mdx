<p class="decl-header">Defined in header <code>&lt;stdckdint.h&gt;</code></p>

```c
#define ckd_mul( result, a, b ) /* implementation-defined */
// exposed interface:

bool ckd_mul( type1* result, type2 a, type3 b );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Computes the multiplication <code>x × y</code> and stores the result into <code>*result</code>. The multiplication is performed as if both operands were represented in a signed integer type with infinite range, and the result was then converted from this integer type to <code>type1</code>. If the value assigned to <code>*result</code> correctly represents the mathematical result of the operation, it returns <code>false</code>. Otherwise, it returns <code>true</code>. In this case, the value assigned to <code>*result</code> is the mathematical result of the operation wrapped around to the width of <code>*result</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>a, b</td><td>-</td><td>integer values</td></tr>
<tr><td>result</td><td>-</td><td>address of where result should be stored</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>false</code> if the value assigned to <code>*result</code> correctly represents the mathematical result of the multiplication, <code>true</code> otherwise.</p>

<h3 id="Note">Note</h3>

<p>Both <code>type2</code> and <code>type3</code> shall be any integer type other than "plain" <code>char</code>, <code>bool</code>, a bit-precise integer type, or an enumerated type, and they can be the same. <code>*result</code> shall be a modifiable lvalue of any integer type other than "plain" <code>char</code>, <code>bool</code>, a bit-precise integer type, or an enumerated type.</p>

<p>It is recommended to produce a diagnostic message if <code>type2</code> or <code>type3</code> are not suitable integer types, or if <code>*result</code> is not a modifiable lvalue of a suitable integer type.</p>
