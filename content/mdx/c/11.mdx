<h3 id="Feature_test_macros_for_optional_features">Feature test macros for optional features</h3>

<ul>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_ANALYZABLE__</code></a>

<ul>
<li>
<p>Indicates analyzability is supported.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_LIB_EXT1__</code></a>

<ul>
<li>
<p>Indicates bounds checking functions are supported.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_NO_ATOMICS__</code></a>

<ul>
<li>
<p>Indicates atomic objects and the atomic operation library are not supported.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_NO_COMPLEX__</code></a>

<ul>
<li>
<p>Indicates complex types and the complex math functions are not supported.</p>
</li>
</ul>

<dl>
<dd><p>These features were mandatory in C99.</p></dd>
</dl>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_NO_THREADS__</code></a>

<ul>
<li>
<p>Indicates thread local storage and the thread support library are not supported.</p>
</li>
</ul>
</li>
<li>
<a href="/reference/c/preprocessor/replace/"><code>__STDC_NO_VLA__</code></a>

<ul>
<li>
<p>Indicates</p>

<a href="/reference/c/language/array/#Variable-length_arrays">variable length arrays and variably modified types</a>

<p>are not supported.</p>
</li>
</ul>

<dl>
<dd><p>These features were mandatory in C99.</p></dd>
</dl>
</li>
</ul>
