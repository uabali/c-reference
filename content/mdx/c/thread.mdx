<p>C includes built-in support for threads, atomic operations, mutual exclusion, condition variables, and thread-specific storages.</p>

<p>These features are optionally provided:</p>

<ul>
<li>
<p>if the macro constant</p>

<code>__STDC_NO_THREADS__</code>

<p>is defined by the compiler, the header</p>

<strong><code>&lt;threads.h&gt;</code></strong>

<p>and all of the names provided in it are not provided;</p>
</li>
<li>
<p>if the macro constant</p>

<code>__STDC_NO_ATOMICS__</code>

<p>is defined by the compiler, the header</p>

<a href="/reference/c/thread/#Atomic_operations"><code>&lt;stdatomic.h&gt;</code></a>

<p>and all of the names provided in it are not provided.</p>
</li>
</ul>

<p>See also <a href="/reference/c/language/atomic/"><code>_Atomic</code> type specifier and qualifier</a>.</p>

<h3 id="Reserved_identifiers">Reserved identifiers</h3>

<p>In future revisions of the C standard:</p>

<ul>
<li>
<p>function names, type names, and enumeration constants that begin with either</p>

<code>cnd_</code>

<p>,</p>

<code>mtx_</code>

<p>,</p>

<code>thrd_</code>

<p>, or</p>

<code>tss_</code>

<p>, and a lowercase letter may be added to the declarations in the</p>

<code>&lt;threads.h&gt;</code>

<p>header;</p>
</li>
<li>
<p>macros that begin with</p>

<code>ATOMIC_</code>

<p>and an uppercase letter may be added to the macros defined in the</p>

<a href="/reference/c/thread/#Atomic_operations"><code>&lt;stdatomic.h&gt;</code></a>

<p>header;</p>
</li>
<li>
<p>typedef names that begin with either</p>

<code>atomic_</code>

<p>or</p>

<code>memory_</code>

<p>, and a lowercase letter may be added to the declarations in the</p>

<a href="/reference/c/thread/#Atomic_operations"><code>&lt;stdatomic.h&gt;</code></a>

<p>header;</p>
</li>
<li>
<p>enumeration constants that begin with</p>

<code>memory_order_</code>

<p>and a lowercase letter may be added to the definition of the</p>

<a href="/reference/c/atomic/memory_order/">memory_order</a>

<p>type in the</p>

<a href="/reference/c/thread/#Atomic_operations"><code>&lt;stdatomic.h&gt;</code></a>

<p>header;</p>
</li>
<li>
<p>function names that begin with</p>

<code>atomic_</code>

<p>and a lowercase letter may be added to the declarations in the</p>

<a href="/reference/c/thread/#Atomic_operations"><code>&lt;stdatomic.h&gt;</code></a>

<p>header.</p>
</li>
</ul>

<p>Identifiers reserved for functions names are always potentially<span class="std std-since std-c23">(since C23)</span> reserved for use as identifiers with external linkage, while other identifiers list here are potentially<span class="std std-since std-c23">(since C23)</span> reserved when <a href="/reference/c/thread/#Atomic_operations"><code>&lt;stdatomic.h&gt;</code></a> is included.</p>

<p>Declaring, defining, or <code>#undef</code>ing such an identifier results in undefined behavior if it is provided by the standard or implementation<span class="std std-since std-c23">(since C23)</span>. Portable programs should not use those identifiers.</p>
