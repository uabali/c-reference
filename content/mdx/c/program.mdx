<h3 id="Program_termination">Program termination</h3>

<p>The following functions manage program termination and resources cleanup.</p>

<table class="ref-table ref-dsc">
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stdlib.h&gt;</code></td></tr>
<tr><td><a href="/reference/c/program/abort/">abort</a></td><td>causes abnormal program termination (without cleaning up)   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/exit/">exit</a></td><td>causes normal program termination with cleaning up   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/quick_exit/">quick_exit</a>

<span class="std std-since std-c11">(C11)</span></td><td>causes normal program termination without completely cleaning up   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/_Exit/">_Exit</a>

<span class="std std-since std-c99">(C99)</span></td><td>causes normal program termination without cleaning up   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/atexit/">atexit</a></td><td>registers a function to be called on <a href="/reference/c/program/exit/">exit()</a> invocation   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/at_quick_exit/">at_quick_exit</a>

<span class="std std-since std-c11">(C11)</span></td><td>registers a function to be called on <a href="/reference/c/program/quick_exit/"><code>quick_exit</code></a> invocation   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/EXIT_status/">EXIT_SUCCESS<br />EXIT_FAILURE</a></td><td>indicates program execution execution status   <span class="mark-note">(macro constant)</span></td></tr>
</table>

<h3 id="Signals">Signals</h3>

<p>Several functions and macro constants for signal management are provided.</p>

<table class="ref-table ref-dsc">
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;signal.h&gt;</code></td></tr>
<tr><td><a href="/reference/c/program/signal/">signal</a></td><td>sets a signal handler for particular signal   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/raise/">raise</a></td><td>runs the signal handler for particular signal   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/program/sig_atomic_t/">sig_atomic_t</a></td><td>the integer type that can be accessed as an atomic entity from an asynchronous signal handler   <span class="mark-note">(typedef)</span></td></tr>
<tr><td><a href="/reference/c/program/SIG_strategies/">SIG_DFL<br />SIG_IGN</a></td><td>defines signal handling strategies   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td><a href="/reference/c/program/SIG_ERR/">SIG_ERR</a></td><td>error was encountered   <span class="mark-note">(macro constant)</span></td></tr>
<tr><td colspan="2">Signal types</td></tr>
<tr><td><a href="/reference/c/program/SIG_types/">SIGABRT<br />SIGFPE<br />SIGILL<br />SIGINT<br />SIGSEGV<br />SIGTERM</a></td><td>defines signal types   <span class="mark-note">(macro constant)</span></td></tr>
</table>
