<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><h3 id="Bounds_checking">Bounds checking</h3>

<p>The standard library provides bounds-checked versions of some existing functions (<a href="/reference/c/io/gets/">gets_s</a>, <a href="/reference/c/io/fopen/">fopen_s</a>, <a href="/reference/c/io/fprintf/">printf_s</a>, <a href="/reference/c/string/byte/strcpy/">strcpy_s</a>, <a href="/reference/c/string/wide/wcscpy/">wcscpy_s</a>, <a href="/reference/c/string/multibyte/mbstowcs/">mbstowcs_s</a>, <a href="/reference/c/algorithm/qsort/">qsort_s</a>, <a href="/reference/c/program/getenv/">getenv_s</a>, etc). This functionality is <em>optional</em> and is only available if <code>__STDC_LIB_EXT1__</code> is defined. The following macros and functions support this functionality.</p>

<table class="ref-table ref-dsc">
<tr><td colspan="2"></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;errno.h&gt;</code></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stdio.h&gt;</code></td></tr>
<tr><td>errno_t

<span class="std std-since std-c11">(C11)</span></td><td>a typedef for the type <code>int</code>, used to self-document functions that return <a href="/reference/c/error/errno/">errno</a> values   <span class="mark-note">(typedef)</span></td></tr>
<tr><td colspan="2"></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stddef.h&gt;</code></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stdio.h&gt;</code></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stdlib.h&gt;</code></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;string.h&gt;</code></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;time.h&gt;</code></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;wchar.h&gt;</code></td></tr>
<tr><td>rsize_t

<span class="std std-since std-c11">(C11)</span></td><td>a typedef for the same type as <a href="/reference/c/types/size_t/">size_t</a>, used to self-document functions that range-check their parameters at runtime   <span class="mark-note">(typedef)</span></td></tr>
<tr><td colspan="2"></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stdint.h&gt;</code></td></tr>
<tr><td>RSIZE_MAX

<span class="std std-since std-c11">(C11)</span></td><td>largest acceptable size for bounds-checked functions, expands to either constant or variable which may change at runtime (e.g. as the currently allocated memory size changes) <span class="mark-note">(macro variable)</span></td></tr>
<tr><td colspan="2"></td></tr>
<tr><td colspan="2"><p>Defined in header</p>

<code>&lt;stdlib.h&gt;</code></td></tr>
<tr><td><a href="/reference/c/error/set_constraint_handler_s/">set_constraint_handler_s</a>

<span class="std std-since std-c11">(C11)</span></td><td>set the error callback for bounds-checked functions   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/error/abort_handler_s/">abort_handler_s</a>

<span class="std std-since std-c11">(C11)</span></td><td>abort callback for the bounds-checked functions   <span class="mark-note">(function)</span></td></tr>
<tr><td><a href="/reference/c/error/ignore_handler_s/">ignore_handler_s</a>

<span class="std std-since std-c11">(C11)</span></td><td>ignore callback for the bounds-checked functions   <span class="mark-note">(function)</span></td></tr>
</table>

<p>Note: implementations of bounds-checked functions are available as open-source libraries <a href="https://github.com/rurban/safeclib/" rel="noreferrer" target="_blank">Safe C</a> and <a href="https://code.google.com/archive/p/slibc/" rel="noreferrer" target="_blank">Slibc</a>, and as part of Watcom C. There is also an incompatible set of bounds-checked functions available in Visual Studio.</p></aside>

<h3 id="Notes">Notes</h3>

<p>Since C23, <a href="/reference/c/language/static_assert/"><code>static_assert</code></a> is itself a keyword, which may also be a predefined macro, so <code>&lt;assert.h&gt;</code> no longer provides it.</p>
