<p class="decl-header">Defined in header <code>&lt;stdarg.h&gt;</code></p>

```c
/* unspecified */ va_list;
```

<p><code>va_list</code> is a complete object type suitable for holding the information needed by the macros va_start, va_copy, va_arg, and va_end.</p>

<p>If a <code>va_list</code> instance is created, passed to another function, and used via va_arg in that function, then any subsequent use in the calling function should be preceded by a call to va_end.</p>

<p>It is legal to pass a pointer to a <code>va_list</code> object to another function and then use that object after the function returns.</p>
