<p>The <strong><code>&lt;stdio.h&gt;</code></strong> header provides generic file operation support and supplies functions with narrow character input/output capabilities.</p>

<p>The <a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a> header supplies functions with wide character input/output capabilities.</p>

<p>I/O streams are denoted by objects of type <a href="/reference/c/io/FILE/">FILE</a> that can only be accessed and manipulated through pointers of type <code>FILE*</code>. Each stream is associated with an external physical device (file, standard input stream, printer, serial port, etc).</p>
