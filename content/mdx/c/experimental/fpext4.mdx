<p>Supplemenatary mathematical functions listed below are merged into C2x standard.</p>

<h3 id="Notes">Notes</h3>

<p>All functions added to the C library by this extension are only declared if a macro <code>__STDC_WANT_IEC_60559_FUNCS_EXT__</code> is defined before math.h is included.</p>

<p>The decimal floating-point variants of every function are only defined if <code>__STDC_WANT_IEC_60559_DFP_EXT__</code> is also defined before math.h is included.</p>

<p>The extended precision variants of every function are only defined if <code>__STDC_WANT_IEC_60559_TYPES_EXT__</code> is defined before math.h is included.</p>

<p>The correctly-rounded versions of all functions (with the <code>cr-</code> prefix) are optional.</p>
