<p class="decl-header">Defined in header <code>&lt;string.h&gt;</code></p>

```c
char * strdup( const char *str1 );
```

<p class="decl-note"><span class="std std-since std-other">(dynamic memory TR)</span></p>

<p>Returns a pointer to a null-terminated byte string, which is a duplicate of the string pointed to by <code>str1</code>. The returned pointer must be passed to <a href="/reference/c/memory/free/">free</a> to avoid a memory leak.</p>

<p>If an error occurs, a null pointer is returned and <a href="/reference/c/error/errno/">errno</a> may be set.</p>

<p>As all functions from Dynamic Memory TR, <code>strdup</code> is only guaranteed to be available if <code>__STDC_ALLOC_LIB__</code> is defined by the implementation and if the user defines <code>__STDC_WANT_LIB_EXT2__</code> to the integer constant <code>1</code> before including <code>string.h</code>.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>str1</td><td>-</td><td>pointer to the null-terminated byte string to duplicate</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>A pointer to the newly allocated string, or a null pointer if an error occurred.</p>

<h3 id="Notes">Notes</h3>

<p>The function is identical to the <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/strdup.html" rel="noreferrer" target="_blank">POSIX strdup</a>.</p>

<h3 id="Example">Example</h3>

```c
#ifdef __STDC_ALLOC_LIB__
#define __STDC_WANT_LIB_EXT2__ 1
#else
#define _POSIX_C_SOURCE 200809L
#endif
 
#include <string.h>
#include <assert.h>
#include <stdlib.h>
 
int main(void)
{
    const char *s1 = "String";
    char *s2 = strdup(s1);
    assert(strcmp(s1, s2) == 0);
    free(s2);
}
```
