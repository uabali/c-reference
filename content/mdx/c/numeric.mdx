<p>The C numerics library includes common mathematical functions and types, as well as support for random number generation.</p>

<h3 id="Common_mathematical_functions"><a href="/reference/c/numeric/math/">Common mathematical functions</a></h3>

<p>The header <a href="/reference/c/numeric/math/"><code>&lt;math.h&gt;</code></a> provides <a href="/reference/c/numeric/math/">standard C library mathematical functions</a> such as <a href="/reference/c/numeric/math/fabs/">fabs</a>, <a href="/reference/c/numeric/math/sqrt/">sqrt</a>, and <a href="/reference/c/numeric/math/sin/">sin</a>.</p>

<h3 id="Floating-point_environment"><a href="/reference/c/numeric/fenv/">Floating-point environment</a></h3>

<p>The header <a href="/reference/c/numeric/fenv/"><code>&lt;fenv.h&gt;</code></a> defines <a href="/reference/c/numeric/fenv/">flags and functions related to exceptional floating-point state</a>, such as overflow and division by zero.</p>

<h3 id="Pseudo-random_number_generation"><a href="/reference/c/numeric/random/">Pseudo-random number generation</a></h3>

<p>The header <a href="/reference/c/program/"><code>&lt;stdlib.h&gt;</code></a> also includes C-style random number generation via <a href="/reference/c/numeric/random/srand/">srand</a> and <a href="/reference/c/numeric/random/rand/">rand</a>.</p>

<h3 id="Complex_number_arithmetic"><a href="/reference/c/numeric/complex/">Complex number arithmetic</a></h3>

<p>The header <a href="/reference/c/numeric/complex/"><code>&lt;complex.h&gt;</code></a> provides types and functions to work with <a href="/reference/c/numeric/complex/">complex numbers</a>.</p>

<h3 id="Bit_manipulation_.28since_C23.29"><a href="/reference/c/numeric/bit_manip/">Bit manipulation</a> <span class="std std-since std-c23">(since C23)</span></h3>

<p>The header <a href="/reference/c/numeric/#Bit_manipulation"><code>&lt;stdbit.h&gt;</code></a> provides macros and functions to work with the <a href="/reference/c/numeric/bit_manip/#Macros">byte ordering</a> and <a href="/reference/c/numeric/bit_manip/#Functions">byte and bit representation</a> of C objects.</p>
