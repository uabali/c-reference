<p><strong>ISO/IEC 9899:2024</strong>, a.k.a. <strong>C23</strong>, is the current revision of the C standard.</p>

<ul>
<li>
<a href="https://open-std.org/JTC1/SC22/WG14/www/docs/n3435.pdf" rel="noreferrer" target="_blank">The latest publicly available WD of C23</a>

<p>(n3435, 2025-01-03).</p>
</li>
<li>
<a href="https://open-std.org/JTC1/SC22/WG14/www/docs/n3149.zip" rel="noreferrer" target="_blank">The latest WD of C23</a>

<p>(n3149, 2023-07-09, a password-protected zip archive, see</p>

<a href="https://open-std.org/JTC1/SC22/WG14/www/docs/n3150.htm" rel="noreferrer" target="_blank">n3150</a>

<p>).</p>
</li>
</ul>

<p>C23 bumps the predefined macro __STDC_VERSION__ to <code>202311L</code>.</p>

<h2 id="Obsolete_features">Obsolete features</h2>

<h3 id="Removed_features">Removed features</h3>

<ul>
<li>
<p>Old-style</p>

<a href="/reference/c/language/function_declaration/">function declarations</a>

<p>and</p>

<a href="/reference/c/language/function_definition/">function definitions</a>
</li>
<li>
<p>Representations for</p>

<a href="/reference/c/language/arithmetic_types/">signed integers</a>

<p>other than two's complement</p>
</li>
<li>
<p>Permission that</p>

<code>u</code>

<p>/</p>

<code>U</code>

<p>-prefixed</p>

<a href="/reference/c/language/character_constant/">character constants</a>

<p>and</p>

<a href="/reference/c/language/string_literal/">string literals</a>

<p>may be not UTF-16/32</p>
</li>
<li>
<p>Mixed wide</p>

<a href="/reference/c/language/string_literal/">string literal</a>

<p>concatenation</p>
</li>
<li>
<p>Support for calling</p>

<a href="/reference/c/memory/realloc/"><code>realloc()</code></a>

<p>with zero size (the behavior becomes undefined)</p>
</li>
<li>
<a href="/reference/c/types/"><code>__alignof_is_defined</code></a>

<p>and</p>

<a href="/reference/c/types/"><code>__alignas_is_defined</code></a>
</li>
<li>
<a href="/reference/c/error/static_assert/"><code>static_assert</code></a>

<p>is not provided as a macro defined in</p>

<a href="/reference/c/error/"><code>&lt;assert.h&gt;</code></a>

<p>(becomes a keyword)</p>
</li>
<li>
<a href="/reference/c/thread/thread_local/"><code>thread_local</code></a>

<p>is not provided as a macro defined in</p>

<a href="/reference/c/thread/"><code>&lt;threads.h&gt;</code></a>

<p>(becomes a keyword)</p>
</li>
</ul>
