<p>Queries the alignment requirement of its operand type.</p>

<h3 id="Syntax">Syntax</h3>

```text
_Alignof( type-name )
alignof( type-name )
```

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c23">(until C23)</span></p><p>This operator is typically used through the convenience macro <a href="/reference/c/types/"><code>alignof</code></a>, which is provided in the header <a href="/reference/c/types/"><code>&lt;stdalign.h&gt;</code></a></p></aside>

<h3 id="Explanation">Explanation</h3>

<p>Returns the <a href="/reference/c/language/object/#Alignment">alignment requirement</a> of the type <a href="/reference/c/language/compatible_type/#Type_names">named</a> by <em>type-name</em>. If <em>type-name</em> is an array type, the result is the alignment requirement of the array element type. The <em>type-name</em> cannot be function type or an incomplete type.</p>

<p>The result is an integer constant of type <a href="/reference/c/types/size_t/">size_t</a>.</p>

<p>The operand is not evaluated (so external identifiers used in the operand do not have to be defined).</p>

<p>If <em>type-name</em> is a <a href="/reference/c/language/array/">VLA</a> type, its size expression is not evaluated.</p>

<h3 id="Notes">Notes</h3>

<p>The use of <code>_Alignof</code><span class="std std-until std-c23">(until C23)</span><code>alignof</code><span class="std std-since std-c23">(since C23)</span> with expressions is allowed by some C compilers as a non-standard extension.</p>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/alignof/"><code>alignof</code></a>, <a href="/reference/c/keyword/_Alignof/"><code>_Alignof</code></a></p>

<h3 id="Example">Example</h3>

```c
#include <stdalign.h>
#include <stddef.h>
#include <stdio.h>
 
int main(void)
{
    printf("Alignment of char = %zu\n", alignof(char));
    printf("Alignment of max_align_t = %zu\n", alignof(max_align_t));
    printf("alignof(float[10]) = %zu\n", alignof(float[10]));
    printf("alignof(struct{char c; int n;}) = %zu\n",
            alignof(struct {char c; int n;}));
}
```

<p>Possible output:</p>

```text
Alignment of char = 1
Alignment of max_align_t = 16
alignof(float[10]) = 4
alignof(struct{char c; int n;}) = 4
```
