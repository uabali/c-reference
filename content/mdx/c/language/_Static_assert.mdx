<h3 id="Syntax">Syntax</h3>

```text
_Static_assert ( expression , message )
static_assert ( expression , message )
_Static_assert ( expression )
static_assert ( expression )
```

<table class="ref-table ref-params">
<tr><td><em>expression</em></td><td>-</td><td>any <a href="/reference/c/language/constant_expression/">integer constant expression</a></td></tr>
<tr><td><em>message</em></td><td>-</td><td>any <a href="/reference/c/language/string_literal/">string literal</a></td></tr>
</table>

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c23">(until C23)</span></p><p>This keyword is also available as convenience macro <a href="/reference/c/error/static_assert/"><code>static_assert</code></a>, available in the header <a href="/reference/c/error/"><code>&lt;assert.h&gt;</code></a>.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>Both of <code>static_assert</code> and <code>_Static_assert</code> have the same effects. <code>_Static_assert</code> is a deprecated spelling that is kept for compatibility.</p>

<p>An implementation may also define <code>static_assert</code> and/or <code>_Static_assert</code> as predefined macros, and <code>static_assert</code> is no longer provided by <a href="/reference/c/error/"><code>&lt;assert.h&gt;</code></a>.</p></aside>

<h3 id="Explanation">Explanation</h3>

<p>The constant expression is evaluated at compile time and compared to zero. If it compares equal to zero, a compile-time error occurs and the compiler must display <em>message</em> as part of the error message (except that characters not in <a href="/reference/c/language/charset/">basic character set</a> are not required to be displayed)<span class="std std-until std-c23">(until C23)</span>should display <em>message</em> (if provided) as part of the error message<span class="std std-since std-c23">(since C23)</span>.</p>

<p>Otherwise, if <em>expression</em> does not equal zero, nothing happens; no code is emitted.</p>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/_Static_assert/"><code>_Static_assert</code></a>, <a href="/reference/c/keyword/static_assert/"><code>static_assert</code></a></p>

<h3 id="Example">Example</h3>

```c
#include <assert.h> // no longer needed since C23
 
int main(void)
{
    // Test if math works, C23:
    static_assert((2 + 2) % 3 == 1, "Whoa dude, you knew!");
    // Pre-C23 alternative:
    _Static_assert(2 + 2 * 2 == 6, "Lucky guess!?");
 
    // This will produce an error at compile time.
    // static_assert(sizeof(int) < sizeof(char), "Unmet condition!");
 
    constexpr int _42 = 2 * 3 * 2 * 3 + 2 * 3;
    static_assert(_42 == 42); // the message string can be omitted.
 
    // const int _13 = 13;
    // Compile time error - not an integer constant expression:
    // static_assert(_13 == 13);
}
```
