<p>Every <a href="/reference/c/language/object/">object</a> in C exists, has a constant address, retains its last-stored value (except when the value is indeterminate), and, for VLA, retains its size<span class="std std-since std-c99">(since C99)</span> over a portion of program execution known as this object's <em>lifetime</em>.</p>

<p>For the objects that are declared with automatic, static, and thread storage duration, lifetime equals their <a href="/reference/c/language/storage_duration/">storage duration</a> (note the difference between non-VLA and VLA automatic storage duration).</p>

<p>For the objects with allocated storage duration, the lifetime begins when the allocation function returns (including the return from <a href="/reference/c/memory/realloc/">realloc</a>) and ends when the <a href="/reference/c/memory/realloc/">realloc</a> or deallocation function is called. Note that since allocated objects have no <a href="/reference/c/language/object/">declared type</a>, the type of the lvalue expression first used to access this object becomes its <a href="/reference/c/language/object/">effective type</a>.</p>

<p>Accessing an object outside of its lifetime is undefined behavior.</p>

```c
int* foo(void) {
    int a = 17; // a has automatic storage duration
    return &a;
}  // lifetime of a ends
int main(void) {
    int* p = foo(); // p points to an object past lifetime ("dangling pointer")
    int n = *p; // undefined behavior
}
```

<p>A pointer to an object (or one past the object) whose lifetime ended has indeterminate value.</p>

<h3 id="Temporary_lifetime">Temporary lifetime</h3>

<p>Struct and union objects with array members (either direct or members of nested struct/union members) that are designated by <a href="/reference/c/language/value_category/">non-lvalue expressions</a>, have <em>temporary lifetime</em>. Temporary lifetime begins when the expression that refers to such object is evaluated and ends at the next <a href="/reference/c/language/eval_order/">sequence point</a><span class="std std-until std-c11">(until C11)</span>when the containing full expression or full declarator ends<span class="std std-since std-c11">(since C11)</span>.</p>

<p>Any attempt to modify an object with temporary lifetime results in undefined behavior.</p>

```c
struct T { double a[4]; };
struct T f(void) { return (struct T){3.15}; }
double g1(double* x) { return *x; }
void g2(double* x) { *x = 1.0; }
int main(void)
{
    double d = g1(f().a); // C99: UB access to a[0] in g1 whose lifetime ended
                          //      at the sequence point at the start of g1
                          // C11: OK, d is 3.15
    g2(f().a); // C99: UB modification of a[0] whose lifetime ended at the sequence point
               // C11: UB attempt to modify a temporary object
}
```
