<p>These are the punctuation symbols in C. The meaning of each symbol is detailed in the linked pages.</p>

<h3 id=".7B_.7D"><code>{</code> <code>}</code></h3>

<ul>
<li>
<p>In a</p>

<a href="/reference/c/language/struct/">struct</a>

<p>or</p>

<a href="/reference/c/language/union/">union</a>

<p>definition, delimit the</p>

<em>struct-declaration-list</em>

<p>.</p>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/enum/">enum</a>

<p>definition, delimit the enumerator list.</p>
</li>
<li>
<p>Delimit a</p>

<a href="/reference/c/language/statements/#Compound_statements">compound statement</a>

<p>. The compound statement may be part of a</p>

<a href="/reference/c/language/function_definition/">function definition</a>

<p>.</p>
</li>
<li>
<p>In</p>

<a href="/reference/c/language/initialization/">initialization</a>

<p>, delimit the initializers.</p>
</li>
</ul>

<h3 id=".5B_.5D"><code>[</code> <code>]</code></h3>

<ul>
<li>
<a href="/reference/c/language/operator_member_access/#Subscript">Subscript operator</a>

<p>.</p>
</li>
<li>
<p>Part of</p>

<a href="/reference/c/language/declarations/#Declarators">array declarator</a>

<p>in a</p>

<a href="/reference/c/language/declarations/">declaration</a>

<p>or a</p>

<a href="/reference/c/language/compatible_type/#Type_names">type-id</a>

<p>.</p>
</li>
<li>
<p>In</p>

<a href="/reference/c/language/initialization/">initialization</a>

<p>, introduce a designator for an array element.</p>

<span class="std std-since std-c99">(since C99)</span>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/attributes/">attribute specifier</a>

<p>, delimit the attributes.</p>

<span class="std std-since std-c23">(since C23)</span>
</li>
</ul>

<ul>
<li>
<p>Introduce a</p>

<a href="/reference/c/preprocessor/">preprocessing directive</a>

<p>.</p>
</li>
<li>
<p>The</p>

<a href="/reference/c/preprocessor/replace/#.23_and_.23.23_operators">preprocessing operator for stringification</a>

<p>.</p>
</li>
</ul>

<ul>
<li>

<a href="/reference/c/preprocessor/replace/#.23_and_.23.23_operators">preprocessing operator for token pasting</a>

<p>.</p>
</li>
</ul>

<h3 id=".28_.29"><code>(</code> <code>)</code></h3>

<ul>
<li>
<p>In an expression,</p>

<a href="/reference/c/language/expressions/#Primary_expressions">indicate grouping</a>

<p>.</p>
</li>
<li>
<a href="/reference/c/language/operator_other/#Function_call">Function call operator</a>

<p>.</p>
</li>
<li>
<p>In a</p>

<a href="/reference/c/language/sizeof/"><code>sizeof</code></a>

, <a href="/reference/c/language/alignof/"><code>_Alignof</code></a><span class="std std-since std-c11">(since C11)</span>

, <a href="/reference/c/language/typeof_unqual/"><code>typeof</code></a> or <a href="/reference/c/language/typeof_unqual/"><code>typeof_unqual</code></a><span class="std std-since std-c23">(since C23)</span>

<p>expression, delimit the operand.</p>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/cast/">explicit cast</a>

<p>, delimit the type-id.</p>
</li>
<li>
<p>In a</p>

<a href="/reference/c/language/compound_literal/">compound literal</a>

<p>, delimit the type-id.</p>

<span class="std std-since std-c99">(since C99)</span>
</li>
<li>
<p>In a</p>

<a href="/reference/c/language/declarations/">declaration</a>

<p>or a</p>

<a href="/reference/c/language/compatible_type/#Type_names">type-id</a>

<p>, indicate grouping.</p>
</li>
<li>
<p>In a</p>

<a href="/reference/c/language/function_declaration/">function declarator</a>

<p>(in a</p>

<a href="/reference/c/language/declarations/">declaration</a>

<p>or a</p>

<a href="/reference/c/language/compatible_type/#Type_names">type-id</a>

<p>), delimit the parameter list.</p>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/if/"><code>if</code></a>

<p>,</p>

<a href="/reference/c/language/switch/"><code>switch</code></a>

<p>,</p>

<a href="/reference/c/language/while/"><code>while</code></a>

<p>,</p>

<a href="/reference/c/language/do/"><code>do-while</code></a>

<p>, or</p>

<a href="/reference/c/language/for/"><code>for</code></a>

<p>statement, delimit the controlling clause.</p>
</li>
<li>
<p>In a</p>

<a href="/reference/c/preprocessor/replace/#Function-like_macros">function-like macro definition</a>

<p>, delimit the macro parameters.</p>
</li>
<li>
<p>In a</p>

<a href="/reference/c/preprocessor/replace/#Function-like_macros">function-like macro invocation</a>

<p>, delimit the macro arguments or prevent commas from being interpreted as argument separators.</p>
</li>
<li>
<p>Part of a</p>

<code>defined</code>

, <code>__has_include</code>, <code>__has_embed</code> or <code>__has_c_attribute</code><span class="std std-since std-c23">(since C23)</span>

<p>preprocessing operator.</p>
</li>
<li>
<p>Part of a</p>

<a href="/reference/c/language/generic/">generic selection expression</a>

<p>.</p>

<span class="std std-since std-c11">(since C11)</span>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/atomic/"><code>_Atomic</code></a>

<p>type specifier, delimit the type-id.</p>

<span class="std std-since std-c11">(since C11)</span>
</li>
<li>
<p>In a</p>

<a href="/reference/c/language/static_assert/">static assertion declaration</a>

<p>, delimit the operands.</p>

<span class="std std-since std-c11">(since C11)</span>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/alignas/"><code>_Alignas</code></a>

<p>specifier, delimit the operand.</p>

<span class="std std-since std-c11">(since C11)</span>
</li>
<li>
<p>In an</p>

<a href="/reference/c/language/attributes/">attribute</a>

<p>, delimit the attribute arguments.</p>

<span class="std std-since std-c23">(since C23)</span>
</li>
<li>
<p>In a bit-precise integer type name (</p>

<code>_BitInt(N)</code>

<p>), delimit the size.</p>

<span class="std std-since std-c23">(since C23)</span>
</li>
<li>
<p>Part of</p>

<a href="/reference/c/preprocessor/replace/"><code>__VA_OPT__</code></a>

<p>replacement in a variadic macro definition.</p>

<span class="std std-since std-c23">(since C23)</span>
</li>
<li>
<p>In a preprocessor parameter used in</p>

<a href="/reference/c/preprocessor/embed/"><code>#embed</code> directives</a>

<p>and</p>

<code>__has_embed</code>

<p>preprocessing expressions, delimit the preprocessor parameter clause.</p>

<span class="std std-since std-c23">(since C23)</span>
</li>
</ul>
