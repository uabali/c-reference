<p>Logical operators apply standard boolean algebra operations to their operands.</p>

<table class="ref-table">
<tr><th>Operator</th><th>Operator name</th><th>Example</th><th>Result</th></tr>
<tr><td><code>!</code></td><td>logical NOT</td><td><code>!a</code></td><td>the logical negation of <strong>a</strong></td></tr>
<tr><td><code>&amp;&amp;</code></td><td>logical AND</td><td><code>a &amp;&amp; b</code></td><td>the logical AND of <strong>a</strong> and <strong>b</strong></td></tr>
<tr><td><code>||</code></td><td>logical OR</td><td><code>a || b</code></td><td>the logical OR of <strong>a</strong> and <strong>b</strong></td></tr>
</table>

<h3 id="Logical_NOT">Logical NOT</h3>

<p>The logical NOT expression has the form</p>

```text
! expression
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>expression</em></td><td>-</td><td>an expression of any <a href="/reference/c/language/compatible_type/#Type_groups">scalar type</a></td></tr>
</table>

<p>The logical NOT operator has type <code>int</code>. Its value is <code>0</code> if <em>expression</em> evaluates to a value that compares unequal to zero. Its value is <code>1</code> if <em>expression</em> evaluates to a value that compares equal to zero. (so <code>!E</code> is the same as <code>(0==E)</code>)</p>

```c
#include <stdbool.h>
#include <stdio.h>
#include <ctype.h>
int main(void)
{
    bool b = !(2+2 == 4); // not true
    printf("!(2+2==4) = %s\n", b ? "true" : "false");
 
    int n = isspace('a'); // non-zero if 'a' is a space, zero otherwise
    int x = !!n; // "bang-bang", common C idiom for mapping integers to [0,1]
                 // (all non-zero values become 1)
    char *a[2] = {"non-space", "space"};
    puts(a[x]); // now x can be safely used as an index to array of 2 strings
}
```

<p>Output:</p>

```text
!(2+2==4) = false
non-space
```

<h3 id="Logical_AND">Logical AND</h3>

<p>The logical AND expression has the form</p>

```text
lhs && rhs
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>lhs</em></td><td>-</td><td>an expression of any scalar type</td></tr>
<tr><td><em>rhs</em></td><td>-</td><td>an expression of any scalar type, which is only evaluated if <em>lhs</em> does not compare equal to <code>0</code></td></tr>
</table>

<p>The logical-AND operator has type <code>int</code> and the value <code>1</code> if both <em>lhs</em> and <em>rhs</em> compare unequal to zero. It has the value <code>0</code> otherwise (if either <em>lhs</em> or <em>rhs</em> or both compare equal to zero).</p>

<p>There is a <a href="/reference/c/language/eval_order/">sequence point</a> after the evaluation of <em>lhs</em>. If the result of <em>lhs</em> compares equal to zero, then <em>rhs</em> is not evaluated at all (so-called <em>short-circuit evaluation</em>)</p>

```c
#include <stdbool.h>
#include <stdio.h>
int main(void)
{
    bool b = 2+2==4 && 2*2==4; // b == true
 
    1 > 2 && puts("this won't print");
 
    char *p = "abc";
    if(p && *p) // common C idiom: if p is not null
                // AND if p does not point at the end of the string
    {           // (note that thanks to short-circuit evaluation, this
                //  will not attempt to dereference a null pointer)
    // ...      // ... then do some string processing
    }
}
```

<h3 id="Logical_OR">Logical OR</h3>

<p>The logical OR expression has the form</p>

```text
lhs || rhs
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>lhs</em></td><td>-</td><td>an expression of any scalar type</td></tr>
<tr><td><em>rhs</em></td><td>-</td><td>an expression of any scalar type, which is only evaluated if <em>lhs</em> compares equal to <code>0</code></td></tr>
</table>

<p>The logical-OR operator has type <code>int</code> and the value <code>1</code> if either <em>lhs</em> or <em>rhs</em> compare unequal to zero. It has value <code>0</code> otherwise (if both <em>lhs</em> and <em>rhs</em> compare equal to zero).</p>

<p>There is a <a href="/reference/c/language/eval_order/">sequence point</a> after the evaluation of <em>lhs</em>. If the result of <em>lhs</em> compares unequal to zero, then <em>rhs</em> is not evaluated at all (so-called <em>short-circuit evaluation</em>)</p>

```c
#include <stdbool.h>
#include <stdio.h>
#include <string.h>
#include <errno.h>
int main(void)
{
    bool b = 2+2 == 4 || 2+2 == 5; // true
    printf("true or false = %s\n", b ? "true" : "false");
 
    // logical OR can be used simialar to perl's "or die", as long as rhs has scalar type
    fopen("test.txt", "r") || printf("could not open test.txt: %s\n", strerror(errno));
}
```

<p>Possible output:</p>

```text
true or false = true
could not open test.txt: No such file or directory
```
