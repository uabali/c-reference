<p>The C language standard precisely specifies the <a href="/reference/c/language/as_if/">observable behavior</a> of C language programs, except for the ones in the following categories:</p>

<ul>
<li>
<em>undefined behavior</em>

<p>- there are no restrictions on the behavior of the program. Examples of undefined behavior are memory accesses outside of array bounds, signed integer overflow, null pointer dereference, modification of the same scalar</p>

<a href="/reference/c/language/eval_order/">more than once</a>

<p>in an expression without sequence points, access to an object through a pointer of a different type, etc. Compilers are not required to diagnose undefined behavior (although many simple situations are diagnosed), and the compiled program is not required to do anything meaningful.</p>
</li>
</ul>

<ul>
<li>
<em>unspecified behavior</em>

<p>- two or more behaviors are permitted and the implementation is not required to document the effects of each behavior. For example,</p>

<a href="/reference/c/language/eval_order/">order of evaluation</a>

<p>, whether identical</p>

<a href="/reference/c/language/string_literal/">string literals</a>

<p>are distinct, etc. Each unspecified behavior results in one of a set of valid results and may produce a different result when repeated in the same program.</p>
</li>
</ul>

<ul>
<li>
<em>implementation-defined behavior</em>

<p>- unspecified behavior where each implementation documents how the choice is made. For example, number of bits in a byte, or whether signed integer right shift is arithmetic or logical.</p>
</li>
</ul>

<ul>
<li>
<em>locale-specific behavior</em>

<p>- implementation-defined behavior that depends on the</p>

<a href="/reference/c/locale/setlocale/">currently chosen locale</a>

<p>. For example, whether</p>

<a href="/reference/c/string/byte/islower/">islower</a>

<p>returns true for any character other than the 26 lowercase Latin letters.</p>
</li>
</ul>

<p>(Note: <a href="/reference/c/language/conformance/">Strictly conforming</a> programs do not depend on any unspecified, undefined, or implementation-defined behavior)</p>

<p>The compilers are required to issue diagnostic messages (either errors or warnings) for any programs that violates any C syntax rule or semantic constraint, even if its behavior is specified as undefined or implementation-defined or if the compiler provides a language extension that allows it to accept such program. Diagnostics for undefined behavior are not otherwise required.</p>

<h3 id="UB_and_optimization">UB and optimization</h3>

<p>Because correct C programs are free of undefined behavior, compilers may produce unexpected results when a program that actually has UB is compiled with optimization enabled:</p>

<p>For example,</p>

<h4 id="Signed_overflow">Signed overflow</h4>

```c
int foo(int x)
{
    return x + 1 > x; // either true or UB due to signed overflow
}
```

<p>may be compiled as (<a href="https://godbolt.org/z/9dh7b71TK" rel="noreferrer" target="_blank">demo</a>)</p>

```c
foo:
        mov     eax, 1
        ret
```

<h4 id="Access_out_of_bounds">Access out of bounds</h4>

```c
int table[4] = {0};
int exists_in_table(int v)
{
    // return 1 in one of the first 4 iterations or UB due to out-of-bounds access
    for (int i = 0; i <= 4; i++)
        if (table[i] == v)
            return 1;
    return 0;
}
```

<p>May be compiled as (<a href="https://godbolt.org/z/48bn19Tsb" rel="noreferrer" target="_blank">demo</a>)</p>

```c
exists_in_table:
        mov     eax, 1
        ret
```

<h4 id="Uninitialized_scalar">Uninitialized scalar</h4>

```c
_Bool p; // uninitialized local variable
if (p) // UB access to uninitialized scalar
    puts("p is true");
if (!p) // UB access to uninitialized scalar
    puts("p is false");
```

<p>May produce the following output (observed with an older version of gcc):</p>

```c
p is true
p is false
```

```c
size_t f(int x)
{
    size_t a;
    if (x) // either x nonzero or UB
        a = 42;
    return a;
}
```

<p>May be compiled as (<a href="https://godbolt.org/z/9nz6EMPTG" rel="noreferrer" target="_blank">demo</a>)</p>

```c
f:
        mov     eax, 42
        ret
```

<h4 id="Invalid_scalar">Invalid scalar</h4>

```c
int f(void)
{
    _Bool b = 0;
    unsigned char* p = (unsigned char*)&b;
    *p = 10;
    // reading from b is now UB
    return b == 0;
}
```

<p>May be compiled as (<a href="https://godbolt.org/z/rjx77bjoh" rel="noreferrer" target="_blank">demo</a>)</p>

```c
f:
        mov     eax, 11
        ret
```

<h4 id="Null_pointer_dereference">Null pointer dereference</h4>

```c
int foo(int* p)
{
    int x = *p;
    if (!p)
        return x; // Either UB above or this branch is never taken
    else
        return 0;
}
 
int bar()
{
    int* p = NULL;
    return *p;    // Unconditional UB
}
```

<p>may be compiled as (<a href="https://godbolt.org/z/8jnjMjcPz" rel="noreferrer" target="_blank">demo</a>)</p>

```c
foo:
        xor     eax, eax
        ret
bar:
        ret
```

<h4 id="Access_to_pointer_passed_to_realloc">Access to pointer passed to <a href="/reference/c/memory/realloc/">realloc</a></h4>

<p>Choose clang to observe the output shown</p>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    int *p = (int*)malloc(sizeof(int));
    int *q = (int*)realloc(p, sizeof(int));
    *p = 1; // UB access to a pointer that was passed to realloc
    *q = 2;
    if (p == q) // UB access to a pointer that was passed to realloc
        printf("%d%d\n", *p, *q);
}
```

<p>Possible output:</p>

```text
12
```

<h4 id="Infinite_loop_without_side-effects">Infinite loop without side-effects</h4>

<p>Choose clang to observe the output shown</p>

```c
#include <stdio.h>
 
int fermat()
{
    const int MAX = 1000;
    // Endless loop with no side effects is UB
    for (int a = 1, b = 1, c = 1; 1;)
    {
        if (((a * a * a) == ((b * b * b) + (c * c * c))))
            return 1;
        ++a;
        if (a > MAX)
        {
            a = 1;
            ++b;
        }
        if (b > MAX)
        {
            b = 1;
            ++c;
        }
        if (c > MAX)
            c = 1;
    }
    return 0;
}
 
int main(void)
{
    if (fermat())
        puts("Fermat's Last Theorem has been disproved.");
    else
        puts("Fermat's Last Theorem has not been disproved.");
}
```

<p>Possible output:</p>

```text
Fermat's Last Theorem has been disproved.
```
