<p>Causes the enclosing <a href="/reference/c/language/for/">for</a>, <a href="/reference/c/language/while/">while</a> or <a href="/reference/c/language/do/">do-while</a> loop or <a href="/reference/c/language/switch/">switch statement</a> to terminate.</p>

<p>Used when it is otherwise awkward to terminate the loop using the condition expression and conditional statements.</p>

<h3 id="Syntax">Syntax</h3>

```text
attr-spec-seq (optional) break ;
```

<table class="ref-table ref-params">
<tr><td><em>attr-spec-seq</em></td><td>-</td><td><span class="std std-since std-c23">(C23)</span> optional list of <a href="/reference/c/language/attributes/">attributes</a>, applied to the <code>break</code> statement</td></tr>
</table>

<p>Appears only within the <em>statement</em> of a loop body (<a href="/reference/c/language/while/"><code>while</code></a>, <a href="/reference/c/language/do/"><code>do-while</code></a>, <a href="/reference/c/language/for/"><code>for</code></a>) or within the <em>statement</em> of a <a href="/reference/c/language/switch/"><code>switch</code></a>.</p>

<h3 id="Explanation">Explanation</h3>

<p>After this statement the control is transferred to the statement or declaration immediately following the enclosing loop or switch, as if by <a href="/reference/c/language/goto/"><code>goto</code></a>.</p>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/break/"><code>break</code></a></p>

<h3 id="Notes">Notes</h3>

<p>A break statement cannot be used to break out of multiple nested loops. The <a href="/reference/c/language/goto/"><code>goto</code> statement</a> may be used for this purpose.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
 
int main(void)
{
    int i = 2;
    switch (i)
    {
        case 1: printf("1");
        case 2: printf("2");   // i==2, so execution starts at this case label
        case 3: printf("3");
        case 4:
        case 5: printf("45");
                break;         // execution of subsequent cases is terminated
        case 6: printf("6");
    }
    printf("\n");
 
    // Compare outputs from these two nested for loops.
    for (int j = 0; j < 2; j++)
        for (int k = 0; k < 5; k++)
            printf("%d%d ", j,k);
    printf("\n");
 
    for (int j = 0; j < 2; j++)
    {
        for (int k = 0; k < 5; k++) // only this loop is exited by break
        {
            if (k == 2)
                break;
            printf("%d%d ", j,k);
        }
    }
}
```

<p>Possible output:</p>

```text
2345
00 01 02 03 04 10 11 12 13 14
00 01 10 11
```
