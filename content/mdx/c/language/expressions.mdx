<p>An expression is a sequence of <em>operators</em> and their <em>operands</em>, that specifies a computation.</p>

<p>Expression evaluation may produce a result (e.g., evaluation of <code>2 + 2</code> produces the result <code>4</code>), may generate side-effects (e.g. evaluation of <code>printf(&quot;%d&quot;, 4)</code> sends the character <code>&#x27;4&#x27;</code> to the standard output stream), and may designate objects or functions.</p>

<h4 id="General">General</h4>

<ul>
<li>
<a href="/reference/c/language/value_category/">value categories</a>

<p>(lvalue, non-lvalue object, function designator) classify expressions by their values</p>
</li>
<li>
<a href="/reference/c/language/eval_order/">order of evaluation</a>

<p>of arguments and subexpressions specifies the order in which intermediate results are obtained</p>
</li>
</ul>

<h4 id="Conversions">Conversions</h4>

<ul>
<li>

<p>take place when types of operands do not match the expectations of operators</p>
</li>
<li>
<a href="/reference/c/language/cast/">Casts</a>

<p>may be used to explicitly convert values from one type to another.</p>
</li>
</ul>

<h3 id="Primary_expressions">Primary expressions</h3>

<p>The operands of any operator may be other expressions or they may be <em>primary expressions</em> (e.g. in <code>1 + 2 * 3</code>, the operands of operator+ are the subexpression <code>2 * 3</code> and the primary expression <code>1</code>).</p>

<p>Primary expressions are any of the following:</p>

<p class="li-note"><span class="li-num">1)</span>  Constants and literals (e.g. <code>2</code> or <code>&quot;Hello, world&quot;</code>)</p>

<p class="li-note"><span class="li-num">2)</span>  Suitably declared <a href="/reference/c/language/identifier/">identifiers</a> (e.g. <code>n</code> or <code>printf</code>)</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p class="li-note"><span class="li-num">3)</span>  <a href="/reference/c/language/generic/">Generic selections</a></p></aside>

<p>Any expression in parentheses is also classified as a primary expression: this guarantees that the parentheses have higher precedence than any operator.</p>

<h4 id="Constants_and_literals">Constants and literals</h4>

<p>Constant values of certain types may be embedded in the source code of a C program using specialized expressions known as literals (for lvalue expressions) and constants (for non-lvalue expressions)</p>

<ul>
<li>
<a href="/reference/c/language/integer_constant/">integer constants</a>

<p>are decimal, octal, or hexadecimal numbers of integer type.</p>
</li>
<li>
<a href="/reference/c/language/character_constant/">character constants</a>

<p>are individual characters of type</p>

<code>int</code>

<p>suitable for conversion to a character type or of type</p>

<code>char8_t</code>,<span class="std std-since std-c23">(since C23)</span>

<code>char16_t</code>, <code>char32_t</code>, or<span class="std std-since std-c11">(since C11)</span>

<code>wchar_t</code>
</li>
<li>
<a href="/reference/c/language/floating_constant/">floating constants</a>

<p>are values of type</p>

<code>float</code>

<p>,</p>

<code>double</code>

<p>, or</p>

<code>long double</code>
</li>
</ul>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><ul>
<li>
<p>predefined constants</p>

<a href="/reference/c/language/bool_constant/"><code>true</code>/<code>false</code></a>

<p>are values of type</p>

<code>bool</code>
</li>
<li>
<p>predefined constant</p>

<a href="/reference/c/language/nullptr/"><code>nullptr</code></a>

<p>is a value of type</p>

<a href="/reference/c/types/nullptr_t/">nullptr_t</a>
</li>
</ul></aside>

<ul>
<li>
<a href="/reference/c/language/string_literal/">string literals</a>

<p>are sequences of characters of type</p>

<code>char[]</code>

, <code>char8_t[]</code><span class="std std-since std-c23">(since C23)</span>

, <code>char16_t[]</code>, <code>char32_t[]</code>,<span class="std std-since std-c11">(since C11)</span>

<p>or</p>

<code>wchar_t[]</code>

<p>that represent null-terminated strings</p>
</li>
</ul>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><ul>
<li>
<a href="/reference/c/language/compound_literal/">compound literals</a>

<p>are values of struct, union, or array type directly embedded in program code</p>
</li>
</ul></aside>

<h3 id="Unevaluated_expressions">Unevaluated expressions</h3>

<p>The operands of the <a href="/reference/c/language/sizeof/"><code>sizeof</code> operator</a> are expressions that are not evaluated (unless they are VLAs)<span class="std std-since std-c99">(since C99)</span>. Thus, <code>size_t n = sizeof(printf(&quot;%d&quot;, 4));</code> does not perform console output.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p>The operands of the <a href="/reference/c/language/alignof/"><code>_Alignof</code></a><span class="std std-until std-c23">(until C23)</span><a href="/reference/c/language/alignof/"><code>alignof</code></a><span class="std std-since std-c23">(since C23)</span> operator, the controlling expression of a <a href="/reference/c/language/generic/">generic selection</a>, and size expressions of VLAs that are operands of <code>_Alignof</code><span class="std std-until std-c23">(until C23)</span><code>alignof</code><span class="std std-since std-c23">(since C23)</span> are also expressions that are not evaluated.</p></aside>
