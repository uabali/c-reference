<p>Terminates current function and returns specified value to the caller function.</p>

<h3 id="Syntax">Syntax</h3>

```text
attr-spec-seq(optional) return expression ;
attr-spec-seq(optional) return ;
```

<table class="ref-table ref-params">
<tr><td><em>expression</em></td><td>-</td><td>expression used for initializing the return value of the function</td></tr>
<tr><td><em>attr-spec-seq</em></td><td>-</td><td><span class="std std-since std-c23">(C23)</span>optional list of <a href="/reference/c/language/attributes/">attributes</a>, applied to the <code>return</code> statement</td></tr>
</table>

<h3 id="Explanation">Explanation</h3>

<p class="li-note"><span class="li-num">1)</span>  Evaluates the <em>expression</em>, terminates the current function and returns the result of the <em>expression</em> to the caller (the value returned becomes the value of the function call expression). Only valid if the function return type is not <code>void</code>.</p>

<p class="li-note"><span class="li-num">2)</span>  Terminates the current function. Only valid if the function return type is <code>void</code>.</p>

<p>If the type of the <em>expression</em> is different from the return type of the function, its value is <a href="/reference/c/language/conversion/">converted</a> as if by assignment to an object whose type is the return type of the function, except that overlap between object representations is permitted:</p>

```c
struct s { double i; } f(void); // function returning struct s
union { struct { int f1; struct s f2; } u1;
        struct { struct s f3; int f4; } u2; } g;
struct s f(void)
{
    return g.u1.f2;
}
int main(void)
{
// g.u2.f3 = g.u1.f2; // undefined behavior (overlap in assignment)
   g.u2.f3 = f();     // well-defined
}
```

<p>If the return type is a real floating type, the result may be represented in <a href="/reference/c/types/limits/FLT_EVAL_METHOD/">greater range and precision</a> than implied by the new type.</p>

<p>Reaching the end of a function returning <code>void</code> is equivalent to <code>return;</code>. Reaching the end of any other value-returning function is undefined behavior if the result of the function is used in an expression (it is allowed to discard such return value). For <code>main</code>, see <a href="/reference/c/language/main_function/"><code>main</code> function</a>.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p>Executing the <code>return</code> statement in a <a href="/reference/c/language/_Noreturn/">no-return function</a> is undefined behavior.</p></aside>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/return/"><code>return</code></a></p>

<h3 id="Example">Example</h3>

<table class="ref-table">

```c
#include <stdio.h>
 
void fa(int i)
{
    if (i == 2)
       return;
    printf("fa():   %d\n", i);
} // implied return;
 
int fb(int i)
{
    if (i > 4)
       return 4;
    printf("fb():   %d\n", i);
    return 2;
}
 
int main(void)
{
    fa(2);
    fa(1);
    int i = fb(5);   // the return value 4 used to initializes i
    i = fb(i);       // the return value 2 used as rhs of assignment
    printf("main(): %d\n", i);
}
```

<p>Output:</p>

```text
fa():   1
fb():   4
main(): 2
```
