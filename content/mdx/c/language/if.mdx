<p>Conditionally executes code.</p>

<p>Used where code needs to be executed only if some condition is true.</p>

<h3 id="Syntax">Syntax</h3>

```text
attr-spec-seq(optional) if ( expression ) statement-true
attr-spec-seq(optional) if ( expression ) statement-true else statement-false
```

<table class="ref-table ref-params">
<tr><td><em>attr-spec-seq</em></td><td>-</td><td><span class="std std-since std-c23">(C23)</span>optional list of <a href="/reference/c/language/attributes/">attributes</a>, applied to the <code>if</code> statement</td></tr>
<tr><td><em>expression</em></td><td>-</td><td>an <a href="/reference/c/language/expressions/">expression</a> of any scalar type</td></tr>
<tr><td><em>statement-true</em></td><td>-</td><td>any <a href="/reference/c/language/statements/">statement</a> (often a compound statement), which is executed if <em>expression</em> compares not equal to <code>0</code></td></tr>
<tr><td><em>statement-false</em></td><td>-</td><td>any <a href="/reference/c/language/statements/">statement</a> (often a compound statement), which is executed if <em>expression</em> compares equal to <code>0</code></td></tr>
</table>

<h3 id="Explanation">Explanation</h3>

<p><em>expression</em> must be an expression of any <a href="/reference/c/language/compatible_type/#Type_groups">scalar type</a>.</p>

<p>If <em>expression</em> compares not equal to the integer zero, <em>statement-true</em> is executed.</p>

<p>In the form (2), if <em>expression</em> compares equal to the integer zero, <em>statement_false</em> is executed.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><p>As with all other selection and iteration statements, the entire if-statement has its own block scope:</p>

```c
enum {a, b};
int different(void)
{
    if (sizeof(enum {b, a}) != sizeof(int))
        return a; // a == 1
    return b; // b == 0 in C89, b == 1 in C99
}
```</aside>

<h3 id="Notes">Notes</h3>

<p>The <code>else</code> is always associated with the closest preceding <code>if</code> (in other words, if <em>statement-true</em> is also an if statement, then that inner if statement must contain an <code>else</code> part as well):</p>

```c
int j = 1;
if (i > 1)
   if(j > 2)
       printf("%d > 1 and %d > 2\n", i, j);
    else // this else is part of if(j>2), not part of if(i>1) 
       printf("%d > 1 and %d <= 2\n", i, j);
```

<p>If <em>statement-true</em> is entered through a <a href="/reference/c/language/goto/">goto</a>, <em>statement-false</em> is not executed.</p>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/if/"><code>if</code></a>, <a href="/reference/c/keyword/else/"><code>else</code></a></p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
 
int main(void)
{
    int i = 2;
    if (i > 2) {
        printf("first is true\n");
    } else {
        printf("first is false\n");
    }
 
    i = 3;
    if (i == 3) printf("i == 3\n");
 
    if (i != 3) printf("i != 3 is true\n");
    else        printf("i != 3 is false\n");
}
```

<p>Output:</p>

```text
first is false
i == 3
i != 3 is false
```
