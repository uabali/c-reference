<h2 id="Early_C">Early C</h2>

<ul>
<li>
<p>1969: B created, based on BCPL, to replace PDP-7 assembler as the system programming language for Unix</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<p>added operators</p>

<code>++</code>

<p>,</p>

<code>--</code>

<p>, compound assignment, remained a typeless language like BCPL</p>
</li>
</ul></dd>
</dl>

<ul>
<li>
<p>1971: NB ("new B") created when porting B to PDP-11</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<p>types (</p>

<code>int</code>

<p>,</p>

<code>char</code>

<p>, arrays and pointers), array-to-pointer conversion, compilation to machine code</p>
</li>
</ul></dd>
</dl>

<ul>
<li>
<p>1972: Language renamed to C</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<code>struct</code>

<p>, operators</p>

<code>&amp;&amp;</code>

<p>and</p>

<code>||</code>

<p>, preprocessor, portable I/O</p>
</li>
</ul></dd>
</dl>

<ul>
<li>
<p>1973: Unix re-written in C</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<code>unsigned</code>

<p>,</p>

<code>long</code>

<p>,</p>

<code>union</code>

<p>, enumerations, increased type safety</p>
</li>
</ul></dd>
</dl>

<ul>
<li>
<p>1978: The C Programming Language, 1st edition</p>
</li>
</ul>

<h2 id="Standard_C">Standard C</h2>

<ul>
<li>
<p>1983: ANSI established X3J11 committee</p>
</li>
<li>
<p>1988: The C Programming Language, 2nd edition</p>
</li>
<li>
<p>1989:</p>

<strong>C89</strong>

<p>, the ANSI C standard published</p>
</li>
</ul>

<ol>
<li>
<p>codified existing practices</p>
</li>
<li>
<p>new features:</p>

<code>volatile</code>

<p>,</p>

<code>enum</code>

<p>,</p>

<code>signed</code>

<p>,</p>

<code>void</code>

<p>, locales</p>
</li>
<li>
<p>From C++:</p>

<code>const</code>

<p>, function prototypes</p>
</li>
</ol>

<ul>
<li>
<p>1990:</p>

<strong>C90</strong>

<p>, the ANSI C standard accepted as ISO/IEC 9899:1990</p>
</li>
<li>
<p>1994: Technical corrigendum 1 (ISO/IEC 9899:1990/Cor.1:1994)</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<a href="https://open-std.org/JTC1/SC22/WG14/www/docs/tc1.htm" rel="noreferrer" target="_blank">44 small changes</a>
</li>
</ul></dd>
</dl>

<ul>
<li>
<p>1995:</p>

<strong>C95</strong>

<p>(ISO/IEC 9899:1990/Amd.1:1995) (</p>

<a href="https://infostore.saiglobal.com/store/Details.aspx?DocN=isoc000767513" rel="noreferrer" target="_blank">online store</a>

<p>)</p>
</li>
</ul>

<ol>
<li>
<p>greatly expanded wide and multibyte character support (</p>

<a href="/reference/c/string/wide/"><code>&lt;wctype.h&gt;</code></a>

<p>,</p>

<a href="/reference/c/string/wide/"><code>&lt;wchar.h&gt;</code></a>

</li>
<li>
<p>digraphs,</p>

<a href="/reference/c/language/operator_alternative/"><code>&lt;iso646.h&gt;</code></a>

</li>
</ol>

<ul>
<li>

<a href="https://open-std.org/JTC1/SC22/WG14/www/docs/tc2.htm" rel="noreferrer" target="_blank">24 small changes</a>

</ul></dd>
</dl>

<ul>
<li>
<p>1999:</p>

<strong>C99</strong>

<p>(ISO/IEC 9899:1999)</p>
</li>
</ul>

<ol>
<li>
<p>new features:</p>

<code>bool</code>

<p>,</p>

<code>long long</code>

<p>,</p>

<a href="/reference/c/types/integer/"><code>&lt;stdint.h&gt;</code></a>

<p>,</p>

<a href="/reference/c/types/integer/"><code>&lt;inttypes.h&gt;</code></a>

<p>,</p>

<code>restrict</code>

<p>, compound literals, variable length arrays, flexible array members, designated initializers,</p>

<a href="/reference/c/numeric/fenv/"><code>&lt;fenv.h&gt;</code></a>

<p>, variadic macros, complex numbers,</p>

<code>__func__</code>

<p>, hexadecimal floating-point format (</p>

<code>%a</code>

<p>), monetary formatting in</p>

<a href="/reference/c/locale/lconv/">lconv</a>

<p>,</p>

<a href="/reference/c/string/byte/isblank/">isblank</a>

<p>, concatenation of narrow and wide string literals, trailing comma in enumerations, empty arguments in function-like macros,</p>

<code>STDC_*</code>

<p>pragmas,</p>

va_copy

<p>, null return of</p>

<a href="/reference/c/io/tmpnam/">tmpnam</a>

<p>, null pointer in</p>

<a href="/reference/c/io/setvbuf/">setvbuf</a>

<p>,</p>

<code>hh</code>

<p>and</p>

<code>ll</code>

<p>length-specifiers in</p>

<a href="/reference/c/io/fprintf/">printf</a>

<p>,</p>

<a href="/reference/c/io/fprintf/">snprintf</a>

<p>,</p>

<a href="/reference/c/program/_Exit/">_Exit</a>

<p>,</p>

<a href="/reference/c/numeric/tgmath/"><code>&lt;tgmath.h&gt;</code></a>

<p>, POSIX-like</p>

<a href="/reference/c/chrono/strftime/">strftime</a>

<p>specifiers</p>
</li>
<li>
<p>from C++:</p>

<code>inline</code>

<p>, mix declarations and code, declarations in the init-clause of the for loop,</p>

<code>//</code>

<p>comments, universal character names in source code</p>
</li>
<li>
<p>removed implicit functions and implicit</p>

<code>int</code>
</li>
</ol>
