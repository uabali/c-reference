<h3 id="Syntax">Syntax</h3>

```text
'c-char '
u8'c-char '
u'c-char '
U'c-char '
L'c-char '
'c-char-sequence '
L'c-char-sequence '
u'c-char-sequence '
U'c-char-sequence '
```

<p>where</p>

<ul>
<li>
<em>c-char</em>

<p>is either</p>
</li>
</ul>

<dl>
<dd><ul>
<li>
<p>a character from the basic source character set minus single-quote (</p>

<code>&#x27;</code>

<p>), backslash (</p>

<code>\</code>

<p>), or the newline character.</p>
</li>
<li>
<p>escape sequence: one of special character escapes</p>

<code>\&#x27;</code>

<code>\&quot;</code>

<code>\?</code>

<code>\\</code>

<code>\a</code>

<code>\b</code>

<code>\f</code>

<code>\n</code>

<code>\r</code>

<code>\t</code>

<code>\v</code>

<p>, hex escapes</p>

<code>\x...</code>

<p>or octal escapes</p>

<code>\...</code>

<p>as defined in</p>

<a href="/reference/c/language/escape/">escape sequences</a>

<p>.</p>
</li>
</ul></dd>
</dl>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><dl>
<dd><ul>
<li>
<p>universal character name,</p>

<code>\u...</code>

<p>or</p>

<code>\U...</code>

<p>as defined in</p>

<a href="/reference/c/language/escape/">escape sequences</a>

<p>.</p>
</li>
</ul></dd>
</dl></aside>

<ul>
<li>
<em>c-char-sequence</em>

<p>is a sequence of two or more</p>

<em>c-char</em>

<p>s.</p>
</li>
</ul>

<p class="li-note"><span class="li-num">1)</span>  single-byte integer character constant, e.g. <code>&#x27;a&#x27;</code> or <code>&#x27;\n&#x27;</code> or <code>&#x27;\13&#x27;</code>. Such constant has type <code>int</code> and a value equal to the representation of <em>c-char</em> in the execution character set as a value of type <code>char</code> mapped to <code>int</code>. If <em>c-char</em> is not representable as a single byte in the execution character set, the value is implementation-defined.</p>

<p class="li-note"><span class="li-num">2)</span>  UTF-8 character constant, e.g. <code>u8&#x27;a&#x27;</code>. Such constant has type <code>char8_t</code> and the value equal to ISO 10646 code point value of <em>c-char</em>, provided that the code point value is representable with a single UTF-8 code unit (that is, <em>c-char</em> is in the range 0x0-0x7F, inclusive). If <em>c-char</em> is not representable with a single UTF-8 code unit, the program is ill-formed.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c23">(until C23)</span></p><p class="li-note"><span class="li-num">3)</span>  16-bit wide character constant, e.g. <code>u&#x27;貓&#x27;</code>, but not <code>u&#x27;🍌&#x27;</code> (<code>u&#x27;\U0001f34c&#x27;</code>). Such constant has type <code>char16_t</code> and a value equal to the value of <em>c-char</em> in the 16-bit encoding produced by <a href="/reference/c/string/multibyte/mbrtoc16/">mbrtoc16</a> (normally UTF-16). If <em>c-char</em> is not representable or maps to more than one 16-bit character, the value is implementation-defined.</p>

<p class="li-note"><span class="li-num">4)</span>  32-bit wide character constant, e.g. <code>U&#x27;貓&#x27;</code> or <code>U&#x27;🍌&#x27;</code>. Such constant has type <code>char32_t</code> and a value equal to the value of <em>c-char</em> in in the 32-bit encoding produced by <a href="/reference/c/string/multibyte/mbrtoc32/">mbrtoc32</a> (normally UTF-32). If <em>c-char</em> is not representable or maps to more than one 32-bit character, the value is implementation-defined.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p class="li-note"><span class="li-num">3)</span>  UTF-16 character constant, e.g. <code>u&#x27;貓&#x27;</code>, but not <code>u&#x27;🍌&#x27;</code> (<code>u&#x27;\U0001f34c&#x27;</code>). Such constant has type <code>char16_t</code> and the value equal to ISO 10646 code point value of <em>c-char</em>, provided that the code point value is representable with a single UTF-16 code unit (that is, <em>c-char</em> is in the range 0x0-0xD7FF or 0xE000-0xFFFF, inclusive). If <em>c-char</em> is not representable with a single UTF-16 code unit, the program is ill-formed.</p>

<p class="li-note"><span class="li-num">4)</span>  UTF-32 character constant, e.g. <code>U&#x27;貓&#x27;</code> or <code>U&#x27;🍌&#x27;</code>. Such constant has type <code>char32_t</code> and the value equal to ISO 10646 code point value of <em>c-char</em>, provided that the code point value is representable with a single UTF-32 code unit (that is, <em>c-char</em> is in the range 0x0-0xD7FF or 0xE000-0x10FFFF, inclusive). If <em>c-char</em> is not representable with a single UTF-32 code unit, the program is ill-formed.</p></aside>

<p class="li-note"><span class="li-num">5)</span>  wide character constant, e.g. <code>L&#x27;β&#x27;</code> or <code>L&#x27;貓</code>. Such constant has type <code>wchar_t</code> and a value equal to the value of <em>c-char</em> in the execution wide character set (that is, the value that would be produced by <a href="/reference/c/string/multibyte/mbtowc/">mbtowc</a>). If <em>c-char</em> is not representable or maps to more than one wide character (e.g. a non-BMP value on Windows where <code>wchar_t</code> is 16-bit), the value is implementation-defined .</p>

<p class="li-note"><span class="li-num">6)</span>  multicharacter constant, e.g. <code>&#x27;AB&#x27;</code>, has type <code>int</code> and implementation-defined value.</p>

<p class="li-note"><span class="li-num">7)</span>  wide multicharacter constant, e.g. <code>L&#x27;AB&#x27;</code>, has type <code>wchar_t</code> and implementation-defined value.</p>

<p class="li-note"><span class="li-num">8)</span>  16-bit multicharacter constant, e.g. <code>u&#x27;CD&#x27;</code>, has type <code>char16_t</code> and implementation-defined value.</p>

<p class="li-note"><span class="li-num">9)</span>  32-bit multicharacter constant, e.g. <code>U&#x27;XY&#x27;</code>, has type <code>char32_t</code> and implementation-defined value.</p>

<h3 id="Notes">Notes</h3>

<p>Multicharacter constants were inherited by C from the B programming language. Although not specified by the C standard, most compilers (MSVC is a notable exception) implement multicharacter constants as specified in B: the values of each char in the constant initialize successive bytes of the resulting integer, in big-endian zero-padded right-adjusted order, e.g. the value of <code>&#x27;\1&#x27;</code> is <code>0x00000001</code> and the value of <code>&#x27;\1\2\3\4&#x27;</code> is <code>0x01020304</code>.</p>

<p>In C++, encodable ordinary character literals have type <code>char</code>, rather than <code>int</code>.</p>

<p>Unlike <a href="/reference/c/language/integer_constant/">integer constants</a>, a character constant may have a negative value if <code>char</code> is signed: on such implementations <code>&#x27;\xFF&#x27;</code> is an <code>int</code> with the value <code>-1</code>.</p>

<p>When used in a controlling expression of <a href="/reference/c/preprocessor/conditional/"><code>#if</code></a> or <a href="/reference/c/preprocessor/conditional/"><code>#elif</code></a>, character constants may be interpreted in terms of the source character set, the execution character set, or some other implementation-defined character set.</p>

<p>16/32-bit multicharacter constants are not widely supported and removed in C23. Some common implementations (e.g. clang) do not accept them at all.</p>

<h3 id="Example">Example</h3>

```c
#include <stddef.h>
#include <stdio.h>
#include <uchar.h>
 
int main (void)
{
    printf("constant value     \n");
    printf("-------- ----------\n");
 
    // integer character constants,
    int c1='a'; printf("'a':\t %#010x\n", c1);
    int c2='🍌'; printf("'🍌':\t %#010x\n\n", c2); // implementation-defined
 
    // multicharacter constant
    int c3='ab'; printf("'ab':\t %#010x\n\n", c3); // implementation-defined
 
    // 16-bit wide character constants
    char16_t uc1 = u'a'; printf("'a':\t %#010x\n", (int)uc1);
    char16_t uc2 = u'¢'; printf("'¢':\t %#010x\n", (int)uc2);
    char16_t uc3 = u'猫'; printf("'猫':\t %#010x\n", (int)uc3);
    // implementation-defined (🍌 maps to two 16-bit characters)
    char16_t uc4 = u'🍌'; printf("'🍌':\t %#010x\n\n", (int)uc4);
 
    // 32-bit wide character constants
    char32_t Uc1 = U'a'; printf("'a':\t %#010x\n", (int)Uc1);
    char32_t Uc2 = U'¢'; printf("'¢':\t %#010x\n", (int)Uc2);
    char32_t Uc3 = U'猫'; printf("'猫':\t %#010x\n", (int)Uc3);
    char32_t Uc4 = U'🍌'; printf("'🍌':\t %#010x\n\n", (int)Uc4);
 
    // wide character constants
    wchar_t wc1 = L'a'; printf("'a':\t %#010x\n", (int)wc1);
    wchar_t wc2 = L'¢'; printf("'¢':\t %#010x\n", (int)wc2);
    wchar_t wc3 = L'猫'; printf("'猫':\t %#010x\n", (int)wc3);
    wchar_t wc4 = L'🍌'; printf("'🍌':\t %#010x\n\n", (int)wc4);
}
```
