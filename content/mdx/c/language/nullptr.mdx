<h3 id="Syntax">Syntax</h3>

```text
nullptr
```

<h3 id="Explanation">Explanation</h3>

<p>The keyword <code>nullptr</code> denotes a predefined null pointer constant. It is a <a href="/reference/c/language/value_category/#Non-lvalue_object_expressions">non-lvalue</a> of type <a href="/reference/c/types/nullptr_t/">nullptr_t</a>. <code>nullptr</code> can be <a href="/reference/c/language/conversion/">converted</a> to a pointer types or <code>bool</code>, where the result is the null pointer value of that type or <code>false</code> respectively.</p>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/nullptr/"><code>nullptr</code></a></p>

<h3 id="Example">Example</h3>

<p>Demonstrates that a copy of <code>nullptr</code> can also be used as a null pointer constant.</p>

```c
#include <stddef.h>
#include <stdio.h>
 
void g(int*)
{
    puts("Function g called");
}
 
#define DETECT_NULL_POINTER_CONSTANT(e) \
    _Generic(e,                         \
        void* : puts("void*"),          \
        nullptr_t : puts("nullptr_t"),  \
        default : puts("integer")       \
    )
 
int main()
{
    g(nullptr); // OK
    g(NULL); // OK
    g(0); // OK
 
    auto cloned_nullptr = nullptr;
    g(cloned_nullptr); // OK
 
    [[maybe_unused]] auto cloned_NULL = NULL;
//  g(cloned_NULL); // implementation-defined: maybe OK
 
    [[maybe_unused]] auto cloned_zero = 0;
//  g(cloned_zero); // Error
 
    DETECT_NULL_POINTER_CONSTANT(((void*)0));
    DETECT_NULL_POINTER_CONSTANT(0);
    DETECT_NULL_POINTER_CONSTANT(nullptr);
    DETECT_NULL_POINTER_CONSTANT(NULL); // implementation-defined
}
```

<p>Possible output:</p>

```text
Function g called
Function g called
Function g called
Function g called
void*
integer
nullptr_t
void*
```
