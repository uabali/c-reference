<p>Member access operators allow access to the members of their operands.</p>

<table class="ref-table">
<tr><th>Operator</th><th>Operator name</th><th>Example</th><th>Description</th></tr>
<tr><td><code>[]</code></td><td>array subscript</td><td><code>a[b]</code></td><td>access the <strong>b</strong>th element of array <strong>a</strong></td></tr>
<tr><td><code>*</code></td><td>pointer dereference</td><td><code>*a</code></td><td>dereference the pointer <strong>a</strong> to access the object or function it refers to</td></tr>
<tr><td><code>&amp;</code></td><td>address of</td><td><code>&amp;a</code></td><td>create a pointer that refers to the object or function <strong>a</strong></td></tr>
<tr><td><code>.</code></td><td>member access</td><td><code>a.b</code></td><td>access member <strong>b</strong> of <a href="/reference/c/language/struct/">struct</a> or <a href="/reference/c/language/union/">union</a> <strong>a</strong></td></tr>
<tr><td><code>-&gt;</code></td><td>member access through pointer</td><td><code>a-&gt;b</code></td><td>access member <strong>b</strong> of <a href="/reference/c/language/struct/">struct</a> or <a href="/reference/c/language/union/">union</a> pointed to by <strong>a</strong></td></tr>
</table>

<h3 id="Subscript">Subscript</h3>

<p>The array subscript expression has the form</p>

```text
pointer-expression [ integer-expression ]
integer-expression [ pointer-expression ]
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>pointer-expression</em></td><td>-</td><td>an <a href="/reference/c/language/expressions/">expression</a> of type pointer to complete object</td></tr>
<tr><td><em>integer-expression</em></td><td>-</td><td>an <a href="/reference/c/language/expressions/">expression</a> of integer type</td></tr>
</table>

<p>The subscript operator expression is an <a href="/reference/c/language/value_category/">lvalue expression</a> whose type is the type of the object pointed to by <em>pointer-expression</em>.</p>

<p>By definition, the subscript operator <code>E1[E2]</code> is exactly identical to <code>*((E1)+(E2))</code>. If <em>pointer-expression</em> is an array expression, it undergoes <a href="/reference/c/language/conversion/">lvalue-to-rvalue conversion</a> and becomes a pointer to the first element of the array.</p>

<p>Due to the definition of the <a href="/reference/c/language/operator_arithmetic/">addition between a pointer and an integer</a>, the result is the element of the array with the index equal to the result of <em>integer-expression</em> (or, if <em>pointer-expression</em> was pointing at ith element of some array, the index of the result is i plus the result of <em>integer-expression</em>)</p>

<p>Note: see <a href="/reference/c/language/array/">array</a> for the details on multidimensional arrays.</p>

```c
#include <stdio.h>
int main(void)
{
    int a[3] = {1,2,3};
    printf("%d %d\n", a[2],  // n == 3
                      2[a]); // same, n == 3
    a[2] = 7; // subscripts are lvalues
 
    int n[2][3] = {{1,2,3},{4,5,6}};
    int (*p)[3] = &n[1]; // elements of n are arrays
    printf("%d %d %d\n", (*p)[0], p[0][1], p[0][2]); // access n[1][] via p
    int x = n[1][2]; // applying [] again to the array n[1]
    printf("%d\n", x);
 
    printf("%c %c\n", "abc"[2], 2["abc"]); // string literals are arrays too
}
```

<p>Output:</p>

```text
3 3
4 5 6
6
c c
```

<h3 id="Dereference">Dereference</h3>

<p>The <em>dereference</em> or <em>indirection</em> expression has the form</p>

```text
* pointer-expression
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>pointer-expression</em></td><td>-</td><td>an <a href="/reference/c/language/expressions/">expression</a> of any pointer type</td></tr>
</table>

<p>If <em>pointer-expression</em> is a pointer to function, the result of the dereference operator is a function designator for that function.</p>

<p>If <em>pointer-expression</em> is a pointer to object, the result is an <a href="/reference/c/language/value_category/">lvalue expression</a> that designates the pointed-to object.</p>

<p>Dereferencing a null pointer, a pointer to an object outside of its lifetime (a dangling pointer), a misaligned pointer, or a pointer with indeterminate value is undefined behavior, except when the dereference operator is nullified by applying the address-of operator to its result, as in <code>&amp;*E</code>.</p>

```c
#include <stdio.h>
int main(void)
{
    int n = 1;
    int* p = &n;
    printf("*p = %d\n", *p); // the value of *p is what's stored in n
    *p = 7; // *p is lvalue
    printf("*p = %d\n", *p);
}
```

<p>Output:</p>

```text
*p = 1
*p = 7
```

<h3 id="Address_of">Address of</h3>

<p>The address-of expression has the form</p>

```text
& function
& lvalue-expression
& * expression
& expression [ expression ]
```

<p class="li-note"><span class="li-num">1)</span>  address of a function</p>

<p class="li-note"><span class="li-num">2)</span>  address of an object</p>

<p class="li-note"><span class="li-num">3)</span>  special case: <code>&amp;</code> and <code>*</code> cancel each other, neither one is evaluated</p>

<p class="li-note"><span class="li-num">4)</span>  special case: <code>&amp;</code> and the <code>*</code> that is implied in <code>[]</code> cancel each other, only the addition implied in <code>[]</code> is evaluated.</p>

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>lvalue-expression</em></td><td>-</td><td>an <a href="/reference/c/language/value_category/">lvalue</a> expression of any type that is not a <a href="/reference/c/language/bit_field/">bit-field</a> and does not have <a href="/reference/c/language/storage_duration/">register</a> storage class</td></tr>
</table>

<p>The address-of operator produces the <a href="/reference/c/language/value_category/">non-lvalue</a> address of its operand, suitable for initializing a pointer to the type of the operand. If the operand is a function designator (1), the result is a pointer to function. If the operand is an object (2), the result is a pointer to object.</p>

<p>If the operand is the dereference operator, no action is taken (so it's okay to apply &amp;* to a null pointer), except that the result is not an lvalue.</p>

<p>If the operand is an array index expression, no action is taken other than the array-to-pointer conversion and the addition, so &amp;a[N] is valid for an array of size N (obtaining a pointer one past the end is okay, dereferencing it is not, but dereference cancels out in this expression).</p>

```c
int f(char c) { return c;}
int main(void)
{
   int n = 1;
   int *p = &n; // address of object n
   int (*fp)(char) = &f; // address of function f
   int a[3] = {1,2,3};
   int *beg=a, *end=&a[3]; // same as end = a+3
}
```

<h3 id="Member_access">Member access</h3>

<p>The member access expression has the form</p>

```text
expression . member-name
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>expression</em></td><td>-</td><td>an expression of <a href="/reference/c/language/struct/">struct</a> or <a href="/reference/c/language/union/">union</a> type</td></tr>
<tr><td><em>member-name</em></td><td>-</td><td>an <a href="/reference/c/language/identifier/">identifier</a> that names a member of the struct or union designated by <em>expression</em></td></tr>
</table>

<p>The member access expression designates the named member of the <a href="/reference/c/language/struct/">struct</a> or <a href="/reference/c/language/union/">union</a> designated by its left operand. It has the same <a href="/reference/c/language/value_category/">value category</a> as its left operand.</p>

<p>If the left operand is <a href="/reference/c/language/const/">const</a> or <a href="/reference/c/language/volatile/">volatile</a> qualified, the result is also qualified. If the left operand is <a href="/reference/c/language/atomic/">atomic</a>, the behavior is undefined.</p>

<p>Note: besides identifiers that name objects of struct or union type, the following expressions may have struct or union types: <a href="/reference/c/language/operator_assignment/">assignment</a>, <a href="/reference/c/language/operator_other/#Function_call">function call</a>, <a href="/reference/c/language/operator_other/#Comma_operator">comma operator</a>, <a href="/reference/c/language/operator_other/#Conditional_operator">conditional operator</a>, and <a href="/reference/c/language/compound_literal/">compound literal</a>.</p>

```c
#include <stdio.h>
struct s {int x;};
struct s f(void) { return (struct s){1}; }
int main(void)
{
    struct s s;
    s.x = 1; // ok, changes the member of s
    int n = f().x; // f() is an expression of type struct s
//  f().x = 1; // Error: this member access expression is not an lvalue
 
    const struct s sc;
//  sc.x = 3;  // Error: sc.x is const, can't be assigned
 
    union { int x; double d; } u = {1};
    u.d = 0.1; // changes the active member of the union
}
```

<h3 id="Member_access_through_pointer">Member access through pointer</h3>

<p>The member access expression has the form</p>

```text
expression -> member-name
```

<p>where</p>

<table class="ref-table ref-params">
<tr><td><em>expression</em></td><td>-</td><td>an expression of type <a href="/reference/c/language/pointer/">pointer</a> to <a href="/reference/c/language/struct/">struct</a> or <a href="/reference/c/language/union/">union</a></td></tr>
<tr><td><em>member-name</em></td><td>-</td><td>an <a href="/reference/c/language/identifier/">identifier</a> that names a member of the struct or union pointed by <em>expression</em></td></tr>
</table>

<p>The member access through pointer expression designates the named member of the <a href="/reference/c/language/struct/">struct</a> or <a href="/reference/c/language/union/">union</a> type pointed to by its left operand. Its value category is always <a href="/reference/c/language/value_category/">lvalue</a></p>

<p>If the type pointed to by the left operand is <a href="/reference/c/language/const/">const</a> or <a href="/reference/c/language/volatile/">volatile</a> qualified, the result is also qualified. If the type pointed to by the left operand is <a href="/reference/c/language/atomic/">atomic</a>, the behavior is undefined.</p>

```c
#include <stdio.h>
struct s {int x;};
int main(void)
{
    struct s s={1}, *p = &s;
    p->x = 7; // changes the value of s.x through the pointer
    printf("%d\n", p->x); // prints 7
}
```
