<p>A function is a C language construct that associates a <a href="/reference/c/language/statements/#Compound_statements">compound statement</a> (the function body) with an <a href="/reference/c/language/identifier/">identifier</a> (the function name). Every C program begins execution from the <a href="/reference/c/language/main_function/">main function</a>, which either terminates, or invokes other, user-defined or library functions.</p>

```c
// function definition.
// defines a function with the name "sum" and with the body "{ return x+y; }"
int sum(int x, int y) 
{
    return x + y;
}
```

<p>A function is introduced by a <a href="/reference/c/language/function_declaration/">function declaration</a> or a <a href="/reference/c/language/function_definition/">function definition</a>.</p>

<p>Functions may accept zero or more <em>parameters</em>, which are initialized from the <em>arguments</em> of a <a href="/reference/c/language/operator_other/#Function_call">function call operator</a>, and may return a value to its caller by means of the <a href="/reference/c/language/return/">return statement</a>.</p>

```c
int n = sum(1, 2); // parameters x and y are initialized with the arguments 1 and 2
```

<p>The body of a function is provided in a <a href="/reference/c/language/function_definition/">function definition</a>. Each non-<a href="/reference/c/language/inline/">inline</a><span class="std std-since std-c99">(since C99)</span> function that is used in an expression (unless <a href="/reference/c/language/expressions/#Unevaluated_expressions">unevaluated</a>) must be <a href="/reference/c/language/extern/#One_definition_rule">defined only once</a> in a program.</p>

<p>There are no nested functions (except where allowed through non-standard compiler extensions): each function definition must appear at file scope, and functions have no access to the local variables from the caller:</p>

```c
int main(void) // the main function definition
{
    int sum(int, int); // function declaration (may appear at any scope)
    int x = 1;  // local variable in main
    sum(1, 2); // function call
 
//    int sum(int a, int b) // error: no nested functions
//    {
//        return  a + b; 
//    }
}
int sum(int a, int b) // function definition
{
//    return x + a + b; //  error: main's x is not accessible within sum
    return a + b;
}
```
