<p>Executes code according to the value of an integral argument.</p>

<p>Used where one or several out of many branches of code need to be executed according to an integral value.</p>

<h3 id="Syntax">Syntax</h3>

```text
attr-spec-seq(optional) switch ( expression ) statement
```

<table class="ref-table ref-params">
<tr><td><em>attr-spec-seq</em></td><td>-</td><td><span class="std std-since std-c23">(C23)</span>optional list of <a href="/reference/c/language/attributes/">attributes</a>, applied to the <code>switch</code> statement</td></tr>
<tr><td><em>expression</em></td><td>-</td><td>any <a href="/reference/c/language/expressions/">expression</a> of <a href="/reference/c/language/compatible_type/#Type_groups">integer type</a> (char, signed or unsigned integer, or enumeration)</td></tr>
<tr><td><em>statement</em></td><td>-</td><td>any <a href="/reference/c/language/statements/">statement</a> (typically a compound statement). <code>case:</code> and <code>default:</code> labels are permitted in <em>statement</em>, and <code>break;</code> statement has special meaning.</td></tr>
</table>

```text
case constant-expression : statement
attr-spec-seq(optional) case constant-expression : statement(optional)
default : statement
attr-spec-seq(optional) default : statement(optional)
```

<table class="ref-table ref-params">
<tr><td><em>constant-expression</em></td><td>-</td><td>any integer <a href="/reference/c/language/constant_expression/">constant expression</a></td></tr>
<tr><td><em>attr-spec-seq</em></td><td>-</td><td><span class="std std-since std-c23">(C23)</span>optional list of <a href="/reference/c/language/attributes/">attributes</a>, applied to the label</td></tr>
</table>

<h3 id="Explanation">Explanation</h3>

<p>The body of a switch statement may have an arbitrary number of <code>case:</code> labels, as long as the values of all <em>constant-expressions</em> are unique (after <a href="/reference/c/language/conversion/">conversion</a> to the <a href="/reference/c/language/conversion/#Integer_promotions">promoted type</a> of <em>expression</em>). At most one <code>default:</code> label may be present (although nested switch statements may use their own <code>default:</code> labels or have <code>case:</code> labels whose constants are identical to the ones used in the enclosing switch).</p>

<p>If <em>expression</em> evaluates to the value that is equal to the value of one of <em>constant-expression</em>s after conversion to the promoted type of <em>expression</em>, then control is transferred to the statement that is labeled with that <em>constant-expression</em>.</p>

<p>If <em>expression</em> evaluates to a value that doesn't match any of the <code>case:</code> labels, and the <code>default:</code> label is present, control is transferred to the statement labeled with the <code>default:</code> label.</p>

<p>If <em>expression</em> evaluates to a value that doesn't match any of the <code>case:</code> labels, and the <code>default:</code> label is not present, none of the switch body is executed.</p>

<p>The <a href="/reference/c/language/break/">break</a> statement, when encountered anywhere in <em>statement</em>, exits the switch statement:</p>

```c
switch(1) {
    case 1 : puts("1"); // prints "1",
    case 2 : puts("2"); // then prints "2" ("fall-through")
}
```

```c
switch(1) {
    case 1 : puts("1"); // prints "1"
             break;     // and exits the switch
    case 2 : puts("2");
             break;
}
```

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><p>As with all other selection and iteration statements, the switch statement establishes <a href="/reference/c/language/scope/">block scope</a>: any identifier introduced in the <em>expression</em> goes out of scope after the <em>statement</em>.</p>

<p>If a VLA or another identifier with variably-modified type has a <code>case:</code> or a <code>default:</code> label within its scope, the entire switch statement must be in its scope (in other words, a VLA must be declared either before the entire switch or after the last label):</p>

```c
switch (expr)
{
        int i = 4; // not a VLA; OK to declare here
        f(i); // never called
//      int a[i]; // error: VLA cannot be declared here
    case 0:
        i = 17;
    default:
        int a[i]; // OK to declare VLA here
        printf("%d\n", i); // prints 17 if expr == 0, prints indeterminate value otherwise
}
```</aside>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/switch/"><code>switch</code></a>, <a href="/reference/c/keyword/case/"><code>case</code></a>, <a href="/reference/c/keyword/default/"><code>default</code></a></p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
 
void func(int x)
{
   printf("func(%d): ", x);
   switch(x)
   {
      case 1: printf("case 1, ");
      case 2: printf("case 2, ");
      case 3: printf("case 3.\n"); break;
      case 4: printf("case 4, ");
      case 5:
      case 6: printf("case 5 or case 6, ");
      default: printf("default.\n");
   }
}
 
int main(void)
{
   for(int i = 1; i < 9; ++i) func(i);
}
```

<p>Output:</p>

```text
func(1): case 1, case 2, case 3.
func(2): case 2, case 3.
func(3): case 3.
func(4): case 4, case 5 or case 6, default.
func(5): case 5 or case 6, default.
func(6): case 5 or case 6, default.
func(7): default.
func(8): default.
```
