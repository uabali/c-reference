<p>Executes a <em>statement</em> repeatedly until the value of the condition <em>expression</em> becomes false. The test takes place after each iteration.</p>

<h3 id="Syntax">Syntax</h3>

```text
attr-spec-seq(optional) do statement while ( expression ) ;
```

<table class="ref-table ref-params">
<tr><td><em>expression</em></td><td>-</td><td>any <a href="/reference/c/language/expressions/">expression</a> of <a href="/reference/c/language/compatible_type/#Type_groups">scalar type</a>. This expression is evaluated after each iteration, and if it compares equal to zero, the loop is exited.</td></tr>
<tr><td><em>statement</em></td><td>-</td><td>any <a href="/reference/c/language/statements/">statement</a>, typically a compound statement, which is the body of the loop</td></tr>
<tr><td><em>attr-spec-seq</em></td><td>-</td><td><span class="std std-since std-c23">(C23)</span>optional list of <a href="/reference/c/language/attributes/">attributes</a>, applied to the loop statement</td></tr>
</table>

<h3 id="Explanation">Explanation</h3>

<p>A <code>do-while</code> statement causes the <em>statement</em> (also called <em>the loop body</em>) to be executed repeatedly until the <em>expression</em> (also called <em>controlling expression</em>) compares equal to 0. The repetition occurs regardless of whether the loop body is entered normally or by a <a href="/reference/c/language/goto/">goto</a> into the middle of <em>statement</em>.</p>

<p>The evaluation of <em>expression</em> takes place after each execution of <em>statement</em> (whether entered normally or by a goto). If the controlling expression needs to be evaluated before the loop body, the <a href="/reference/c/language/while/">while loop</a> or the <a href="/reference/c/language/for/">for loop</a> may be used.</p>

<p>If the execution of the loop needs to be terminated at some point, <a href="/reference/c/language/break/">break statement</a> can be used as terminating statement.</p>

<p>If the execution of the loop needs to be continued at the end of the loop body, <a href="/reference/c/language/continue/">continue statement</a> can be used as a shortcut.</p>

<p>A program with an endless loop has undefined behavior if the loop has no observable behavior (I/O, volatile accesses, atomic or synchronization operation) in any part of its <em>statement</em> or <em>expression</em>. This allows the compilers to optimize out all unobservable loops without proving that they terminate. The only exceptions are the loops where <em>expression</em> is a constant expression; <code>do {...} while(true);</code> is always an endless loop.</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c99">(since C99)</span></p><p>As with all other selection and iteration statements, the do-while statement establishes <a href="/reference/c/language/scope/">block scope</a>: any identifier introduced in the <em>expression</em> goes out of scope after the statement.</p></aside>

<h3 id="Notes">Notes</h3>

<p>Boolean and pointer expressions are often used as loop controlling expressions. The boolean value <code>false</code> and the null pointer value of any pointer type compare equal to zero.</p>

<h3 id="Keywords">Keywords</h3>

<p><a href="/reference/c/keyword/do/"><code>do</code></a>, <a href="/reference/c/keyword/while/"><code>while</code></a></p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
enum { SIZE = 8 };
int main(void)
{
    // trivial example
    int array[SIZE], n = 0;
    do array[n++] = rand() % 2; // the loop body is a single expression statement
    while(n < SIZE);
    puts("Array filled!");
    n = 0;
    do { // the loop body is a compound statement
        printf("%d ", array[n]);
        ++n;
    } while (n < SIZE);
    printf("\n");
 
    // the loop from K&R itoa(). The do-while loop is used
    // because there is always at least one digit to generate
    int num = 1234, i=0;
    char s[10];
    do s[i++] = num % 10 + '0'; // get next digit in reverse order
    while ((num /= 10) > 0);
    s[i] = '\0';
    puts(s);
}
```

<p>Possible output:</p>

```text
Array filled!
1 0 1 1 1 1 0 0
4321
```
