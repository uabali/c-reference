<p>Determines the type of an object.</p>

<h3 id="Syntax">Syntax</h3>

```text
typeof( type )
typeof( expression )
typeof_unqual( type )
typeof_unqual( expression )
```

<h3 id="Explanation">Explanation</h3>

<p class="li-note"><span class="li-num">1)</span>  produces the type-name with any nested typeof-specifier evaluated</p>

<p class="li-note"><span class="li-num">2)</span>  yields the type-name representing the type of its operand. No implicit conversions are applied to <em>expression</em>.</p>

<p class="li-note"><span class="li-num">3,4)</span>  the same as (1) and (2) respectively but remove qualifiers</p>

<h3 id="Notes">Notes</h3>

<p><code>typeof</code> and <code>typeof_unqual</code> are collectively called the <em>typeof operators</em>. The <code>typeof</code> operators cannot be applied to bit-field members. If the type of the operand is a variably modified type, the operand is evaluated; otherwise, the operand is not evaluated. The result of the <code>typeof_unqual</code> operator is the non-atomic unqualified type that would result from the <code>typeof</code> operator. The <code>typeof</code> operator preserves all qualifiers.</p>
