<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int system( const char *command );
```

<p>Calls the host environment's command processor with the parameter <code>command</code>. Returns an implementation-defined value (usually the value that the invoked program returns).</p>

<p>If command is a null pointer, checks if the host environment has a command processor and returns a nonzero value if and only if the command processor exists.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>command</td><td>-</td><td>character string identifying the command to be run in the command processor. If a null pointer is given, command processor is checked for existence</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>Implementation-defined value. If <code>command</code> is a null pointer, returns a nonzero value if and only if the command processor exists.</p>

<h3 id="Notes">Notes</h3>

<p>On POSIX systems, the return value can be decomposed using <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/wait.html" rel="noreferrer" target="_blank"><code>WEXITSTATUS</code> and <code>WSTOPSIG</code></a>.</p>

<p>The related POSIX function <a href="http://pubs.opengroup.org/onlinepubs/9699919799/functions/popen.html" rel="noreferrer" target="_blank">popen</a> makes the output generated by <code>command</code> available to the caller.</p>

<h3 id="Example">Example</h3>

<p>In this example there is a system call of the unix command <strong>date +%A</strong> and a system call to (possibly installed) <strong>gcc</strong> compiler with command-line argument (<em>--version</em>):</p>

```c
#include <stdlib.h>
 
int main(void) {
    system("date +%A");
    system("gcc --version");
}
```

<p>Possible output:</p>

```text
Wednesday
gcc (GCC) 11.2.0
...
```
