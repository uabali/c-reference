<p class="decl-header">Defined in header <code>&lt;signal.h&gt;</code></p>

```c
#define SIGTERM /*implementation defined*/
```

```c
#define SIGSEGV /*implementation defined*/
```

```c
#define SIGINT /*implementation defined*/
```

```c
#define SIGILL /*implementation defined*/
```

```c
#define SIGABRT /*implementation defined*/
```

```c
#define SIGFPE /*implementation defined*/
```

<p>Each of the above macro constants expands to an integer constant expression with distinct values, which represent different signals sent to the program.</p>

<table class="ref-table ref-dsc">
<tr><td>Constant</td><td>Explanation</td></tr>
<tr><td><code>SIGTERM</code></td><td>termination request, sent to the program</td></tr>
<tr><td><code>SIGSEGV</code></td><td>invalid memory access (segmentation fault)</td></tr>
<tr><td><code>SIGINT</code></td><td>external interrupt, usually initiated by the user</td></tr>
<tr><td><code>SIGILL</code></td><td>invalid program image, such as invalid instruction</td></tr>
<tr><td><code>SIGABRT</code></td><td>abnormal termination condition, as is e.g. initiated by <a href="/reference/c/program/abort/">abort()</a></td></tr>
<tr><td><code>SIGFPE</code></td><td>erroneous arithmetic operation such as divide by zero</td></tr>
</table>
