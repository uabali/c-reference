<p class="decl-header">Defined in header <code>&lt;signal.h&gt;</code></p>

```c
int raise( int sig );
```

<p>Sends signal sig to the program. The signal handler, specified using <a href="/reference/c/program/signal/">signal()</a>, is invoked.</p>

<p>If the user-defined signal handling strategy is not set using <a href="/reference/c/program/signal/">signal()</a> yet, it is implementation-defined whether the signal will be ignored or default handler will be invoked.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>sig</td><td>-</td><td><p>the signal to be sent. It can be an implementation-defined value or one of the following values:</p>

<table class="ref-table ref-dsc">
<tr><td><a href="/reference/c/program/SIG_types/">SIGABRT<br />SIGFPE<br />SIGILL<br />SIGINT<br />SIGSEGV<br />SIGTERM</a></td><td>defines signal types   <span class="mark-note">(macro constant)</span></td></tr>
</table></td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>0</code> upon success, non-zero value on failure.</p>

<h3 id="Example">Example</h3>

```c
#include <signal.h>
#include <stdio.h>
 
void signal_handler(int signal)
{
    printf("Received signal %d\n", signal);
}
 
int main(void)
{
    // Install a signal handler.
    signal(SIGTERM, signal_handler);
 
    printf("Sending signal %d\n", SIGTERM);
    raise(SIGTERM);
    printf("Exit main()\n");
}
```

<p>Output:</p>

```text
Sending signal 15
Received signal 15
Exit main()
```
