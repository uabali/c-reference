<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
_Noreturn void quick_exit( int exit_code );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span>  <span class="std std-until std-c23">(until C23)</span></p>

```c
[[noreturn]] void quick_exit( int exit_code );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Causes normal program termination to occur without completely cleaning the resources.</p>

<p>Functions passed to <a href="/reference/c/program/at_quick_exit/">at_quick_exit</a> are called in reverse order of their registration. After calling the registered functions, calls <code>_Exit(exit_code)</code>.</p>

<p>Functions passed to <a href="/reference/c/program/atexit/">atexit</a> or signal handlers passed to <a href="/reference/c/program/signal/">signal</a> are not called.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>exit_code</td><td>-</td><td>exit status of the program</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Example">Example</h3>

```c
#include <stdlib.h>
#include <stdio.h>
 
void f1(void)
{
    puts("pushed first");
    fflush(stdout);
}
 
void f2(void)
{
    puts("pushed second");
}
 
void f3(void)
{
    puts("won't be called");
}
 
int main(void)
{
    at_quick_exit(f1);
    at_quick_exit(f2);
    atexit(f3);
    quick_exit(0);
}
```

<p>Output:</p>

```text
pushed second
pushed first
```
