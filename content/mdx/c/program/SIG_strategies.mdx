<p class="decl-header">Defined in header <code>&lt;signal.h&gt;</code></p>

```c
#define SIG_DFL /*implementation defined*/
```

```c
#define SIG_IGN /*implementation defined*/
```

<p>The <strong>SIG_DFL</strong> and <strong>SIG_IGN</strong> macros expand into integral expressions that are not equal to an address of any function. The macros define signal handling strategies for <code>signal()</code> function.</p>

<table class="ref-table ref-dsc">
<tr><td>Constant</td><td>Explanation</td></tr>
<tr><td><code>SIG_DFL</code></td><td>default signal handling</td></tr>
<tr><td><code>SIG_IGN</code></td><td>signal is ignored</td></tr>
</table>

<h3 id="Example">Example</h3>

```c
#include <signal.h>
#include <stdio.h>
 
int main(void)
{
    /* using the default signal handler */
    raise(SIGTERM);
    printf("Exit main()\n");   /* never reached */
}
```

<p>Output:</p>

```text
(none)
```

<h3 id="Example_2">Example</h3>

```c
#include <signal.h>
#include <stdio.h>
 
int main(void)
{
    /* ignoring the signal */
    signal(SIGTERM, SIG_IGN);
    raise(SIGTERM);
    printf("Exit main()\n");
}
```

<p>Output:</p>

```text
Exit main()
```
