```c
void _Exit( int exit_code );
```

<p class="decl-note"><span class="std std-since std-c99">(since C99)</span>  <span class="std std-until std-c11">(until C11)</span></p>

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span>  <span class="std std-until std-c23">(until C23)</span></p>

```c
[[noreturn]] void _Exit( int exit_code );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Causes normal program termination to occur without completely cleaning the resources.</p>

<p>Functions passed to <a href="/reference/c/program/at_quick_exit/">at_quick_exit()</a> or <a href="/reference/c/program/atexit/">atexit()</a> are not called. Whether open streams with unwritten buffered data are flushed, open streams are closed, or temporary files are removed is implementation-defined.</p>

<p>If <code>exit_code</code> is 0 or <a href="/reference/c/program/EXIT_status/">EXIT_SUCCESS</a>, an implementation-defined status indicating successful termination is returned to the host environment. If <code>exit_code</code> is <a href="/reference/c/program/EXIT_status/">EXIT_FAILURE</a>, an implementation-defined status, indicating <em>unsuccessful</em> termination, is returned. In other cases an implementation-defined status value is returned.</p>

<table class="ref-table ref-params">
<tr><td>exit_code</td><td>-</td><td>exit status of the program</td></tr>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Example">Example</h3>

```c
#include <stdlib.h>
#include <stdio.h>
 
/* _Exit does not call functions registered with atexit. */
void f1(void)
{
    puts("pushed first");
}
 
void f2(void)
{
    puts("pushed second");
}
 
int main(void)
{
    printf("Enter main()\n");
    atexit(f1);
    atexit(f2);
    fflush(stdout);   /* _Exit may not flush unwritten buffered data */
    _Exit(0);
}
```

<p>Output:</p>

```text
Enter main()
```
