<p class="decl-header">Defined in header <code>&lt;signal.h&gt;</code></p>

```c
typedef /* unspecified */ sig_atomic_t;
```

<p>An integer type which can be accessed as an atomic entity even in the presence of asynchronous interrupts made by signals.</p>

<h3 id="Example">Example</h3>

```c
#include <signal.h>
#include <stdio.h>
 
volatile sig_atomic_t gSignalStatus = 0;
 
void signal_handler(int status)
{
    gSignalStatus = status;
}
 
int main(void)
{
    /* Install a signal handler. */
    signal(SIGINT, signal_handler);
 
    printf("SignalValue:    %d\n", gSignalStatus);
    printf("Sending signal: %d\n", SIGINT);
    raise(SIGINT);
    printf("SignalValue:    %d\n", gSignalStatus);
}
```

<p>Possible output:</p>

```text
SignalValue:    0
Sending signal: 2
SignalValue:    2
```
