<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
void abort(void);
```

<p class="decl-note"><span class="std std-until std-c11">(until C11)</span></p>

```c
_Noreturn void abort(void);
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span>  <span class="std std-until std-c23">(until C23)</span></p>

```c
[[noreturn]] void abort(void);
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Causes abnormal program termination unless <a href="/reference/c/program/SIG_types/">SIGABRT</a> is being caught by a signal handler passed to signal and the handler does not return.</p>

<p>Functions passed to <a href="/reference/c/program/atexit/">atexit()</a> are not called. Whether open resources such as files are closed is implementation defined. An implementation defined status is returned to the host environment that indicates unsuccessful execution.</p>

<h3 id="Parameters">Parameters</h3>

<p>(none)</p>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Notes">Notes</h3>

<p>POSIX <a href="https://pubs.opengroup.org/onlinepubs/9699919799/functions/abort.html" rel="noreferrer" target="_blank">specifies</a> that the <code>abort()</code> function overrides blocking or ignoring the <code>SIGABRT</code> signal.</p>

<p>Some compiler intrinsics, e.g. <a href="https://gcc.gnu.org/onlinedocs/gcc/Other-Builtins.html" rel="noreferrer" target="_blank"><code>__builtin_trap</code></a> (gcc, clang, and icc) or <a href="https://learn.microsoft.com/en-us/cpp/intrinsics/fastfail" rel="noreferrer" target="_blank"><code>__fastfail</code></a>/<a href="https://learn.microsoft.com/en-us/cpp/intrinsics/debugbreak" rel="noreferrer" target="_blank"><code>__debugbreak</code></a> (msvc), can be used to terminate the program as fast as possible.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    FILE *fp = fopen("data.txt","r");
    if (fp == NULL)
    {
        fprintf(stderr, "error opening file data.txt in function main()\n");
        abort();
    }
 
    /* Normal processing continues here. */
    fclose(fp);
    printf("Normal Return\n");
    return 0;
}
```

<p>Output:</p>

```text
error opening file data.txt in function main()
```
