<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
#define EXIT_SUCCESS /*implementation defined*/
```

```c
#define EXIT_FAILURE /*implementation defined*/
```

<p>The <code>EXIT_SUCCESS</code> and <code>EXIT_FAILURE</code> macros expand into integral constant expressions that can be used as arguments to the <a href="/reference/c/program/exit/">exit</a> function (and, therefore, as the values to return from the <a href="/reference/c/language/main_function/">main function</a>), and indicate program execution status.</p>

<table class="ref-table ref-dsc">
<tr><td>Constant</td><td>Description</td></tr>
<tr><td><code>EXIT_SUCCESS</code></td><td>successful execution of a program</td></tr>
<tr><td><code>EXIT_FAILURE</code></td><td>unsuccessful execution of a program</td></tr>
</table>

<h3 id="Notes">Notes</h3>

<p>Both <code>EXIT_SUCCESS</code> and the value zero indicate successful program execution status (see <a href="/reference/c/program/exit/">exit</a>), although it is not required that <code>EXIT_SUCCESS</code> equals zero.</p>

<h3 id="Example">Example</h3>

```c
#include <stdio.h>
#include <stdlib.h>
 
int main(void)
{
    FILE* fp = fopen("data.txt", "r");
    if (fp == NULL)
    {
       fprintf(stderr, "fopen() failed in file %s at line #%d", __FILE__, __LINE__);
       exit(EXIT_FAILURE);
    }
 
    /* Normal processing continues here. */
    fclose(fp);
    printf("Normal Return\n");
 
    return EXIT_SUCCESS;
}
```

<p>Output:</p>

```text
fopen() failed in file main.cpp at line #9
```
