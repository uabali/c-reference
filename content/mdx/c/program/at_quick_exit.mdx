<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
int at_quick_exit( void (*func)(void) );
```

<p class="decl-note"><span class="std std-since std-c11">(since C11)</span></p>

<p>Registers the function pointed to by <code>func</code> to be called on quick program termination (via <a href="/reference/c/program/quick_exit/">quick_exit</a>).</p>

<p>Calling the function from several threads does not induce a data race. The implementation is guaranteed to support the registration of at least 32 functions. The exact limit is implementation-defined.</p>

<p>The registered functions will not be called on <a href="/reference/c/program/exit/">normal program termination</a>. If a function need to be called in that case, <a href="/reference/c/program/atexit/">atexit</a> must be used.</p>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>func</td><td>-</td><td>pointer to a function to be called on quick program termination</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p><code>0</code> if the registration succeeds, nonzero value otherwise.</p>

<h3 id="Example">Example</h3>

```c
#include <stdlib.h>
#include <stdio.h>
 
void f1(void)
{
    puts("pushed first");
    fflush(stdout);
}
 
void f2(void)
{
    puts("pushed second");
}
 
int main(void)
{
    at_quick_exit(f1);
    at_quick_exit(f2);
    quick_exit(0);
}
```

<p>Output:</p>

```text
pushed second
pushed first
```
