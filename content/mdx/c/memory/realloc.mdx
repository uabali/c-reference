<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
void *realloc( void *ptr, size_t new_size );
```

<p>Reallocates the given area of memory. If <code>ptr</code> is not NULL, it must be previously allocated by <a href="/reference/c/memory/malloc/">malloc</a>, <a href="/reference/c/memory/calloc/">calloc</a> or <code>realloc</code> and not yet freed with a call to <a href="/reference/c/memory/free/">free</a> or <code>realloc</code>. Otherwise, the results are undefined.</p>

<p>The reallocation is done by either:</p>

<p class="li-note"><span class="li-num">a)</span>  expanding or contracting the existing area pointed to by <code>ptr</code>, if possible. The contents of the area remain unchanged up to the lesser of the new and old sizes. If the area is expanded, the contents of the new part of the array are undefined.</p>

<p class="li-note"><span class="li-num">b)</span>  allocating a new memory block of size <code>new_size</code> bytes, copying memory area with size equal the lesser of the new and the old sizes, and freeing the old block.</p>

<p>If there is not enough memory, the old memory block is not freed and null pointer is returned.</p>

<p>If <code>ptr</code> is <a href="/reference/c/types/NULL/">NULL</a>, the behavior is the same as calling <code>malloc(new_size)</code>.</p>

<p>Otherwise,</p>

<aside class="revision"><p class="rev-mark"><span class="std std-until std-c23">(until C23)</span></p><p>if <code>new_size</code> is zero, the behavior is implementation defined (null pointer may be returned (in which case the old memory block may or may not be freed), or some non-null pointer may be returned that may not be used to access storage). Such usage is deprecated (via <a href="https://open-std.org/JTC1/SC22/WG14/www/docs/n2396.htm#dr_400" rel="noreferrer" target="_blank">C DR 400</a>).<span class="std std-until std-c17">(since C17)</span></p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c23">(since C23)</span></p><p>if <code>new_size</code> is zero, the behavior is undefined.</p></aside>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p><code>realloc</code> is thread-safe: it behaves as though only accessing the memory locations visible through its argument, and not any static storage.</p>

<p>A previous call to <a href="/reference/c/memory/free/">free</a> or <code>realloc</code> that deallocates a region of memory <em>synchronizes-with</em> a call to any allocation function, including <code>realloc</code> that allocates the same or a part of the same region of memory. This synchronization occurs after any access to the memory by the deallocating function and before any access to the memory by <code>realloc</code>. There is a single total order of all allocation and deallocation functions operating on each particular region of memory.</p></aside>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ptr</td><td>-</td><td>pointer to the memory area to be reallocated</td></tr>
<tr><td>new_size</td><td>-</td><td>new size of the array in bytes</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>On success, returns the pointer to the beginning of newly allocated memory. To avoid a memory leak, the returned pointer must be deallocated with <a href="/reference/c/memory/free/">free</a> or <code>realloc</code>. The original pointer <code>ptr</code> is invalidated and any access to it is undefined behavior (even if reallocation was in-place).</p>

<p>On failure, returns a null pointer. The original pointer <code>ptr</code> remains valid and may need to be deallocated with <a href="/reference/c/memory/free/">free</a> or <code>realloc</code>.</p>

<h3 id="Notes">Notes</h3>

<p>Originally (in C89), support for zero size was added to accommodate code such as</p>

```c
OBJ *p = calloc(0, sizeof(OBJ)); // "zero-length" placeholder
/*...*/
while (1)
{
    p = realloc(p, c * sizeof(OBJ)); // reallocations until size settles
    /* code that may change c or break out of loop */
}
```

<h3 id="Example">Example</h3>

```c
#include <assert.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
 
void print_storage_info(const int* next, const int* prev, int ints)
{
    if (next)
        printf("%s location: %p. Size: %d ints (%ld bytes).\n",
               (next != prev ? "New" : "Old"), (void*)next, ints, ints * sizeof(int));
    else
        printf("Allocation failed.\n");
}
 
int main(void)
{
    const int pattern[] = {1, 2, 3, 4, 5, 6, 7, 8};
    const int pattern_size = sizeof pattern / sizeof(int);
    int *next = NULL, *prev = NULL;
 
    if ((next = (int*)malloc(pattern_size * sizeof *next))) // allocates an array
    {
        memcpy(next, pattern, sizeof pattern); // fills the array
        print_storage_info(next, prev, pattern_size);
    }
    else
        return EXIT_FAILURE;
 
    // Reallocate in cycle using the following values as a new storage size.
    const int realloc_size[] = {10, 12, 512, 32768, 65536, 32768};
 
    for (int i = 0; i != sizeof realloc_size / sizeof(int); ++i)
    {
        if ((next = (int*)realloc(prev = next, realloc_size[i] * sizeof(int))))
        {
            print_storage_info(next, prev, realloc_size[i]);
            assert(!memcmp(next, pattern, sizeof pattern));  // is pattern held
        }
        else // if realloc failed, the original pointer needs to be freed
        {
            free(prev);
            return EXIT_FAILURE;
        }
    }
 
    free(next); // finally, frees the storage
    return EXIT_SUCCESS;
}
```

<p>Possible output:</p>

```text
New location: 0x144c010. Size: 8 ints (32 bytes).
Old location: 0x144c010. Size: 10 ints (40 bytes).
New location: 0x144c450. Size: 12 ints (48 bytes).
Old location: 0x144c450. Size: 512 ints (2048 bytes).
Old location: 0x144c450. Size: 32768 ints (131072 bytes).
New location: 0x7f490c5bd010. Size: 65536 ints (262144 bytes).
Old location: 0x7f490c5bd010. Size: 32768 ints (131072 bytes).
```
