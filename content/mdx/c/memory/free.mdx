<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
void free( void *ptr );
```

<p>Deallocates the space previously allocated by <a href="/reference/c/memory/malloc/">malloc()</a>, <a href="/reference/c/memory/calloc/">calloc()</a>, aligned_alloc(),<span class="std std-since std-c11">(since C11)</span> or <a href="/reference/c/memory/realloc/">realloc()</a>.</p>

<p>If <code>ptr</code> is a null pointer, the function does nothing.</p>

<p>The behavior is undefined if the value of <code>ptr</code> does not equal a value returned earlier by <a href="/reference/c/memory/malloc/">malloc()</a>, <a href="/reference/c/memory/calloc/">calloc()</a>, <a href="/reference/c/memory/realloc/">realloc()</a>, or aligned_alloc()<span class="std std-since std-c11">(since C11)</span>.</p>

<p>The behavior is undefined if the memory area referred to by <code>ptr</code> has already been deallocated, that is, <code>free()</code>, free_sized(), free_aligned_sized()<span class="std std-since std-c23">(since C23)</span>, or <a href="/reference/c/memory/realloc/">realloc()</a> has already been called with <code>ptr</code> as the argument and no calls to <a href="/reference/c/memory/malloc/">malloc()</a>, <a href="/reference/c/memory/calloc/">calloc()</a>, <a href="/reference/c/memory/realloc/">realloc()</a>, or aligned_alloc()<span class="std std-since std-c11">(since C11)</span> resulted in a pointer equal to <code>ptr</code> afterwards.</p>

<p>The behavior is undefined if after <code>free()</code> returns, an access is made through the pointer <code>ptr</code> (unless another allocation function happened to result in a pointer value equal to <code>ptr</code>).</p>

<aside class="revision"><p class="rev-mark"><span class="std std-since std-c11">(since C11)</span></p><p><code>free</code> is thread-safe: it behaves as though only accessing the memory locations visible through its argument, and not any static storage.</p>

<p>A call to <code>free</code> that deallocates a region of memory <em>synchronizes-with</em> a call to any subsequent allocation function that allocates the same or a part of the same region of memory. This synchronization occurs after any access to the memory by the deallocating function and before any access to the memory by the allocation function. There is a single total order of all allocation and deallocation functions operating on each particular region of memory.</p></aside>

<h3 id="Parameters">Parameters</h3>

<table class="ref-table ref-params">
<tr><td>ptr</td><td>-</td><td>pointer to the memory to deallocate</td></tr>
</table>

<h3 id="Return_value">Return value</h3>

<p>(none)</p>

<h3 id="Notes">Notes</h3>

<p>The function accepts (and does nothing with) the null pointer to reduce the amount of special-casing. Whether allocation succeeds or not, the pointer returned by an allocation function can be passed to <code>free()</code>.</p>

<h3 id="Example">Example</h3>

```c
#include <stdlib.h>
 
int main(void)
{
    int *p1 = malloc(10*sizeof *p1);
    free(p1); // every allocated pointer must be freed
 
    int *p2 = calloc(10, sizeof *p2);
    int *p3 = realloc(p2, 1000*sizeof *p3);
    if(p3) // p3 not null means p2 was freed by realloc
       free(p3);
    else // p3 null means p2 was not freed
       free(p2);
}
```
