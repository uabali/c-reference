<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
void free_aligned_sized( void* ptr, size_t alignment, size_t size );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>If <code>ptr</code> is a null pointer or the result obtained from a call to aligned_alloc, where <code>alignment</code> is equal to the requested allocation alignment and <code>size</code> is equal to the requested allocation size, this function is equivalent to <code>free(ptr)</code>. Otherwise, the behavior is undefined.</p>

<p>The result of an <a href="/reference/c/memory/malloc/">malloc</a>, <a href="/reference/c/memory/calloc/">calloc</a>, or <a href="/reference/c/memory/realloc/">realloc</a> call may not be passed to <code>free_aligned_sized</code>.</p>

<p><code>free_aligned_sized</code> is thread-safe: it behaves as though only accessing the memory locations visible through its argument, and not any static storage.</p>

<p>A call to <code>free_aligned_sized</code> that deallocates a region of memory <em>synchronizes-with</em> a call to any subsequent allocation function that allocates the same or a part of the same region of memory. This synchronization occurs after any access to the memory by the deallocating function and before any access to the memory by the allocation function. There is a single total order of all allocation and deallocation functions operating on each particular region of memory.</p>
