<p class="decl-header">Defined in header <code>&lt;stdlib.h&gt;</code></p>

```c
void free_sized( void* ptr, size_t size );
```

<p class="decl-note"><span class="std std-since std-c23">(since C23)</span></p>

<p>Deallocates the space previously allocated by <a href="/reference/c/memory/malloc/">malloc()</a>, <a href="/reference/c/memory/calloc/">calloc()</a>, or <a href="/reference/c/memory/realloc/">realloc()</a> (but not aligned_alloc()).</p>

<table class="ref-table">
<tr><td></td><td>This section is incomplete Reason: share wording among `free_*` family</td></tr>
</table>

<p><code>free_sized</code> is thread-safe: it behaves as though only accessing the memory locations visible through its argument, and not any static storage.</p>

<p>A call to <code>free_sized</code> that deallocates a region of memory <em>synchronizes-with</em> a call to any subsequent allocation function that allocates the same or a part of the same region of memory. This synchronization occurs after any access to the memory by the deallocating function and before any access to the memory by the allocation function. There is a single total order of all allocation and deallocation functions operating on each particular region of memory.</p>

<h3 id="Possible_implementation">Possible implementation</h3>

```c
void free_sized(void* ptr, size_t /*size*/)
{
    free(ptr);
}
```

<h3 id="Example">Example</h3>

```c
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
 
typedef struct
{
    size_t size;     // current number of elements
    size_t capacity; // reserved number of elements
    void** data;
} PtrVector;
 
PtrVector vector_create(size_t initial_capacity)
{
    PtrVector ret =
    {
        .capacity = initial_capacity,
        .data = (void**) malloc(initial_capacity * sizeof(void*))
    };
    return ret;
}
 
void vector_delete(PtrVector* self)
{
    free_sized(self->data, self->capacity * sizeof(void*));
}
 
void vector_push_back(PtrVector* self, void* value)
{
    if (self->size == self->capacity)
    {
        self->capacity *= 2;
        self->data = (void**) realloc(self->data, self->capacity * sizeof(void*));
    }
    self->data[self->size++] = value;
}
 
int main()
{
    int data = 42;
    float pi = 3.141592f;
    PtrVector v = vector_create(8);
    vector_push_back(&v, &data);
    vector_push_back(&v, &pi);
    printf("data[0] = %i\n", *(int*)v.data[0]);
    printf("data[1] = %f\n", *(float*)v.data[1]);
    vector_delete(&v);
}
```

<p>Output:</p>

```text
data[0] = 42
data[1] = 3.141592
```
